# 문과생을 위한 웹앱 개발 8주 완성 강의 (No-Code)

파이썬 몰라도, 터미널 몰라도, 브라우저만 있으면 8주 만에 실제로 배포된 웹앱을 만들 수 있도록 안내하는 강의 교안 사이트입니다. 웹앱 개발의 기초 개념을 v0.dev와 함께 하나씩 익힙니다.

## 커리큘럼

| 주차 | 배우는 개념 | 만드는 것 |
|---|---|---|
| 1 | 웹의 기초, v0.dev 첫 만남 | 나의 첫 웹페이지 (공개 URL) |
| 2 | 랜딩 페이지 구조 | 자기소개 랜딩 페이지 |
| 3 | 라우팅 (URL과 페이지) | 4페이지 개인 포트폴리오 |
| 4 | 폼과 사용자 입력 | 이메일 오는 문의 폼 (Formspree) |
| 5 | 데이터와 반복 렌더링 | 카페 갤러리 (검색/필터/정렬) |
| 6 | 상태 관리와 localStorage | To-Do 앱 (진짜 사용 가능한) |
| 7 | 외부 API 호출 | AI 챗봇 (Gemini API) |
| 8 | 프로덕트 마무리 + 배포 | 최종 프로젝트 + 커스텀 도메인 |

## 학생 실습 스택

- **v0.dev** — 말로 부탁하면 웹앱을 만들어주는 도구
- **Vercel** — v0가 만든 앱을 인터넷에 자동 배포
- **Formspree** (Week 4) — 폼 데이터를 이메일로 전달
- **Gemini API** (Week 7) — AI 챗봇 기능 (유료 요금제)

**설치할 것 없음. 파이썬 없음. 터미널 없음.**

## 이 사이트 스택 (강사·기여자용)

- Next.js 16 App Router
- TypeScript · Tailwind CSS
- MDX (@next/mdx + rehype-pretty-code)
- Vercel 배포

## 로컬 개발

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 확인.

## 프로덕션 빌드

```bash
npm run build
npm start
```
