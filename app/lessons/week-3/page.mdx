## 이번 주에 할 일

지난 2주는 텍스트만 다뤘어요. 이번 주는 **이미지**를 다룹니다.

두 가지 방향으로 이미지를 씁니다:

1. **이미지 → 텍스트** (Vision): 사진을 보여주면 AI가 설명해줌
   - 여행 사진 → 자동 캡션
   - 스캔한 노트 → 텍스트 정리
2. **텍스트 → 이미지** (Imagen): 상상을 이미지로
   - "구름 위에 앉은 고양이가 커피 마시는 수채화" → 진짜 그림 생성

**여전히 코드는 필요 없습니다.** 전부 AI Studio 안에서 마우스로 해결.

## Part 1: 이미지 이해하기 (Vision)

### Step 1. AI Studio에서 이미지 업로드

<a href="https://aistudio.google.com" target="_blank">aistudio.google.com</a>에서 새 대화(**+ New chat**)를 엽니다.

가운데 대화창 하단, 입력창 왼쪽에 **➕ 또는 클립 아이콘**이 있어요. 이걸 클릭하면 파일 업로드 옵션이 뜹니다.

- **Upload File**: 컴퓨터에서 이미지 선택
- **Take a photo**: 웹캠으로 찍기 (Mac은 잘 됨)

여러분의 폰에서 여행 사진 하나를 컴퓨터로 옮겨서 업로드해보세요. 아니면 아무 사진이나 OK.

### Step 2. 이미지에 대해 물어보기

이미지가 대화창 위에 미리보기로 뜬 상태에서, 입력창에 이렇게 써보세요:

```
이 사진에 뭐가 보여? 한국어로 상세하게 설명해줘.
```

`Enter` → 잠시 후 AI가 사진을 보고 답변합니다.

**놀랍지 않나요?** AI가 정말로 사진을 이해합니다. 색깔, 사물, 표정, 분위기까지.

### Step 3. 이미지에 관한 다양한 질문

같은 사진에 대해 다양한 질문을 던져보세요:

- `이 사진의 분위기를 한 문장으로 표현해줘`
- `이 사진에 어울리는 인스타 캡션 만들어줘. 감성적으로.`
- `이 사진을 초등학생이 이해할 수 있게 설명해줘`
- `이 사진 속 상황이 왜 웃긴지 (혹은 슬픈지) 분석해줘`

## Step 4. 여행 사진 자동 캡션 앱 (System Instructions 활용)

이번엔 페르소나 챗봇처럼 시스템 지시로 **"여행 사진 캡션 전문가"**를 만들어봅시다.

**+ New chat** → System instructions에:

```text
당신은 인스타그램 감성 캡션 전문가입니다.

【역할】
사용자가 여행 사진을 올리면, 아래 형식으로 캡션 3가지 스타일을 제안합니다.

【답변 형식】
✨ **감성적** 
[3~4문장, 시적이고 잔잔한 톤. #해시태그 3개 포함]

😎 **위트있게**
[2~3문장, 짧고 재치있게. 이모지 2~3개 자연스럽게 배치]

📖 **긴 여행기**
[5~7문장, 그 순간의 감정과 배경을 담아 진솔하게. 마지막에 여행에서 얻은 인사이트 한 줄]

【규칙】
- 사진 속 실제 요소(색감, 시간대, 사물, 분위기)를 반드시 반영한다.
- 국가·지역이 명확히 보이면 언급하고, 애매하면 상상으로 채우지 않는다.
- 각 스타일 사이에 구분선 --- 을 넣는다.
```

Temperature: **0.9** (창의성 높게)

저장: `여행 사진 캡션 전문가`.

이제 여행 사진 몇 장 올려서 테스트해보세요. 세 가지 스타일의 캡션이 나옵니다.

**이걸 인스타 올리기 전에 실제로 참고 자료로 쓰면 진짜 유용해요.**

## Step 5. 영수증에서 정보 뽑기

이미지 이해의 실용적 활용법. 영수증 사진 한 장을 업로드하고:

```
이 영수증에서 다음 정보를 뽑아줘. 모르는 건 "확인 불가"로 답해.

- 상호명
- 방문 날짜
- 총 결제 금액
- 카테고리 (식당/카페/편의점/기타 중 선택)
- 구매 품목 리스트 (있으면)
```

AI가 텍스트로 정리해서 뿌려줍니다.

> 💡 다음 주에는 이걸 **표(테이블) 형식으로 자동 정리**하는 방법을 배웁니다.

## Step 6. 여러 이미지 한번에

이미지를 여러 장 업로드할 수도 있어요. 클립 아이콘을 여러 번 눌러 사진 2~3장 추가:

- `두 사진의 차이점을 5가지 찾아줘` (다른 그림 찾기)
- `세 장 중 인스타에 올리기 제일 좋은 사진을 골라줘. 이유도.`
- `이 4장을 시간 순서대로 나열해줘`

## Part 2: 이미지 생성하기 (Imagen)

Google AI Studio는 **텍스트로 이미지를 생성**하는 기능도 있어요.

### Step 7. Imagen 접근하기

왼쪽 사이드바 아래쪽에 **"Media generation"** 또는 **"Image"** 메뉴가 있어요.

또는 대화창의 모델 선택 드롭다운에서 **"Imagen"** 시리즈를 선택할 수도 있습니다 (버전은 UI에 따라 다를 수 있음, 최신 Imagen 선택).

### Step 8. 첫 이미지 생성

Imagen 화면에 프롬프트 입력창이 있어요. 이런 걸 넣어봅시다:

```
구름 위에 앉은 고양이가 아메리카노를 마시는 수채화. 파스텔 색감, 부드러운 붓 자국.
```

`Generate` 버튼 → 30초~1분 후 이미지 4장 생성.

### Step 9. 이미지 프롬프트 잘 쓰는 공식

Imagen이 좋은 이미지를 만들려면 프롬프트에 다음이 들어가야 좋아요:

```
[주제] + [상황·행동] + [스타일] + [색감/조명] + [카메라·구도]
```

예시:

- ❌ 나쁨: `고양이`
- ✅ 좋음: `털이 부드러운 러시안블루 고양이 (주제) + 창가에서 낮잠 자는 (상황) + 유화 스타일 (스타일) + 따뜻한 오후 햇살 (조명) + 클로즈업 (구도)`

### Step 10. 다양한 스타일 실험

같은 주제로 스타일만 바꿔서 여러 번 생성해보세요:

- `우주에서 지구를 바라보는 우주인, 3D 렌더링, 시네마틱`
- `우주에서 지구를 바라보는 우주인, 수채화, 몽환적`
- `우주에서 지구를 바라보는 우주인, 픽셀아트, 8비트`
- `우주에서 지구를 바라보는 우주인, 만화 스타일, 밝고 경쾌`

같은 아이디어인데 결과물이 완전히 달라요.

## Step 11. 실전 활용 예시

이번 주에 배운 것으로 실제로 할 수 있는 일들:

1. **SNS 감성 관리**: 여행 사진 → 자동 캡션 → 그대로 인스타 업로드
2. **가계부 정리**: 영수증 사진 → 텍스트 뽑기 → 노션·엑셀에 정리
3. **발표 자료 이미지**: 발표 슬라이드용 이미지를 직접 만들기 (스톡 이미지 필요 없음)
4. **연구 자료 분석**: 오래된 문서 사진 → 텍스트 변환 → 분석
5. **드립·밈 만들기**: Imagen으로 웃긴 상황 이미지 → 친구들과 공유

## 이번 주 과제

1. **여행 사진 캡션 전문가** 저장 & 공유 URL 발급.
2. 여러분의 여행 사진 3장을 업로드해서 캡션 뽑아보기. 결과 스크린샷.
3. 영수증 정보 뽑기 실습 1회.
4. **Imagen으로 다음 세 개 이미지 생성**:
   - 여러분이 상상하는 이상적인 카페 인테리어
   - 좋아하는 캐릭터가 나오는 상상 장면
   - 자기소개 아바타 이미지
5. 생성한 이미지 중 마음에 드는 것 하나 저장 (다운로드 아이콘).
