## 이번 주에 할 일

지난 2주에 프롬프트 몇 개 만드셨죠? 이번 주는 그것들을 **잘 정리하고, 여러 프롬프트를 비교**하는 법을 배웁니다. 크리에이터가 아니라 **프로 프롬프트 엔지니어**처럼 일하는 법.

### 오늘의 목표

1. My Prompts 라이브러리에 최소 5개 프롬프트 정리
2. **Compare 모드**로 두 프롬프트 나란히 실행해 비교
3. **Public Prompts Gallery**에서 다른 사람 프롬프트 참고
4. 프롬프트를 **YAML 파일로 내보내기** (백업 & 공유)

## Step 1. My Prompts 라이브러리 훑어보기

<a href="https://aistudio.google.com" target="_blank">aistudio.google.com</a> 접속 → 왼쪽 사이드바 **"My prompts"** 클릭.

지난 2주에 저장한 프롬프트들이 여기 목록으로 있을 거예요:

- 나의 학습 도우미
- 조선시대 선비 이한
- 츤데레 유리
- 미슐랭 셰프 박찬성
- (실습 중 만든 실험용 프롬프트들)

### 프롬프트 이름 다시 짓기

정리를 위해 각 프롬프트의 이름을 이해하기 쉽게 통일해봅시다. **각 프롬프트 카드의 ⋯ 메뉴 → Rename**.

권장 이름 규칙: `[카테고리] 이름 - 설명`

예를 들어:

```
[학습] 대학생 튜터 - 눈높이 설명
[캐릭터] 조선 선비 이한 - 하오체 유교 인용
[캐릭터] 츤데레 유리 - 반말 무뚝뚝
[요리] 셰프 박찬성 - 재료→3가지 요리 추천
[실험] Temperature 비교 - 시 창작 (0.3 vs 1.5)
```

이렇게 이름 규칙을 세우면 나중에 프롬프트가 20~30개 쌓여도 찾기 쉬워요.

### 오래된 실험용 프롬프트 삭제

Week 1 실습 중 만든 임시 프롬프트들은 필요 없으면 삭제. **⋯ 메뉴 → Delete**.

## Step 2. Compare 모드 - 두 프롬프트 나란히 비교

같은 질문을 두 프롬프트(예: temperature 0.3 vs 1.5, 또는 다른 System Instructions)에 동시에 던져 결과를 나란히 볼 수 있어요.

### 2-1. Compare 열기

프롬프트 편집 화면에서 상단의 **"Compare"** 버튼 또는 **⋯ 메뉴 → Compare**.

화면이 좌우 두 개 창으로 분할됩니다. **왼쪽은 현재 프롬프트**, **오른쪽은 비교할 프롬프트**.

### 2-2. 비교 대상 선택

오른쪽 창의 상단에서 **"Load prompt"** → My prompts 중 하나 선택. 또는 완전히 새 설정으로.

### 2-3. 실험 - Temperature 비교

**왼쪽 창** 세팅:
- System instructions: 비워두기 (기본)
- Temperature: **0.3**

**오른쪽 창** 세팅:
- System instructions: 비워두기 (기본)  
- Temperature: **1.5**

두 창에 같은 질문 던지기:

```
겨울에 어울리는 시 한 편 지어줘.
```

두 창의 결과를 나란히 비교해보세요. Temperature가 낮은 쪽은 뻣뻣하고 안전한 시, 높은 쪽은 창의적이지만 때로 이상한 표현이 섞이는 시가 나옵니다.

### 2-4. 실험 - System Instructions 비교

**왼쪽**: System instructions 비워두기
**오른쪽**: 아래 프롬프트를 System instructions에 붙여넣기

```
당신은 시조 시인 정지용입니다. 답변은 모두 시조 형식(3장 6구 45자 내외)으로 하며, 
자연·계절·정서를 소재로 삼습니다.
```

같은 질문 던지기:

```
오늘 하루 어떻게 살아야 할지 조언해줘.
```

두 답변의 차이가 극명하죠? System instructions의 힘을 눈으로 확인하는 순간입니다.

## Step 3. Public Prompts Gallery 둘러보기

다른 사람들이 만든 프롬프트를 참고하면 학습 속도가 빨라져요.

### 3-1. Gallery 접근

왼쪽 사이드바 하단 또는 홈 화면의 **"Explore prompts"** / **"Prompt gallery"** / **"Templates"** 등의 메뉴 클릭.

### 3-2. 카테고리별 훑어보기

- **Writing** (글쓰기)
- **Coding** (코딩)
- **Analysis** (분석)
- **Fun** (재미)
- **Business** (업무)

각 프롬프트 카드를 클릭하면 System instructions와 예시 대화를 볼 수 있어요.

### 3-3. 마음에 드는 프롬프트 복제

**"Try it"** 또는 **"Fork"** 버튼 클릭 → 여러분의 My prompts에 복사됩니다. 그 상태에서 자유롭게 수정 가능.

**과제**: Gallery에서 3개 프롬프트를 골라 각각 fork한 뒤, 여러분 스타일로 수정.

## Step 4. 프롬프트를 YAML 파일로 내보내기

프롬프트를 텍스트 파일로 백업하거나, GitHub에 공유하거나, 팀원과 나눌 수 있어요.

### 4-1. Export

편집 화면 상단 **⋯ 메뉴** → **"Export as YAML"** (또는 JSON).

파일이 다운로드됩니다. 이런 형태의 텍스트 파일:

```yaml
name: 조선시대 선비 이한
model: gemini-2.5-flash
temperature: 0.9
systemInstructions: |
  당신은 조선시대 선비 '이한(李翰)'입니다...
```

이걸 GitHub이나 Notion에 붙여넣어 프롬프트 컬렉션을 만들 수 있어요.

### 4-2. Import

다른 사람의 YAML 파일이 있다면 **⋯ 메뉴 → "Import from file"**로 여러분 계정에 불러올 수 있어요.

## Step 5. 프롬프트 폴더로 정리 (있는 경우)

AI Studio에는 **프롬프트를 폴더로 정리하는 기능**이 있어요 (인터페이스에 따라 다르지만).

폴더 예시:

- 📚 **학습용**: 튜터, 정리 도우미, 시험 문제 생성
- 🎭 **캐릭터**: 선비, 유리, 셰프
- 💼 **업무용**: 이메일 초안, 회의 요약, 자소서 첨삭
- 🧪 **실험용**: Temperature 비교, 모델 비교

왼쪽 사이드바에서 **"+ New folder"** 또는 프롬프트 우클릭 → **"Move to..."**로 폴더에 넣을 수 있어요.

만약 UI에 폴더 기능이 없다면 프롬프트 이름의 앞부분(예: `[학습]`, `[캐릭터]`)으로 분류하세요.

## Step 6. 5개 프롬프트 라이브러리 만들기

이번 주 필수 과제: **My Prompts에 최소 5개 프롬프트 정리**.

기존에 만든 3~4개 + 새로 만들 1~2개.

### 새로 만들 프롬프트 아이디어

아래 System Instructions 중 하나를 골라 새로 저장해보세요.

**A. 자소서 첨삭 도우미**

```
당신은 15년차 인사담당자입니다. 사용자가 자기소개서를 붙여넣으면 
다음 3가지 관점에서 첨삭합니다:

1. 구조: 핵심 메시지가 명확한가? 문단 흐름이 자연스러운가?
2. 임팩트: 지원하는 회사·직무에 대한 관심이 구체적으로 드러나는가?
3. 진정성: 자기 이야기가 진짜 자기 것으로 느껴지는가?

각 관점마다 잘된 점과 개선할 점을 3~5문장으로 지적하고, 
마지막에 개선된 문장을 예시로 하나 제시합니다.
```

**B. 문학 작품 해설사**

```
당신은 국문학 전공 대학원생입니다. 사용자가 시나 짧은 소설을 붙여넣으면
다음 순서로 해설합니다:

1. 시대적 배경 (2~3문장)
2. 핵심 주제 (한 문장)
3. 문학적 기법 (구체적으로 3가지)
4. 개인적 감상 (진솔한 톤으로 2~3문장)
5. 관련 작품 추천 (제목·저자만, 3개)
```

**C. 아이디어 브레인스토밍**

```
당신은 창의적 브레인스토밍 파트너입니다. 사용자가 주제를 말하면
다음 형식으로 아이디어를 제시합니다:

- 🌱 안전한 아이디어 3개 (실현 가능성 높음)
- 🚀 도전적 아이디어 3개 (실현 어렵지만 임팩트 큼)  
- 🌈 엉뚱한 아이디어 3개 (성공 확률 낮지만 재밌음)

각 아이디어에 30자 이내 설명 첨부. 판단하지 말고 확산적으로 생각.
```

## Step 7. 프롬프트 관리 팁

프롬프트가 여러 개 쌓이면 다음 관리 습관이 유용해요.

### 팁 1. 버전 관리

프롬프트를 크게 수정할 땐 원본을 **Duplicate**한 뒤 새 버전을 만드세요. 원본은 `v1`, 수정본은 `v2` 이런 식.

### 팁 2. 설명 노트

프롬프트 상단이나 System instructions의 첫 줄에 **주석**을 남겨두세요:

```
# 목적: 학생 자소서 첨삭용
# 사용법: 자소서 초안 그대로 붙여넣으면 됨
# 마지막 수정: 2026-03-15
# 버전: v3 (예시 3개 추가)

당신은 15년차 인사담당자입니다...
```

### 팁 3. 정기 청소

한 달에 한 번씩 My Prompts를 훑어보고 안 쓰는 것 삭제. 5개 이내로 유지하면 진짜 잘 쓰이는 것만 남습니다.

## 자주 발생하는 상황

### ❓ Compare 모드가 안 보여요

**해결**: AI Studio 인터페이스는 자주 업데이트됩니다. Compare 대신 **"Duplicate this prompt"**로 두 개를 나란히 여러 창(브라우저 탭)에서 실행해도 됩니다.

### ❓ 프롬프트 순서를 바꿀 수 없어요

**해결**: 이름 규칙(`[학습]`, `[캐릭터]` 등 카테고리 접두어)으로 알파벳 순 정렬을 활용하세요.

### ❓ 저장한 프롬프트가 다른 브라우저에서 안 보임

**해결**: 두 브라우저 모두 **같은 구글 계정으로 로그인**되어 있는지 확인. 계정이 다르면 데이터도 별개.

## 이번 주 과제

1. **My Prompts에 최소 5개 프롬프트 정리** (필수). 스크린샷 제출.
2. **Compare 모드로 2개 프롬프트 비교** 실습. 결과 스크린샷.
3. **Public Prompt Gallery에서 3개 fork**, 각각 여러분 스타일로 수정.
4. **YAML export** 실습 - 프롬프트 하나를 파일로 저장.
5. **선택 도전**: 프롬프트 컬렉션을 Notion 페이지 or GitHub 저장소에 정리해 공개.

## 다음 주 예고

지금까지 AI 답변은 **줄글**이었죠. Week 4에서는 답변을 **구조화된 JSON 데이터**로 받는 법을 배웁니다.

- 뉴스 기사 → 자동으로 요약·키워드·카테고리·감정 톤 JSON으로
- 영수증 사진 → 상호·날짜·금액·품목 JSON으로  
- 자소서 → 학력·경력·스킬 배열 JSON으로

이 데이터를 그대로 엑셀·노션·다른 앱에 붙여넣을 수 있어요. **Structured Output**이 이번 주의 주인공입니다.
