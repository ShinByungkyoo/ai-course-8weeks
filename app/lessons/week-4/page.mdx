## 이번 주에 할 일

지난 3주까지 AI 답변은 **줄글**이었죠. 이번 주는 AI가 **표·리스트·JSON** 같은 **구조화된 형식**으로 답하게 만듭니다.

왜 중요할까요?

- 영수증 10장 정리 → 표로 뽑히면 엑셀·노션에 그대로 붙여넣기 가능
- 뉴스 기사 5개 → 요약·키워드·카테고리로 정리되면 분석하기 쉬움
- 이력서 → 학력·경력이 표로 정리되면 검색·비교 편함

이 기능이 **Structured Output**입니다. Google AI Studio는 이걸 마우스 클릭 몇 번으로 세팅할 수 있어요.

**결과물 예시**:

```json
{
  "상호": "스타벅스 신촌점",
  "날짜": "2026-03-15",
  "총액": 12500,
  "카테고리": "카페",
  "품목": [
    { "이름": "아메리카노 T", "가격": 4500 },
    { "이름": "블루베리 스콘", "가격": 3800 },
    { "이름": "샌드위치", "가격": 4200 }
  ]
}
```

이런 걸 AI가 자동으로 뽑아줍니다.

## Step 1. Structured Output 옵션 켜기

AI Studio에서 **+ New chat** 새로 시작.

오른쪽 사이드바를 아래로 스크롤하면 **"Structured output"** 스위치가 있어요 (또는 **"Response format"** → **"JSON"**).

이걸 켜면 아래에 **"Add JSON schema"** 또는 **"Edit schema"** 같은 버튼이 나타납니다. 클릭.

**JSON 스키마 편집기**가 열립니다. 여기서 마우스로 필드를 추가하면 됩니다.

## Step 2. 첫 스키마 - 뉴스 기사 정리

간단한 예로 시작해봅시다. 뉴스 기사 하나를 붙여넣으면 AI가 이렇게 정리하게 하려고요:

- **제목** (문자열)
- **한줄요약** (문자열)
- **키워드** (문자열 리스트, 최대 5개)
- **카테고리** (정해진 값 중 하나: 정치/경제/사회/문화/스포츠/기타)
- **감정 톤** (긍정/중립/부정)

### 스키마 만들기 (버튼 클릭만으로)

Structured Output 편집기에서:

1. **"+ Add property"** 버튼 클릭.
2. Name: `title` / Type: `string` / Description: `뉴스 기사 제목`
3. 다시 **"+ Add property"** → Name: `summary` / Type: `string` / Description: `한 문장 요약`
4. **"+ Add property"** → Name: `keywords` / Type: `array` / Items type: `string` / Description: `핵심 키워드 최대 5개`
5. **"+ Add property"** → Name: `category` / Type: `string` / **Enum**에 다음 값 추가: `정치, 경제, 사회, 문화, 스포츠, 기타`
6. **"+ Add property"** → Name: `sentiment` / Type: `string` / **Enum**: `긍정, 중립, 부정`

> **Enum이 뭐예요?** AI가 자유롭게 답하지 못하게 **정해진 몇 가지 중에서만** 고르게 하는 옵션이에요. 카테고리처럼 정해진 범주가 있을 때 필수.

### System Instructions

오른쪽 사이드바 **System Instructions**에 이렇게 입력:

```text
당신은 뉴스 기사 분석 전문가입니다. 사용자가 붙여넣은 뉴스 기사를 
읽고, 지정된 JSON 스키마 형식으로 정확하게 정리하세요.

규칙:
- title은 원문에서 그대로 가져옵니다.
- summary는 반드시 한 문장으로 압축합니다.
- keywords는 명사 중심으로, 중복 없이 3~5개.
- category와 sentiment는 스키마에 정의된 값 중에서만 고릅니다.
```

### 테스트

가운데 대화창에 아무 뉴스 기사를 복사해서 붙여넣어보세요. 네이버 뉴스든, 신문 웹사이트든.

그리고 **Run**.

결과가 이렇게 나옵니다:

```json
{
  "title": "삼성전자, 3분기 영업이익 사상 최대치 경신",
  "summary": "삼성전자가 반도체 부문 실적 회복에 힘입어 3분기 영업이익이 전년 대비 274% 증가한 12조원을 기록했다.",
  "keywords": ["삼성전자", "영업이익", "반도체", "3분기", "실적"],
  "category": "경제",
  "sentiment": "긍정"
}
```

이 JSON을 그대로 노션 데이터베이스나 엑셀에 붙여넣을 수 있어요.

## Step 3. 영수증 정리 앱 만들기 🧾

이번 주의 하이라이트. 이미지 이해(Week 3) + 구조화 출력(Week 4)의 조합.

### 새 프롬프트 시작

**+ New chat**.

### 스키마 만들기

**Structured output** 켜고, 다음 필드를 추가:

- `store_name`: string, "상호명"
- `date`: string, "구매 날짜 (YYYY-MM-DD 형식)"
- `total_amount`: number, "총 결제 금액 (원)"
- `category`: string, enum: [`식비`, `카페`, `쇼핑`, `교통`, `의료`, `기타`]
- `items`: array
  - items type: **object**
  - object 내부 property:
    - `name`: string, "품목명"
    - `quantity`: integer, "수량"
    - `price`: number, "가격"

### System Instructions

```text
당신은 한국 영수증 정보 추출 전문가입니다. 
사용자가 업로드한 영수증 이미지에서 지정된 필드를 정확히 뽑아냅니다.

규칙:
- 읽을 수 없는 필드는 null로 둡니다.
- 날짜는 반드시 YYYY-MM-DD 형식으로.
- total_amount는 숫자만 (원화 기호 제외).
- 품목명이 흐릿하거나 안 보이면 items를 빈 배열로.
- category는 스키마에 정의된 값에서만 선택.
```

저장: `영수증 자동 정리`.

### 테스트

영수증 사진 하나를 대화창에 업로드하고, 메시지는 이거 하나만 입력:

```
이 영수증을 정리해줘.
```

이런 결과가 나옵니다:

```json
{
  "store_name": "스타벅스 신촌점",
  "date": "2026-03-15",
  "total_amount": 12500,
  "category": "카페",
  "items": [
    { "name": "아메리카노 T", "quantity": 1, "price": 4500 },
    { "name": "블루베리 스콘", "quantity": 1, "price": 3800 },
    { "name": "샌드위치", "quantity": 1, "price": 4200 }
  ]
}
```

## Step 4. 여러 영수증 한번에 정리

한 번의 대화에 영수증 여러 장을 업로드할 수도 있어요. 클립 아이콘으로 3~5장 추가 → 메시지: `이 영수증들 모두 정리해줘.`

AI가 각 영수증을 배열로 정리해줍니다. **JSON 스키마를 배열의 배열로 만들면** 더 깔끔하게 나오는데, 이건 심화 과제.

## Step 5. 이력서 파싱 앱 (실용적)

문과생 여러분에게 실용적인 앱 하나. 자기소개서·이력서를 붙여넣으면 자동 정리.

### 스키마

- `name`: string
- `contact`: object (email, phone)
- `education`: array of object (school, major, degree, year)
- `experience`: array of object (company, role, period, description)
- `skills`: array of string
- `certifications`: array of string

### System Instructions

```text
당신은 이력서·자소서 파서입니다. 사용자가 붙여넣은 텍스트에서 
경력·학력·기술·자격 정보를 정확히 추출합니다.

규칙:
- 추측하지 않습니다. 없는 정보는 null 또는 빈 배열.
- 날짜는 YYYY-MM 형식.
- 학력은 최신 순으로 정렬.
- 경력도 최신 순.
```

이걸 만들어두면 여러분 자소서를 붙여넣어 검토용으로도 쓸 수 있고, 취업 준비 때 회사별로 재구성할 때 유용해요.

## Step 6. 스키마 만들기 팁

Structured Output을 잘 쓰는 요령:

### 팁 1. Description은 자세히

각 필드의 **Description**에 상세히 적을수록 AI가 정확히 채워요:

- ❌ `"날짜"`
- ✅ `"구매 날짜, YYYY-MM-DD 형식, 시각은 포함하지 않음"`

### 팁 2. Enum 적극 활용

카테고리·상태 같은 필드는 반드시 **enum**으로 값을 제한. 안 그러면 매번 다른 표현이 나옵니다.

### 팁 3. Required 필드 명시

정말 필요한 필드는 **Required**로 표시. AI가 반드시 채웁니다.

### 팁 4. 중첩 구조 사용

품목처럼 여러 개가 있는 건 **array**, 그 안의 각 항목은 **object**. 처음엔 복잡해 보여도 몇 번 만들면 익숙해집니다.

### 팁 5. 짧게 시작

한 번에 30개 필드 만들지 마세요. 3~5개로 시작해서 잘 되면 늘리기.

## 이번 주 과제

1. **영수증 자동 정리** 프롬프트 저장 & 공유 URL 발급.
2. 실제 영수증 5장을 업로드해서 결과를 정리. 스크린샷.
3. **뉴스 기사 분석기** 프롬프트 저장.
4. 관심 있는 뉴스 기사 3개를 처리해서 결과 비교.
5. **선택 도전**: 여러분만의 데이터 정리 앱을 만드세요. 아이디어:
   - 요리 레시피 → 재료·조리 시간·난이도 표로
   - 영화 리뷰 → 평점·장르·감정 정리
   - 여행 계획 → 날짜별·장소별 정리
