## 이번 주에 할 일

Week 6에 만든 챗봇은 텍스트만 주고받았죠. 이번 주엔 진짜 실용적인 기능들을 붙입니다:

1. 📄 **PDF 업로드** → PDF와 대화하는 앱
2. 🖼️ **이미지 업로드** → 사진 이해하는 앱
3. 🌐 **웹 검색** → 최신 정보 답변

Week 6 앱에 이어서 대화로 확장할 수도 있고, 새 앱으로 만들 수도 있어요. 이번 주는 **원하는 것 하나만** 골라서 완성도 있게 만드는 걸 권장합니다.

## 접근 방식

이번 주는 이전 주들처럼 세세히 알려주지 않아요. 대신 **좋은 프롬프트 예시**를 드립니다. 그대로 복사해서 시도해보고, 결과에 따라 대화로 수정하세요.

**핵심 원칙**: v0에게 뭘 만들지 명확히 설명하되, 여러분이 원하는 최종 사용자 경험을 상세히 그려주세요.

## 옵션 1: PDF 대화 앱 만들기 📄

교과서·논문·계약서 PDF를 올리면, 그 내용을 근거로 답해주는 앱.

### 시작 프롬프트

<a href="https://v0.dev" target="_blank">v0.dev</a> **+ New Chat**:

```
PDF와 대화하는 웹앱을 만들어줘.

기능:
1. 화면 상단에 큰 파일 드롭 영역. PDF 파일을 드래그하거나 클릭해서 업로드.
2. 업로드된 PDF는 자동으로 텍스트로 변환되어 대화 컨텍스트에 포함.
3. 하단에 채팅창. 사용자가 PDF 내용에 대해 질문하면 AI가 답변.
4. 답변은 반드시 PDF 내용에 근거. 답을 모르면 "이 문서에서 찾을 수 없어요"라고 답변.
5. 각 답변 하단에 "이 정보의 근거 부분 보기" 접힌 영역 (참고한 원문 표시).
6. 새 PDF 업로드 시 대화 초기화.

디자인:
- 학술 논문 리더 느낌의 클래식한 톤.
- 크림 배경, 짙은 남색 포인트.
- 세리프 폰트.

기술:
- Next.js App Router.
- Gemini API (모델: gemini-2.5-flash, 환경변수 GEMINI_API_KEY).
- PDF 파싱은 pdf-parse 라이브러리 또는 유사한 것 사용.
- 대용량 PDF 대응: 텍스트가 너무 길면 앞 100,000자만 사용.
- 시스템 프롬프트: "당신은 사용자가 업로드한 PDF 내용을 근거로 답변하는 도우미. 
  근거 없는 추측 금지. 답변 뒤에 참고한 원문 스니펫을 별도 필드로 리턴."
```

**Generate** → 결과 확인 → API 키 설정 → 배포.

### 개선 대화 예시

```
답변에 '근거' 스니펫이 원문 그대로 나와야 하는데 
지금은 요약된 문장이 나와. 원문 그대로 뽑아오게 수정해줘.
```

```
PDF가 여러 페이지일 때 페이지 번호도 함께 표시되게 해줘. 
"3페이지 참고" 같은 식으로.
```

```
답변 중에도 계속 새 질문을 입력할 수 있게 
채팅창을 항상 활성 상태로 유지해줘.
```

## 옵션 2: 이미지 이해 앱 📷

사진을 올리면 AI가 이해하고 답변하는 앱.

### 시작 프롬프트

```
이미지를 이해하는 챗봇 웹앱.

기능:
1. 채팅 UI 하단에 이미지 첨부 버튼 (클립 아이콘).
2. 이미지를 첨부한 뒤 텍스트 질문을 함께 전송하면, 
   AI가 이미지와 텍스트를 함께 이해해서 답변.
3. 첨부한 이미지는 채팅창에 미리보기로 표시 (사용자 메시지 안에).
4. 이미지 없이 텍스트만 보내도 일반 대화 가능.
5. 여러 이미지를 한 메시지에 첨부 가능.

사용 케이스 예시:
- 옷장 사진 첨부 + "오늘 소개팅인데 뭐 입을까?" → 코디 추천
- 냉장고 사진 + "이걸로 뭐 만들지?" → 레시피 추천
- 여행 사진 + "인스타 캡션 짜줘" → 감성 캡션 3개

디자인:
- 캐주얼하고 밝은 톤.
- 이미지가 강조되도록 파스텔 배경.
- 채팅 말풍선 안에 이미지가 자연스럽게 배치.

기술:
- Next.js App Router.
- Gemini 2.5 Flash (멀티모달 지원).
- 이미지는 base64로 인코딩해서 API에 전달.
- 파일 크기 제한: 각 이미지 5MB 이하.
- GEMINI_API_KEY 환경변수.
- 시스템 프롬프트는 없이 시작. 자유롭게 대화하되 사진 속 실제 요소를 근거로 답변.
```

### 확장 예시

- `"이미지가 여러 장이면 몇 번째 사진에 대한 답인지 명시하게 해줘."`
- `"음식 사진이면 자동으로 칼로리 추정치를 알려주는 모드 추가."`
- `"영수증 사진이면 자동으로 표로 정리하는 모드 (Week 4 스타일)."`

## 옵션 3: 웹 검색 챗봇 🌐

지금 시점 정보를 답할 수 있는 챗봇 (Gemini의 Google Search grounding 사용).

### 시작 프롬프트

```
실시간 웹 검색 기능이 있는 챗봇 웹앱.

기능:
1. 일반 챗봇 UI.
2. AI가 답변할 때 최신 정보가 필요하면 자동으로 Google 검색.
3. 검색 결과를 근거로 답변하고, 답변 하단에 "참고 링크" 목록 표시.
4. 검색이 사용된 경우 답변 옆에 🌐 아이콘 표시.

기술 요구사항:
- Next.js App Router.
- Gemini 2.5 Flash + Google Search grounding 사용.
- API 호출 시 config에 
  tools: [{ googleSearch: {} }] 
  형태로 설정.
- 답변 응답에서 grounding_metadata의 grounding_chunks를 파싱해서 
  참고 URL 리스트 추출.

사용자 예시 질문:
- "오늘 서울 날씨 어때?"
- "이번 주 개봉 영화 뭐 있어?"
- "요즘 주식 시장 이슈"
- "최근 애플 신제품 뉴스"

디자인:
- 뉴스 리더 느낌.
- 깔끔한 화이트 배경, 파란 링크 포인트.
- 참고 링크는 카드 형태로 (제목 + URL 미리보기).
```

### 확장 예시

- `"검색 결과의 신뢰도(뉴스/블로그/공식) 배지를 추가."`
- `"답변에 인용 번호 [1], [2]를 표시하고 하단 참고 목록과 연결."`
- `"주제별 필터: 뉴스만, 학술만, 쇼핑만 검색하도록 사이드바 옵션."`

## Step 4. 공통 개선 팁

어떤 옵션을 골랐든, 완성도를 높이는 공통 요령.

### 팁 1. 로딩 상태 자세히

```
"AI가 응답하는 동안 로딩 애니메이션에 
'검색 중...', '문서 분석 중...', '이미지 이해 중...' 
같은 진행 단계 텍스트를 순차 표시해줘."
```

### 팁 2. 에러 처리 친절하게

```
"API 호출이 실패했을 때 
'죄송해요, 지금 AI가 살짝 바빠요. 잠시 후 다시 시도해주세요' 
같은 친절한 메시지 + 재시도 버튼."
```

### 팁 3. 대화 다운로드

```
"우측 상단에 '대화 저장' 버튼. 
누르면 지금까지의 대화를 마크다운 파일로 다운로드."
```

### 팁 4. 다크모드

```
"우측 상단에 다크모드 토글. 
localStorage로 선택 기억하기."
```

### 팁 5. 공유 링크

```
"대화 스크린샷을 URL로 공유하는 기능. 
현재 대화를 서버에 저장하고, 
공유 가능한 짧은 URL 생성 (예: /share/abc123)."
```

1. **옵션 1, 2, 3 중 하나를 골라 완성**하세요. URL 제출.

   개선 이력 스크린샷.

## 자주 발생하는 상황

### ❓ 배포 후 특정 기능만 안 됨 (로컬은 됨)

**원인**: 환경변수가 프로덕션 배포에 반영 안 됨, 또는 서버리스 함수 타임아웃.

**해결**: 
1. Vercel Dashboard → Env Vars 재확인.
2. v0에게: `"프로덕션 배포에서 timeout 오류가 나요. 응답 시간이 긴 요청은 스트리밍으로 바꾸거나 
   maxDuration을 30초 이상으로 설정해줘."`

### ❓ 답변이 너무 길거나 짧음

**해결**: 시스템 프롬프트에 길이 지침:
```
"모든 답변은 최소 3문장, 최대 10문장. 
너무 길어질 것 같으면 하이라이트 먼저 3문장, 
그 다음 '더 자세히 알려드릴까요?' 물어봄."
```

### ❓ 페르소나가 대화 도중 흐트러짐

**해결**: 위 Week 6과 동일 — 매 요청에 시스템 프롬프트 항상 포함.
