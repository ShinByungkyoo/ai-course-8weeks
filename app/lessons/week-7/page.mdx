## 이번 주에 할 일

Week 1~6까지 만든 프롬프트는 **AI Studio 공유 URL**로 다른 사람과 나눴어요. 하지만:

- 접속하려면 **구글 로그인 필요**
- UI는 AI Studio 기본 (내가 커스텀 못함)
- "진짜 웹앱"보단 프롬프트 공유에 가까움

이번 주 **AI Studio의 Get Code** 기능으로 이 한계를 넘습니다. 여러분 프롬프트의 코드를 받아 **CodePen**에 붙여넣으면 진짜 웹페이지가 만들어져요.

### 오늘의 결과물

- 여러분의 챗봇이 심어진 **CodePen 페이지 URL** (예: `codepen.io/yourname/pen/xxxxx`)
- **누구나 로그인 없이 접속** 가능
- UI를 여러분 취향으로 커스텀 가능

## 1단계 개념

### Get Code란?

Google AI Studio에는 **"Get Code"** 버튼이 있어요. 여러분이 만든 프롬프트(System Instructions, Temperature, Tools 등 모든 설정 포함)를 실제로 부를 수 있는 **JavaScript/Python 코드**를 자동 생성해줍니다.

이 코드를 웹페이지에 붙여넣으면 → 여러분 프롬프트가 그 페이지에서 작동합니다.

### CodePen이란?

<a href="https://codepen.io" target="_blank">CodePen</a>은 **브라우저에서 바로 웹페이지를 만들고 공유하는 무료 서비스**예요.

- HTML, CSS, JavaScript를 실시간으로 편집
- 자동으로 공개 URL 발급
- 설치 필요 없음

**AI Studio가 코드를 주고, CodePen이 그 코드를 실행하는 웹페이지 역할**을 합니다.

### API 키 개념

Get Code로 받는 코드에는 `API_KEY` 자리가 있어요. 이건 여러분이 Gemini API를 호출할 수 있는 **열쇠**입니다.

**⚠️ 매우 중요**: API 키는 **비밀번호와 같아요**. 이번 주 마지막 부분에서 안전하게 다루는 법을 배웁니다.

## Step 2. AI Studio에서 프롬프트 준비

<a href="https://aistudio.google.com" target="_blank">aistudio.google.com</a> → 왼쪽 사이드바 **My prompts** → 이한 프롬프트 클릭.

## Step 3. Get Code 실행

편집 화면 상단 오른쪽 근처에 **"Get code"** 또는 **"{'</>'} Code"** 버튼이 있어요. 클릭.

팝업이 뜨면:

- **Language**: JavaScript 선택 (CodePen에서 쓸 것)
- **Framework**: 없음 (또는 Vanilla JS)

**Copy** 버튼으로 코드 복사. 이런 형태의 코드가 나올 거예요:

```javascript
import { GoogleGenAI } from "@google/genai";

async function main() {
  const ai = new GoogleGenAI({ apiKey: "YOUR_API_KEY" });

  const config = {
    systemInstruction: `당신은 조선시대 선비 '이한(李翰)'입니다...`,
    temperature: 0.9,
  };

  const response = await ai.models.generateContent({
    model: "gemini-2.5-flash",
    contents: [{ role: "user", parts: [{ text: "안녕하세요!" }] }],
    config,
  });

  console.log(response.text);
}

main();
```

### JS

```javascript
// Gemini API 키 - Step 1에서 발급받은 걸 여기 붙여넣기
const API_KEY = "여기에_당신의_API_키_붙여넣기";

// System Instructions - AI Studio에서 만든 프롬프트 복사
const SYSTEM_INSTRUCTIONS = `당신은 조선시대 선비 '이한(李翰)'입니다. 
다음 규칙을 반드시 지킵니다.

【언어 규칙】
1. 항상 '~하오', '~구려', '~외다' 같은 하오체를 사용한다.
2. '~합니다', '~해요' 같은 현대어는 절대 쓰지 않는다.
3. 이모지는 절대 사용하지 않는다.

【스타일 규칙】
4. 대답 중 논어, 맹자, 대학, 중용에서 한 구절을 자주 인용한다.
5. 답변 끝에는 짧은 훈계나 인생 조언을 덧붙인다.`;

// 대화 히스토리
const history = [];

// UI 요소
const messagesEl = document.getElementById("messages");
const formEl = document.getElementById("chat-form");
const inputEl = document.getElementById("user-input");
const buttonEl = formEl.querySelector("button");

// 메시지를 화면에 추가
function addMessage(role, text) {
  const div = document.createElement("div");
  div.className = `message ${role}`;
  div.textContent = text;
  messagesEl.appendChild(div);
  messagesEl.scrollTop = messagesEl.scrollHeight;
  return div;
}

// Gemini API 호출
async function callGemini(userText) {
  history.push({ role: "user", parts: [{ text: userText }] });

  const response = await fetch(
    `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${API_KEY}`,
    {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        contents: history,
        systemInstruction: { parts: [{ text: SYSTEM_INSTRUCTIONS }] },
        generationConfig: { temperature: 0.9 },
      }),
    }
  );

  if (!response.ok) {
    const err = await response.text();
    throw new Error(`API 오류: ${response.status} - ${err}`);
  }

  const data = await response.json();
  const answer = data.candidates?.[0]?.content?.parts?.[0]?.text ?? "";

  history.push({ role: "model", parts: [{ text: answer }] });
  return answer;
}

// 폼 제출 처리
formEl.addEventListener("submit", async (e) => {
  e.preventDefault();
  const userText = inputEl.value.trim();
  if (!userText) return;

  addMessage("user", userText);
  inputEl.value = "";
  buttonEl.disabled = true;

  const loadingEl = addMessage("assistant loading", "선비께서 붓을 놀리시는 중이오...");

  try {
    const answer = await callGemini(userText);
    loadingEl.className = "message assistant";
    loadingEl.textContent = answer;
  } catch (err) {
    loadingEl.textContent = `오류가 발생했소: ${err.message}`;
    loadingEl.style.color = "#c33";
  } finally {
    buttonEl.disabled = false;
    inputEl.focus();
  }
});

// 첫 인사말
addMessage("assistant", "허, 반갑구려. 무엇을 물으시려는가?");
```

## ⚠️ API 키 보안 - 매우 중요

CodePen 코드에 API 키를 넣으면 **누구나 페이지 소스에서 볼 수 있어요**. 실전에서는 반드시 서버를 통해야 하지만, 강의용으로는:

### 강의용 임시 방편

- **일일 예산 알림 설정** (필수): Google Cloud Console에서 API 키 프로젝트에 예산 알림 등록. 하루 5,000원 넘으면 이메일 오도록.
- **URL 제한**: <a href="https://aistudio.google.com/app/apikey" target="_blank">API keys 페이지</a>에서 여러분 키 → "Edit" → "HTTP referrer"에 `codepen.io/*` 추가 → 이 도메인에서만 키 사용 가능.
- **강의 끝난 후 키 삭제**: 강의 종료 후 API 키 프로젝트에서 삭제하면 안전.

### 진짜 앱을 만들려면?

**서버**가 필요해요. 이건 Week 8 최종 프로젝트에서 필요하면 안내합니다.

## 자주 발생하는 상황

### ❌ 400 Bad Request 오류

**원인**: API 키가 잘못됨 or 요청 형식 오류.

**해결**:
1. API 키를 다시 복사해서 붙여넣기 (앞뒤 공백 제거).
2. `AIzaSy`로 시작하는지 확인.

### ❌ 403 Forbidden

**원인**: API 키가 유효하지 않거나, HTTP referrer 제한이 CodePen을 막고 있음.

**해결**: 
1. API 키 페이지에서 referrer 설정 확인.
2. `codepen.io/*` 추가 or 제한 해제.

### ❌ 429 Too Many Requests

**원인**: 무료 요금제 한도 초과.

**해결**: Paid tier 확인. 여전히 안 되면 몇 분 대기.

### ❌ CORS 에러

**원인**: 브라우저 정책상 특정 도메인 요청 차단.

**해결**: Gemini API는 CORS를 허용하지만, 만약 오류가 뜨면 CodePen을 **"Full page view"** 모드로 열어서 사용 (Pen 편집기가 아닌 실제 페이지).

### ❌ 응답이 안 옴 / 오래 걸림

**해결**:
1. 네트워크 확인.
2. 콘솔(F12 → Console 탭)에서 오류 메시지 확인.
3. `SYSTEM_INSTRUCTIONS`가 너무 길지 않은지 (5000자 이내 권장).
