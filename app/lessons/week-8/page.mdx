## 이번 주에 할 일

마지막 주. 이번엔 강의 대신 **여러분만의 프로젝트**를 만듭니다.

- 8주간 배운 조각들을 조립해 **여러분에게 진짜 필요한 앱** 완성.
- 커스텀 도메인 붙이기 (예: `myapp.com`).
- SEO, OG 이미지 등 프로덕트다운 마무리.
- SNS·부모님·교수님께 공유.

## Step 1. 아이디어 정하기 (제일 어려움)

**아이디어 없다** 라는 함정에 빠지기 쉬워요. 이렇게 접근하세요.

### 접근 1. 일주일 불편함 목록

지난 일주일간 반복해서 겪은 소소한 불편 5개 이상 나열.

**예시**:
- 논문 요약하는 데 시간이 오래 걸림
- 인스타 캡션 매번 뭐 쓸지 고민
- 스터디원과 일정 조율이 번거로움
- 지출 정리가 귀찮음
- 매일 아침 뉴스 확인 힘듦
- 좋아하는 시 모아둘 곳이 없음
- 학과 공지 놓치기 자주 함

### 접근 2. 배운 걸로 뭐가 가능한가

7주간 배운 기술:

| 기술 | 활용 예시 |
|---|---|
| Week 2 랜딩 | 프로젝트·이벤트 홍보 페이지 |
| Week 3 여러 페이지 | 포트폴리오·블로그·강의 노트 |
| Week 4 폼 | 문의·예약·신청 |
| Week 5 갤러리 | 리스트·카탈로그·아카이브 |
| Week 6 To-Do (localStorage) | 트래커·로그·습관 앱 |
| Week 7 AI API | 챗봇·자동 요약·자동 정리 |

### 접근 3. 원 문장 사용자 가치

이 문장이 나오면 시작할 수 있어요:

> **"[누구]가 [상황]에서 [내 앱]으로 [원하는 결과]를 얻는다."**

**예시**:
- "**대학생**이 **논문 읽을 때** **논문요약봇**으로 **핵심 5분에 파악한다**."
- "**자취생**이 **저녁 고민할 때** **냉장고 셰프**로 **집에 있는 재료로 요리 추천 받는다**."
- "**국문학 학생**이 **좋아하는 시를 아카이브할 때** **시집**으로 **감상평과 함께 저장한다**."

## Step 2. 프로젝트 아이디어 예시

영감을 위한 8개 예시. 그대로 만들어도 되고 응용해도 좋아요.

### 예시 A: 나의 시집 (문학과)

**사용자 가치**: 국문학·문학 애호가가 좋아하는 시를 정리하고 감상평을 남기는 앱.

**사용 기술**:
- Week 5 (카드 갤러리)
- Week 6 (localStorage 저장)
- Week 7 (Gemini로 시의 해설 자동 생성)

**핵심 기능**:
- 시 추가 (제목·시인·본문·감상평)
- 카테고리 태그 (봄·여름·가을·겨울·사랑·이별·자연)
- Gemini에게 "이 시의 문학적 기법 분석해줘" 버튼
- 검색·필터

### 예시 B: 인스타 캡션 도우미

**사용자 가치**: SNS 사용자가 사진에 어울리는 캡션을 3가지 스타일(감성/유머/짧게)로 자동 생성.

**사용 기술**: Week 7 (AI API), 이미지 첨부.

**핵심 기능**:
- 사진 업로드 + 원하는 톤 선택
- Gemini가 캡션 3개 생성
- 해시태그 5개 추천
- 마음에 드는 캡션 클립보드에 복사

### 예시 C: 학습 로그

**사용자 가치**: 매일 공부한 것을 기록하고 시각화.

**사용 기술**: Week 6 (To-Do 패턴), Week 5 (카드).

**핵심 기능**:
- 일별 학습 항목 추가 (과목·시간·요약)
- 통계 (이번 주 총 시간, 과목별 분포 그래프)
- Streak (연속 학습일)
- Gemini에게 "이 로그 기반으로 다음 주 학습 계획 짜줘" 버튼

### 예시 D: 스터디 그룹 페이지

**사용자 가치**: 스터디 리더가 참여자·일정·자료를 한 페이지에 정리해 공유.

**사용 기술**:
- Week 3 (여러 페이지)
- Week 4 (신청 폼 - Formspree)
- Week 5 (구성원 카드)

**핵심 기능**:
- 홈 (스터디 소개, 다음 모임)
- 참여자 (프로필 카드)
- 자료실 (링크 리스트)
- 신청 폼

### 예시 E: 여행 계획 앱

**사용자 가치**: 여행 준비하는 사람이 목적지·일정·짐 목록·예산을 한 곳에서 관리.

**사용 기술**: Week 3, 5, 6.

**핵심 기능**:
- 여행지별 페이지 (일정·짐·예산)
- 짐 체크리스트 (localStorage)
- 예산 트래커
- Gemini에게 "이 목적지 3박 4일 추천 코스" 자동 생성

### 예시 F: 학과 자료 웨이백 머신

**사용자 가치**: 학과 전공 개념을 검색·정리해두는 개인 위키.

**사용 기술**: Week 5 (카드), Week 6 (localStorage).

**핵심 기능**:
- 개념 추가 (제목·정의·예시·관련 개념)
- 검색
- Gemini에게 "이 개념 더 쉽게 설명해줘" 버튼
- 랜덤 개념 뽑기 (복습용)

### 예시 G: AI 자소서 첨삭

**사용자 가치**: 취업 준비생이 자소서 초안을 첨삭받음.

**사용 기술**: Week 7 (Gemini).

**핵심 기능**:
- 자소서 텍스트 입력 + 지원 회사·직무 입력
- Gemini가 3가지 관점 첨삭 (구조·설득력·회사 적합성)
- 개선된 예시 문장 자동 제안
- localStorage에 여러 버전 저장

### 예시 H: 감정 일기

**사용자 가치**: 매일 감정과 있었던 일을 기록하고 패턴 발견.

**사용 기술**: Week 6, 7.

**핵심 기능**:
- 일별 감정(이모지 선택) + 짧은 글
- 캘린더 뷰 (감정별 색으로)
- Gemini에게 "지난 한 달 감정 패턴 분석해줘" 버튼

## Step 3. 실행 순서 (표준 워크플로)

아이디어를 정했다면 이 순서대로 진행하세요.

### 3-1. 스케치 (30분)

종이 또는 Figma에 앱 화면을 그려보세요. 
- 홈 화면
- 주요 페이지 2~3개
- 사용자 흐름 (첫 방문 → 첫 사용 → 재방문)

세밀하게 그리지 마세요. 큰 네모·글자·화살표로 충분.

### 3-2. v0에 시작 프롬프트 (30분)

Week 5·6·7의 프롬프트 예시를 참고해서 여러분 앱의 시작 프롬프트를 만드세요.

포함해야 할 것:
- 앱의 목적 (한 문장)
- 페이지 구조 (라우팅)
- 각 페이지의 기능
- 데이터 구조 (있다면)
- localStorage 사용 여부
- API 호출 여부 (Gemini 등)
- 디자인 톤

**첫 프롬프트는 완벽할 필요 없어요.** 뼈대만 있어도 됩니다. 나머지는 대화로 다듬어요.

### 3-3. 반복 개선 (2~4시간)

v0의 미리보기 → 문제점 발견 → 대화로 요청 → 개선 → 반복.

한 세션에 완성하려 하지 말고 **여러 번에 걸쳐** 만드세요. 지쳤을 때 나온 결과물은 별로예요.

### 3-4. 환경변수 & 배포 (30분)

- API 키가 필요한 앱이면 GEMINI_API_KEY 등록.
- **Publish** → 배포된 URL 확인.
- 시크릿 브라우저에서 로그인 없이 접속 → 잘 작동하는가?

### 3-5. 실사용자 피드백 (1시간)

친구 3명 이상에게 URL 공유. 그들이 사용하는 걸 지켜보거나 반응을 들어보세요:
- 어디서 헷갈렸나?
- 무슨 기능이 필요해 보였나?
- 어떤 느낌이었나?

## Step 4. 커스텀 도메인 연결 (선택, 프로젝트를 프로답게)

기본 URL은 `앱이름.vercel.app`인데, 이걸 `내앱.com` 같은 걸로 바꿀 수 있어요.

### 옵션 A: 짧고 예쁜 vercel 서브도메인 (무료)

Vercel Dashboard → 프로젝트 → **Settings → Domains** → **Edit**.

`ai-course-8weeks-abc123.vercel.app`처럼 긴 걸 `myapp.vercel.app`처럼 짧게 바꿀 수 있어요. **완전 무료**.

### 옵션 B: 개인 도메인 사서 연결 (연 1~3만원)

**진지한 프로젝트라면 추천**.

#### B-1. 도메인 구매

<a href="https://vercel.com/domains" target="_blank">Vercel Domains</a>에서 직접 사면 편해요 (Vercel과 자동 연결). 또는 다음 사이트에서 구매:

- **가비아** (한국) — `.com` 연 15,000원 수준
- **Namecheap** (미국) — `.com` 연 US$11 수준
- **Cloudflare Registrar** — 원가에 가까움 (US$9~10)

한글 도메인(`한국어.com`)도 가능하지만 검색 인덱싱에 불리해서 영문 권장.

#### B-2. Vercel에 연결

Vercel Dashboard → 프로젝트 → **Settings → Domains** → **Add Domain** → 여러분 도메인 입력.

Vercel이 알려주는 DNS 설정을 도메인 판매처(가비아, Namecheap 등)의 DNS 관리 페이지에서 입력하면 자동 연결됩니다.

- **A 레코드**: `76.76.21.21`
- **CNAME**: `cname.vercel-dns.com`

15분 ~ 몇 시간 내에 도메인이 연결됩니다.

## Step 5. 프로덕트로서의 마무리

앱을 좀 더 프로답게 만드는 요소들:

### 5-1. Meta 태그 (SEO)

v0에게:

```
루트 layout에서 metadata를 다음으로 설정해줘:

- title: "[내 앱 이름] - [한 줄 설명]"
- description: "[100자 이내로 앱 설명]"
- openGraph:
  - title, description, url, siteName
  - images: [{ url: "/og-image.png", width: 1200, height: 630 }]
- twitter card: summary_large_image
- viewport: width=device-width, initial-scale=1
- 언어: ko
```

### 5-2. OG 이미지 (SNS 공유 시 미리보기)

카톡·트위터에서 링크 공유할 때 뜨는 예쁜 미리보기 이미지.

```
Next.js App Router의 opengraph-image 규칙을 사용해서 
동적 OG 이미지를 생성해줘.

- app/opengraph-image.tsx 파일
- ImageResponse로 이미지 생성
- 크기: 1200x630
- 배경: 앱의 브랜드 컬러 그라데이션
- 중앙에 큰 앱 이름 + 부제
```

카톡으로 URL 공유 → 예쁜 미리보기가 뜨는 그 순간이 짜릿합니다.

### 5-3. Favicon (탭 아이콘)

브라우저 탭에 뜨는 작은 아이콘:

```
favicon.ico 대신 app/icon.tsx 파일로 
동적 아이콘 생성해줘. 
32x32 크기에 이모지 or 이니셜.
```

### 5-4. 로딩 상태

Next.js의 `loading.tsx`로 페이지 전환 시 자연스러운 로딩:

```
각 라우트에 loading.tsx 추가해서 
페이지 데이터 로딩 시 스켈레톤 UI 표시.
```

### 5-5. Analytics (방문자 통계)

**Vercel Analytics**가 무료로 제공됩니다.

- Vercel Dashboard → 프로젝트 → **Analytics** 탭 → **Enable**.
- 몇 시간 후부터 방문자 수, 페이지별 조회수 등을 볼 수 있어요.

## Step 6. 회고문 쓰기 (필수)

프로젝트의 마지막은 회고입니다. 500자 이내로:

1. **어떤 문제를 해결하고 싶었나?**
2. **8주간 무엇을 배웠나?** (기술적/사고방식/자기 자신에 대해)
3. **뭐가 가장 어려웠나?** (구체적 사례)
4. **뭐가 가장 재미있었나?**
5. **다음에 더 배우고 싶은 것?**

이 회고문을 앱의 About 페이지에 붙여넣어도 좋아요. 프로젝트에 서사가 생깁니다.

## Step 7. 세상에 공개하기 🚀

만들었으면 세상에 알려야죠.

- **오픈채팅**: 관련 관심사 오픈채팅에서 소개.
- **부모님·교수님께**: 직접 링크 보내드리고 반응 듣기.
- **X(Twitter)**: `#내가만든웹앱 #8주완성` 해시태그.
- **LinkedIn**: 취업 준비생이라면 포트폴리오로 첨부.
- **로그레켑드(Read.cv, Polywork)**: 개인 브랜딩 프로필에 프로젝트 추가.
