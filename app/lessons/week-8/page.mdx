## 이번 주에 할 일

마지막 주. 이번엔 강의 대신 **여러분만의 프로젝트**를 만듭니다.

7주 동안 배운 것:
- Week 1~3: AI Studio 기본 (Chat, System Instructions, 프롬프트 관리)
- Week 4: Structured Output (JSON으로 정리)
- Week 5: Vision (이미지 이해)
- Week 6: Tools & Grounding (도구 사용, 실시간 정보)
- Week 7: Get Code로 웹페이지 만들기

이 조각들을 조립해 **여러분에게 진짜 필요한 앱**을 만듭니다.

## Step 1. 아이디어 정하기 (제일 어려움)

### 접근 1. 일주일 불편함 목록

지난 일주일간 반복해서 겪은 소소한 불편 5개 이상 나열.

**예시**:
- 논문 요약이 오래 걸림
- 인스타 캡션 매번 뭐 쓸지 고민
- 가계부 정리 귀찮음
- 자소서 첨삭받을 곳 없음
- 매일 아침 뉴스 챙기기 힘듦
- 시조·한시 공부에 스승이 없음

### 접근 2. 배운 걸로 뭐가 가능한가

| 배운 기술 | 활용 예시 |
|---|---|
| Week 2 페르소나 | 특정 분야 전문가 챗봇 |
| Week 4 Structured Output | 자동 데이터 정리 앱 |
| Week 5 Vision | 사진 분석·설명 앱 |
| Week 6 Tools/Grounding | 최신 정보·리서치 봇 |
| Week 7 CodePen | 진짜 웹페이지로 배포 |

### 접근 3. 한 문장 사용자 가치

> **"[누구]가 [상황]에서 [내 앱]으로 [원하는 결과]를 얻는다."**

**예시**:
- "**대학생**이 **논문 읽을 때** **논문요약봇**으로 **핵심 5분에 파악한다**."
- "**자취생**이 **저녁 고민할 때** **냉장고 셰프**로 **집 재료로 요리 추천 받는다**."

## Step 2. 프로젝트 예시 6개

### 예시 A: 문학 작품 해설 봇 📚

**대상**: 국문학·문학 애호가

- Vision으로 문제집 사진 업로드 or 텍스트 직접 입력
- Structured Output으로 시대적 배경·주제·기법 자동 정리
- Grounding으로 관련 자료 실시간 검색

시작 System Instructions:

```
당신은 국문학 전공 대학원생을 돕는 해설 도우미입니다.
사용자가 시나 짧은 소설 텍스트를 붙여넣으면 다음 순서로 해설합니다.

1. 시대적 배경 (2~3문장)
2. 핵심 주제 (한 문장)
3. 문학적 기법 (구체적으로 3가지)
4. 감상 (진솔한 톤으로 2~3문장)
5. 관련 작품 추천 (제목·저자 3개)

관련 정보가 필요하면 Google Search를 자유롭게 사용하세요.
```

### 예시 B: 인스타 캡션 도우미 📸

Week 5의 여행 사진 캡션 앱을 확장. Vision + Structured Output.

- 사진 업로드 + 원하는 톤 선택 (감성/유머/짧게)
- 3가지 스타일 캡션 자동 생성
- 해시태그 5개 추천
- Get Code로 CodePen에 심어 앱화

### 예시 C: 학습 로그 어시스턴트 📝

- 매일 학습한 내용을 붙여넣으면 카테고리·시간·요약 JSON으로
- 주간 통계 자동 정리
- 다음 주 학습 계획 자동 제안 (Grounding으로 관련 자료 추천)

### 예시 D: AI 자소서 첨삭 ✏️

- 자소서 초안 + 지원 회사/직무 입력
- 3가지 관점 첨삭 (구조·설득력·회사 적합성)
- Grounding으로 지원 회사 최신 뉴스 조사
- 개선 예시 문장 자동 제안

### 예시 E: 냉장고 셰프 🍳

- 냉장고 사진 업로드 (Vision)
- 재료 파악 → 3가지 요리 추천 (Structured Output)
- 조리 시간·난이도·팁 함께
- CodePen으로 배포

### 예시 F: 감정 일기 🌱

- 매일 감정(이모지 선택) + 짧은 글
- 주간·월간 패턴 자동 분석 (Grounding 안 씀, 순수 프롬프트)
- Structured Output으로 감정 통계

## Step 3. 실행 순서

### 3-1. AI Studio에서 프롬프트 완성 (1~2시간)

- System Instructions 작성 & 반복 튜닝.
- Structured Output 스키마 필요하면 정의.
- Vision/Tools/Grounding 필요 기능 켜기.
- 다양한 입력으로 5~10회 테스트.
- **답변이 만족스러울 때까지** 프롬프트 다듬기.

### 3-2. 저장 & 공유 URL 발급 (10분)

- My Prompts에 저장.
- Share → Anyone with the link → Copy link.

### 3-3. Get Code (10분)

- Get Code 버튼 → JavaScript 선택 → Copy.

### 3-4. CodePen에 배포 (1~2시간)

- Week 7 페이지의 HTML/CSS/JS 템플릿을 시작점으로.
- 여러분 프롬프트의 System Instructions 붙여넣기.
- API 키 넣기.
- CSS를 앱 컨셉에 맞게 커스텀.

### 3-5. 실사용자 피드백 (1시간)

- 친구·부모님·교수님에게 링크 공유.
- 실제로 사용해보게 하고 반응 관찰.
- 개선점 정리.

### 3-6. 최종 개선 & 마무리 (1시간)

- 피드백 반영해서 CodePen 재수정.
- README (설명서) 작성.
- 회고문 500자 작성.

## Step 4. 프로덕트 마무리 (선택 심화)

앱을 더 프로답게 만드는 요소들.

### 4-1. 커스텀 도메인 (연 1~3만원)

CodePen만으론 `codepen.io/yourname/pen/xxxxx` URL이에요. **개인 도메인**을 원하면:

1. **도메인 구매**: 가비아, Namecheap 등에서 `myapp.com` 구매.
2. **CodePen Pro** (또는 다른 호스팅) 필요할 수 있음.
3. 또는 **Netlify Drop** (netlify.com/drop)에 HTML 파일 그대로 드래그 → 자동 배포 + 커스텀 도메인 연결.

Netlify 방법:

```
1. CodePen의 Pen에서 Export → ZIP 다운로드.
2. ZIP 안의 dist/index.html 등을 폴더에 정리.
3. netlify.com/drop에 폴더 드래그 → 자동 배포.
4. Netlify 대시보드 → Domain settings → Add custom domain.
```

### 4-2. 파비콘 (탭 아이콘)

HTML의 `<head>`에 추가:

```html
<link rel="icon" href="data:image/svg+xml,<svg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 100 100%22><text y=%22.9em%22 font-size=%2290%22>🎓</text></svg>" />
```

`🎓` 부분을 여러분 앱을 상징하는 이모지로.

### 4-3. Meta 태그 (SNS 공유 미리보기)

HTML `<head>`에 추가:

```html
<meta property="og:title" content="[내 앱 이름]" />
<meta property="og:description" content="[한 줄 설명]" />
<meta property="og:image" content="[미리보기 이미지 URL]" />
<meta property="og:url" content="[내 앱 URL]" />
<meta name="twitter:card" content="summary_large_image" />
```

카톡·트위터에 URL 공유할 때 예쁜 미리보기가 뜹니다.

### 4-4. 사용 안내 표시

앱 상단이나 접힌 영역에 사용법 안내 추가:

```html
<details>
  <summary>💡 사용 방법</summary>
  <ol>
    <li>여행 사진을 업로드하세요.</li>
    <li>원하는 캡션 스타일을 선택하세요.</li>
    <li>[생성하기] 버튼을 누르세요.</li>
    <li>마음에 드는 캡션을 복사해 인스타에 붙여넣기.</li>
  </ol>
</details>
```

## Step 5. 회고문 쓰기 (필수)

500자 이내로 다음을 정리하세요.

1. **어떤 문제를 해결하고 싶었나?**
2. **8주간 무엇을 배웠나?** (기술적/사고방식/자기 자신에 대해)
3. **뭐가 가장 어려웠나?** (구체적 사례)
4. **뭐가 가장 재미있었나?**
5. **다음에 더 배우고 싶은 것?**

## Step 6. 세상에 공개하기 🚀

만들었으면 세상에 알려야죠.

- **인스타그램 스토리**: "8주 동안 배워서 이걸 만들었어요!" + 앱 스크린샷 + URL
- **오픈채팅·디스코드**: 관심사 커뮤니티에서 소개.
- **부모님·교수님께**: 직접 링크 보내드리고 반응 듣기.
- **X(Twitter)**: `#내가만든AI앱 #8주완성` 해시태그.
- **LinkedIn**: 취업 준비생이라면 포트폴리오로 첨부.

## Step 7. 발표 준비 (수업에서 발표한다면)

3~5분 발표 구성:

1. **문제 정의** (30초): 어떤 불편을 왜 나에게 중요했는가.
2. **데모** (2분): 실제 URL 시연.
3. **기술 하이라이트** (1분): 어떤 주차 기술을 어떻게 조합.
4. **어려웠던 점** (30초): 배운 것.
5. **다음 단계** (30초): 더 발전시킨다면.

## 최종 과제

1. **최종 프로젝트 URL** (AI Studio 프롬프트 공유 URL + CodePen 배포 URL).

4. **발표 자료** or **데모 영상** (수업 발표용, 선택).
