## 이번 주에 할 일

드디어 마지막 주. 이번 주는 **여러분만의 앱**을 만듭니다.

7주 동안 프롬프트 짜는 법, AI Studio 활용, v0로 웹앱 만들기, 기능 붙이기까지 다 배웠어요. 이제 그 조각들을 **여러분에게 진짜 필요한 문제**를 해결하는 하나의 앱으로 조립합니다.

### 이번 주 산출물

1. **최종 프로젝트 앱** (공개 URL)
2. **회고문 500자** (배운 것과 다음 목표)
3. **발표 자료 or 데모 영상** (선택)

## Step 1. 아이디어 정하기 (제일 어려움)

앱을 만드는 것보다 **뭘 만들지 정하는 게** 어려워요. 다음 순서로 접근:

### 1-1. 내가 겪는 불편 목록 만들기

일주일 동안 내가 반복적으로 겪는 소소한 불편을 5개 이상 적어보세요:

**예시**:
- 논문 읽을 때 요약이 너무 오래 걸림
- 인스타 캡션 매번 뭐 쓸지 고민
- 가계부 정리하기 귀찮음
- 취업 자소서 첨삭받을 곳이 없음
- 매일 뉴스 챙기기 힘듦
- 시조·한시 공부하려는데 스승이 없음

### 1-2. AI로 해결 가능한지 판단

7주간 배운 기술로 해결할 수 있는지 체크:

- 텍스트 대화? → 챗봇 (Week 2, 6)
- 이미지 이해? → Vision (Week 3, 7)
- 문서 요약? → PDF RAG (Week 7)
- 정형 데이터 정리? → Structured Output (Week 4)
- 최신 정보? → 웹 검색 (Week 7)

### 1-3. 사용자 가치 문장 만들기

한 문장으로 명확하게:

> "[누구]가 [상황]에서 [나의 앱]으로 [원하는 결과]를 얻는다."

예시:
- "**대학생**이 **논문 읽을 때** **논문요약봇**으로 **핵심 5분에 파악한다**."
- "**직장인**이 **점심 고민할 때** **오늘의 점심 큐레이터**로 **재밌게 결정한다**."
- "**엄마**가 **밥 짓기 힘들 때** **냉장고 셰프**로 **집에 있는 재료로 요리 추천받는다**."

이 한 문장이 나오면, 그 뒤는 만드는 일만 남았어요.

## Step 2. 실전 프로젝트 예시 5개

영감을 위한 예시들. 그대로 만들어도 되고, 응용해도 좋아요.

### 예시 A: 문학 작품 해설 챗봇 📚

**대상**: 국문학·문학 전공 학생

**기능**:
- 시나 짧은 소설 텍스트를 붙여넣거나 PDF 업로드.
- AI가 시대적 배경, 핵심 주제, 문학적 기법을 해설.
- 학생 눈높이로 설명 + 관련 시험 예상 문제 생성.

**사용 기술**: 
- Week 2 (페르소나 - "문학 교수님")
- Week 4 (구조화 출력 - 해설 섹션 자동 나누기)
- Week 7 (PDF 업로드)

**시작 프롬프트** (v0에):
```
문학 작품 해설 챗봇 웹앱. 
사용자가 시/소설 텍스트를 붙여넣거나 PDF 업로드하면, 
AI가 다음 4가지를 자동 정리:
1. 시대적 배경
2. 핵심 주제
3. 사용된 문학적 기법
4. 이 작품 관련 시험 예상 문제 3개

디자인: 도서관 열람실 느낌. 크림 배경, 세리프 폰트, 
차분한 브라운 포인트.
```

### 예시 B: 냉장고 셰프 🍳

**대상**: 요리 초보자, 자취생

**기능**:
- 냉장고 사진 업로드.
- AI가 재료 파악 후 만들 수 있는 요리 3가지 제안.
- 각 요리의 조리 시간, 난이도, 팁 함께 제공.

**사용 기술**:
- Week 3 (이미지 이해)
- Week 4 (구조화 출력)

**시작 프롬프트**:
```
냉장고 셰프 웹앱. 
사용자가 냉장고 안 사진을 업로드하면, 
AI가 재료를 파악하고 3가지 요리를 표 형식으로 추천.
각 요리마다 조리 시간, 난이도(★1~5), 
초보자 실패 방지 팁 포함.

디자인: 밝고 캐주얼한 톤. 
아이보리 배경, 오렌지·초록 포인트.
```

### 예시 C: 하루 명언 서비스 🌅

**대상**: 자기계발 관심 있는 누구나

**기능**:
- 매일 새로운 명언 생성 (오늘 날짜 기반).
- 사용자의 기분에 맞춰 명언 추천.
- 그 명언을 이미지 카드로 만들어 다운로드.

**사용 기술**:
- Week 2 (톤 세팅)
- Week 5 (v0 UI)

### 예시 D: 인스타 캡션 생성기 📸

**대상**: SNS 활발히 하는 학생

**기능**:
- 사진 업로드 + 자기 스타일 선택 (감성/유머/시크).
- 각 스타일별로 캡션 3개씩 생성.
- 해시태그도 추천.

**사용 기술**:
- Week 3 (이미지 이해)
- Week 5 (탭 UI)

### 예시 E: 자기소개서 첨삭 도우미 📝

**대상**: 취업 준비생

**기능**:
- 자기소개서 초안 붙여넣기.
- 지원 회사/직무 입력.
- AI가 3가지 관점에서 첨삭 (구조, 임팩트, 회사 적합성).
- 개선 예시 함께 제공.

**사용 기술**:
- Week 2 (전문가 페르소나)
- Week 4 (구조화 답변)
- Week 7 (긴 텍스트 처리)

## Step 3. 프로젝트 실행 순서

아이디어 정해지면 이 순서대로 진행:

### 3-1. AI Studio에서 프롬프트 다듬기 (30분~1시간)

먼저 **AI Studio에서 시스템 프롬프트를 완벽하게** 만드세요. 답변이 정확히 원하는 대로 나올 때까지.

시스템 프롬프트가 좋지 못하면 v0로 앱을 아무리 예쁘게 만들어도 소용없어요.

### 3-2. v0에 앱 뼈대 요청 (30분)

Step 2의 시작 프롬프트를 참고해서 v0에게 첫 요청. 완벽하지 않아도 OK.

### 3-3. UI 다듬기 (1~2시간)

v0와 계속 대화하며 화면 개선:
- 색깔·폰트·간격
- 반응형 확인 (폰에서도 예쁜지)
- 로딩·에러 상태 처리

### 3-4. API 키 연결 & 배포 (30분)

- Gemini API 키 환경변수 등록
- Deploy → 공개 URL 발급
- 실제 배포 URL에서 정상 작동 확인

### 3-5. 실사용자 피드백 (1시간)

친구 3명에게 URL 공유하고 사용해보게 하세요. 그들의 반응·건의사항을 받으세요:
- 뭐가 헷갈리는지
- 어디서 막히는지
- 기대와 다른 결과는 뭐였는지

### 3-6. 최종 개선 (1~2시간)

피드백을 반영해서 v0에게 마지막 개선 요청 → 재배포.

## Step 4. 도메인 예쁘게 만들기 (선택)

기본 URL은 `https://앱이름-abc123.vercel.app` 같은 형식. 이걸 예쁘게 바꾸고 싶다면:

### 옵션 A: Vercel 서브도메인 변경 (무료)

Vercel Dashboard → 프로젝트 선택 → **Settings → Domains** → **Edit** → 원하는 이름으로 변경 (예: `refrigerator-chef.vercel.app`).

### 옵션 B: 개인 도메인 연결 (연 1~3만원)

가비아, Cloudflare 등에서 도메인을 사고 (예: `my-app.com`), Vercel의 Domains 설정에서 연결. 초보자에겐 옵션 A로 충분.

## Step 5. 회고문 쓰기

500자 이내로 다음을 정리하세요:

1. **어떤 문제를 해결하고 싶었나요?** (배경, 동기)
2. **8주간 무엇을 배웠나요?** (기술적/사고방식)
3. **뭐가 가장 어려웠나요?** (구체적 사례)
4. **뭐가 가장 재미있었나요?**
5. **다음에 더 배우고 싶은 것?** (파이썬? 다른 도구? 특정 도메인?)

이 회고문은 앱의 `About` 페이지나 홈에 붙여넣어도 좋아요.

## Step 6. 발표 준비 (수업에서 발표한다면)

3~5분 발표 구성 추천:

1. **문제 정의** (30초): 어떤 불편함? 왜 나에게 중요?
2. **데모** (2분): 배포된 URL로 실제 시연.
3. **기술 하이라이트** (1분): 어떤 주차 기술을 어떻게 조합?
4. **어려웠던 점** (30초): 배운 것.
5. **다음 단계** (30초): 더 발전시킨다면?

**슬라이드는 Canva나 Google Slides로 10분 안에** 만드세요. 발표 내용이 훨씬 중요합니다.

## Step 7. 세상에 공개하기 🚀

완성했다면 진짜로 공유해보세요:

- **인스타그램**: "8주 동안 배운 것, 이걸 만들었어요" + URL
- **오픈채팅·디스코드**: 관심사 커뮤니티에서 피드백 받기
- **부모님·교수님께**: 직접 사용하시게 해보기
- **X(Twitter)**: `#내가만든AI앱` 해시태그와 함께
- **LinkedIn**: 취업 준비생이라면 포트폴리오로

**여러분이 만든 앱은 진짜 앱입니다.** 세상 어디서든 접속 가능하고, 실제로 유용해요. 자랑하지 않으면 손해예요.
