## 이번 주에 무엇을 배우나요?

컴퓨터에 **AI 앱을 만들 수 있는 환경**을 세팅합니다. 그리고 진짜 짧은 10줄짜리 파이썬 프로그램으로 **Gemini(구글의 AI)와 첫 대화**를 해봅니다.

솔직히 말씀드리면, 이번 주는 가장 지루하지만 가장 중요한 주차입니다. 여기서 세팅한 환경을 8주 내내 쓰기 때문이에요. 딱 오늘만 참고 따라오세요.

### 오늘 만들 프로그램 미리보기

터미널에서 `python hello_ai.py`를 실행하면 이런 결과가 나옵니다:

```
👉 나: 세종대왕이 만든 것 세 가지만 알려줘.
🤖 AI: 세종대왕이 만든 대표적인 것 세 가지는 다음과 같습니다.
1. 훈민정음(한글) — 백성이 쉽게 배울 수 있도록 만든 한국 고유 문자입니다.
2. 측우기 — 세계 최초로 강수량을 재는 도구를 만들었습니다.
3. 앙부일구(해시계) — 시간을 정확히 측정할 수 있는 해시계입니다.
```

## 준비물 체크리스트

- ☑️ 노트북 (Windows 10/11 또는 macOS)
- ☑️ 인터넷 연결
- ☑️ 구글 계정 (Gemini API 키 발급용, 학교 이메일이든 개인 이메일이든 OK)
- ☑️ **결제 가능한 신용카드** (Gemini 유료 요금제 등록용 — 이번 강의에서 총 몇천 원 정도 나옵니다)

> ⚠️ **중요**: 신용카드가 없으면 부모님이나 지도교수님께 여쭤보세요. Gemini의 무료 요금제도 있긴 하지만, 수업 중 갑자기 "quota exceeded" 오류가 나서 진행이 멈추는 경우가 많아 유료로 진행합니다. 하루 100원~500원 정도의 소액이 나옵니다.

## Step 1. Python 설치하기

Python(파이썬)은 AI 앱을 만들 때 가장 많이 쓰는 프로그래밍 언어입니다. 뱀 그림 아이콘이 특징이에요. 🐍

### Windows 사용자

1. 웹 브라우저에서 <a href="https://www.python.org/downloads/" target="_blank">python.org/downloads</a>에 접속합니다.
2. 노란색 **"Download Python 3.12.x"** 버튼을 클릭합니다. (버전 숫자는 조금 다를 수 있어요. 3.10 이상이면 OK)
3. 다운로드된 `.exe` 파일을 **더블클릭**합니다.
4. **⚠️ 절대 놓치지 마세요**: 설치 창 아래쪽 **"Add python.exe to PATH"** 체크박스를 반드시 체크합니다.
5. **"Install Now"** 클릭 → 설치 완료까지 기다립니다.

> 💡 **PATH가 뭐길래 그렇게 강조하나요?** 컴퓨터에게 "python이라는 명령어가 어디에 있는지" 알려주는 목록이에요. 체크 안 하면 나중에 `'python'은 내부 또는 외부 명령이 아닙니다`라는 오류가 뜹니다. 이미 놓쳤다면 파이썬을 삭제하고 다시 설치하는 게 제일 빠릅니다.

### macOS 사용자

Mac에는 이미 오래된 Python이 있지만, 강의용으로 최신 버전을 다시 설치합니다.

1. <a href="https://www.python.org/downloads/" target="_blank">python.org/downloads</a>에 접속.
2. **"Download Python 3.12.x"** 클릭 → `.pkg` 파일 다운로드.
3. 파일을 더블클릭 → 안내대로 **"계속" → "설치"** 클릭.

### 설치 확인

설치가 잘 됐는지 확인합니다.

**Windows**: 시작 메뉴에서 "cmd" 검색 → **명령 프롬프트** 실행.
**macOS**: `⌘ + Space` → "terminal" 검색 → **터미널** 실행.

검은 창이 뜨면 아래 명령어를 그대로 타이핑하고 `Enter`를 누릅니다:

```bash
python --version
```

이런 결과가 나오면 성공입니다:

```
Python 3.12.10
```

> 🆘 **"python is not recognized" 오류가 나면?** Windows에서 PATH 체크박스를 놓친 경우입니다. 파이썬을 [프로그램 추가/제거]에서 삭제하고, 위 Step 1을 처음부터 다시 하세요. Mac에서 안 되면 `python3 --version`으로 시도해보세요.

## Step 2. VS Code 설치하기

VS Code(비주얼 스튜디오 코드)는 **코드 편집기**입니다. 메모장 같은 것인데, 프로그래밍용으로 훨씬 편리한 기능이 많아요.

1. <a href="https://code.visualstudio.com/" target="_blank">code.visualstudio.com</a> 접속.
2. 큰 파란 버튼 **"Download for Windows"** (또는 Mac) 클릭 → 설치.
3. Windows 설치 중 나오는 옵션 중 **"코드에서 열기"** 관련 체크박스 3개는 다 켜두세요. 나중에 편해요.

### Python 확장 설치

VS Code를 처음 열면 왼쪽 세로 메뉴에 여러 아이콘이 보입니다. 그중 **네모 네 개짜리 아이콘(확장)**을 클릭하세요. 검색창에 **"Python"**을 입력하고, Microsoft가 만든 첫 번째 결과를 **Install** 버튼으로 설치합니다.

## Step 3. 터미널이 뭔가요?

**터미널(Terminal) = 컴퓨터에게 명령어로 대화하는 검은 창**입니다. 마우스로 클릭하는 대신 글자를 쳐서 파일을 만들고, 프로그램을 실행합니다.

프로그래머는 마우스보다 키보드가 빨라서 이 방식을 씁니다. 여러분도 곧 익숙해질 거예요.

가장 많이 쓸 명령어 3개만 기억하세요:

| 명령어 | 뜻 |
|---|---|
| `cd 폴더이름` | 그 폴더 안으로 이동 (change directory) |
| `dir` (Windows) / `ls` (Mac) | 현재 위치의 파일·폴더 목록 보기 |
| `python 파일이름.py` | 그 파이썬 파일 실행 |

## Step 4. 프로젝트 폴더 만들기

이 강의에서 만드는 모든 코드를 한 곳에 모아둡시다.

1. **바탕화면(Desktop)**에서 마우스 오른쪽 클릭 → 새 폴더 → 이름을 `ai-course`로 짓습니다.
2. VS Code를 열고, 상단 메뉴 **File → Open Folder** → 방금 만든 `ai-course` 폴더 선택.
3. "Do you trust the authors of the files in this folder?" 라는 창이 뜨면 **"Yes, I trust..."** 클릭.

VS Code에서 이 폴더가 왼쪽에 표시되면 성공입니다.

### VS Code에서 터미널 열기

VS Code 상단 메뉴 **Terminal → New Terminal**을 클릭하면 VS Code 안쪽 아래에 검은 창이 생깁니다. 이게 터미널이에요. 앞으로 명령어는 여기에 입력합니다.

> 💡 **Windows 사용자 팁**: 터미널 오른쪽 위에 `PowerShell`이나 `cmd`로 표시된 드롭다운이 있어요. 강의는 `PowerShell` 기준으로 진행합니다. 그냥 기본값 그대로 두면 됩니다.

## Step 5. 가상환경(venv) 만들기

**가상환경**은 "이 프로젝트만을 위한 격리된 파이썬 공간"입니다. 왜 필요할까요?

- 프로젝트 A는 라이브러리 X의 1.0버전이 필요한데,
- 프로젝트 B는 X의 2.0버전이 필요하면?

가상환경이 없으면 서로 충돌합니다. 각 프로젝트마다 venv를 만들면 이 문제가 해결돼요. **모든 파이썬 프로젝트에서 항상 하는 표준 관행**입니다.

VS Code 터미널에 아래 명령어를 입력하세요:

```bash
python -m venv .venv
```

몇 초 후 아무 메시지 없이 프롬프트가 돌아오면 성공. `ai-course` 폴더 안에 `.venv`라는 새 폴더가 생겼을 거예요.

### 가상환경 활성화

만든 가상환경을 "지금 사용하겠다"고 알려줘야 합니다. 이걸 **활성화(activate)**라고 해요.

**Windows PowerShell**:

```powershell
.venv\Scripts\Activate.ps1
```

**macOS / Linux**:

```bash
source .venv/bin/activate
```

프롬프트 앞에 `(.venv)`가 붙으면 활성화 성공입니다. 이렇게요:

```
(.venv) PS C:\Users\student\Desktop\ai-course>
```

> 🆘 **Windows에서 "이 시스템에서 스크립트를 실행할 수 없으므로..."라는 오류가 나면?** PowerShell을 관리자 권한으로 다시 열고 아래 명령어를 실행한 뒤, 원래 창으로 돌아와서 다시 시도하세요.
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
> ```
> "Yes to All"에 해당하는 `A`를 눌러 확인.

> 💡 **매번 다시 활성화해야 하나요?** 네, VS Code나 터미널을 닫았다 열면 다시 활성화해야 합니다. 프롬프트 앞에 `(.venv)`가 있는지 항상 확인하세요.

## Step 6. Gemini 라이브러리 설치

이제 파이썬에서 Gemini AI를 쓸 수 있는 라이브러리를 설치합니다. `(.venv)`가 붙은 터미널에서:

```bash
pip install google-genai python-dotenv
```

`pip`는 "파이썬 라이브러리 설치 도구"입니다. 위 명령어는 두 가지를 한꺼번에 설치해요:

- **google-genai**: Gemini API를 파이썬에서 부르는 공식 라이브러리
- **python-dotenv**: API 키 같은 비밀 정보를 파일로 관리하는 유틸리티

`Successfully installed ...`라는 초록 글씨가 마지막에 나오면 성공.

## Step 7. Gemini API 키 발급 (⭐ 이번 주의 핵심 ⭐)

이제 대망의 API 키를 발급받습니다. **API 키 = AI 서비스를 쓸 수 있는 열쇠**라고 생각하세요.

### 7-1. Google AI Studio 접속

<a href="https://aistudio.google.com/" target="_blank">aistudio.google.com</a>에 접속해 구글 계정으로 로그인합니다.

### 7-2. API 키 생성

1. 왼쪽 사이드바 아래쪽 **"Get API key"** 클릭.
2. **"Create API key"** 버튼 클릭.
3. 프로젝트를 선택하라고 하면, 기본으로 뜨는 프로젝트를 그대로 선택.
4. 잠시 후 `AIzaSy...`로 시작하는 긴 문자열이 나옵니다. **이게 여러분의 API 키**예요.
5. 오른쪽 복사 아이콘을 눌러 복사하고, **메모장에 임시로 붙여넣어 두세요**.

> ⚠️ **경고**: API 키는 비밀번호와 같습니다. 절대로 다음 세 가지를 하지 마세요:
> - SNS에 스크린샷 올리기
> - GitHub에 그대로 올리기
> - 다른 사람에게 공유하기
>
> 유출되면 누가 여러분 이름으로 Gemini를 마구 쓰고, 요금이 나옵니다. 만약 실수로 유출됐다면, 같은 페이지에서 즉시 **"Delete"** 하고 새로 만드세요.

### 7-3. 유료 요금제 등록 (Billing 활성화)

무료 요금제는 하루 사용량이 매우 적어 수업에 부족합니다. 유료로 전환합니다.

1. <a href="https://aistudio.google.com/app/apikey" target="_blank">API keys 페이지</a>에서 방금 만든 키의 **프로젝트 이름**을 클릭.
2. **"Set up billing"** 또는 **"Upgrade"** 버튼 → Google Cloud Billing 페이지로 이동.
3. **결제 계정 만들기** → 국가, 계정 유형(개인), 신용카드 정보 입력.
4. 다시 AI Studio로 돌아와 몇 분 뒤 새로고침 → "Paid tier" 표시가 뜨면 완료.

> 💰 **얼마나 나오나요?** Gemini 2.5 Flash 기준, 이 강의 전체를 진행해도 **약 3천~5천 원** 수준입니다. 걱정 마세요. 예산 초과가 걱정된다면 Google Cloud 콘솔에서 **"Budget alerts"**로 하루 1,000원 알림을 걸어두면 안심입니다.

## Step 8. API 키를 안전하게 저장하기

API 키를 코드에 직접 쓰면 실수로 유출되기 쉽습니다. 대신 `.env`라는 별도 파일에 저장하고, 코드는 그 파일에서 읽어옵니다.

### 8-1. .env 파일 만들기

VS Code 왼쪽 파일 탐색기에서 **New File** 아이콘을 클릭하고, 파일 이름을 정확히 **`.env`** (점으로 시작)로 만듭니다.

파일 안에 다음 한 줄만 입력하고 저장(`Ctrl+S` / `⌘+S`):

```env
GEMINI_API_KEY=AIzaSy여러분의_실제_키를_붙여넣기
```

`=` 뒤에 아까 복사해둔 API 키를 그대로 붙여넣으세요. 따옴표 없이, 공백 없이.

### 8-2. .gitignore 만들기

나중에 GitHub에 코드를 올릴 때 `.env` 파일이 실수로 같이 올라가면 큰일입니다. 미리 방지 파일을 만들어둡시다.

새 파일 이름 **`.gitignore`**:

```gitignore
.env
.venv/
__pycache__/
*.pyc
```

이렇게 하면 Git이 이 파일들을 절대 업로드하지 않습니다.

## Step 9. 첫 AI 프로그램 작성하기 🎉

드디어 코드를 씁니다. VS Code에서 새 파일 **`hello_ai.py`**를 만들고, 아래 코드를 그대로 복사·붙여넣기 하세요.

```python filename="hello_ai.py"
import os
from dotenv import load_dotenv
from google import genai

# .env 파일에서 API 키 불러오기
load_dotenv()

# Gemini 클라이언트 준비
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

# AI에게 질문 보내기
질문 = "세종대왕이 만든 것 세 가지만 알려줘."
응답 = client.models.generate_content(
    model="gemini-2.5-flash",
    contents=질문,
)

# 결과 출력
print(f"👉 나: {질문}")
print(f"🤖 AI: {응답.text}")
```

### 한 줄씩 뜯어보기

- `import ...`: 다른 사람이 만든 도구를 가져다 씁니다. `os`(환경변수 읽기), `dotenv`(.env 파일 로드), `genai`(Gemini).
- `load_dotenv()`: `.env` 파일을 읽어서 컴퓨터에 잠시 등록해둡니다.
- `genai.Client(...)`: Gemini와 통신할 창구를 엽니다. API 키를 여기에 전달합니다.
- `generate_content(...)`: 실제로 AI에게 질문을 보냅니다. `model="gemini-2.5-flash"`는 사용할 AI 모델 이름이에요.
- `응답.text`: 돌아온 답변의 텍스트 부분만 꺼내옵니다.

> 💡 **파이썬 변수명에 한글?** 네, 파이썬은 한글 변수명도 지원합니다. 이번 주만 이해를 돕기 위해 한글로 썼어요. 다음 주부터는 영어 관례를 따를게요.

## Step 10. 실행하기 🏃

터미널(`(.venv)` 붙어있는지 다시 확인)에서:

```bash
python hello_ai.py
```

`Enter`를 누르고 2~5초 기다리면… 짜잔! AI의 답변이 나타납니다.

```
👉 나: 세종대왕이 만든 것 세 가지만 알려줘.
🤖 AI: 세종대왕이 만든 대표적인 것 세 가지는 다음과 같습니다.
1. 훈민정음 — ...
```

**축하합니다! 여러분은 방금 AI 앱을 만들었습니다.** 🎉

## 자주 발생하는 오류와 해결법

### ❌ `ModuleNotFoundError: No module named 'google'`

**원인**: 가상환경이 활성화되지 않은 채 `pip install`을 했거나, 다른 터미널에서 실행 중.

**해결**: 터미널 앞에 `(.venv)`가 있는지 확인. 없으면 `.venv\Scripts\Activate.ps1` (Mac은 `source .venv/bin/activate`)로 다시 활성화 후, `pip install google-genai python-dotenv`를 다시 실행.

### ❌ `KeyError: 'GEMINI_API_KEY'`

**원인**: `.env` 파일이 없거나, 이름이 틀렸거나, 안에 `GEMINI_API_KEY=`가 없음.

**해결**: 
1. `.env` 파일이 `hello_ai.py`와 **같은 폴더**에 있는지 확인.
2. 파일 이름이 정확히 `.env`인지 확인. (앞에 점이 있어야 함)
3. 파일 안에 `GEMINI_API_KEY=AIzaSy...` 형식으로 되어 있는지 확인.

### ❌ `google.api_core.exceptions.PermissionDenied: 403 API key not valid`

**원인**: API 키가 잘못 복사되었거나, Google Cloud 프로젝트에 Generative Language API가 활성화되지 않음.

**해결**: 
1. `.env`의 키에 공백이나 줄바꿈이 섞이지 않았는지 확인.
2. <a href="https://aistudio.google.com/app/apikey" target="_blank">API keys 페이지</a>에서 키를 새로 발급받아 교체.

### ❌ `Quota exceeded` 또는 `429 Resource has been exhausted`

**원인**: 무료 요금제 한도 초과.

**해결**: Step 7-3을 다시 확인해 유료 요금제로 전환.
