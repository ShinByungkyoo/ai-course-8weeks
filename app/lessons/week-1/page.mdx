## 이번 주에 할 일

지금 여러분이 보고 있는 이 강의 사이트도 **웹페이지**입니다. 오늘 우리도 이런 웹페이지를 하나 만들어봅시다. **딱 5분이면 됩니다.**

준비물은 노트북과 브라우저 하나. 파이썬도, 코드 편집기도, 터미널도 필요 없어요.

### 이번 주 결과물 미리보기

- 여러분의 첫 웹페이지 (예: "안녕! 나는 김지은이야!")
- 세상 누구나 접속 가능한 **공개 URL** (예: `https://hello-jieun.vercel.app`)
- 이 URL을 카톡으로 친구에게 보내면 → 친구가 여러분의 페이지를 봄

## 웹페이지가 뭔가요? (3분 개념)

이 부분은 후딱 지나가고 실습으로 넘어갑니다.

### URL

여러분이 카카오톡에서 "네이버 봐봐"라며 링크를 보낼 때 그 링크가 바로 URL입니다.

```
https://www.naver.com
```

- `https://` — 안전한 연결이라는 표시
- `www.naver.com` — 어느 컴퓨터(서버)에 접속할지 알려주는 주소

이 주소로 들어가면 그 회사의 컴퓨터가 여러분에게 "화면을 그리는 지도"(HTML)를 보내주고, 브라우저가 그걸 화면에 그려주는 겁니다.

### 웹페이지 vs 웹사이트

- **웹페이지**: 한 장의 화면 (예: `naver.com/main`)
- **웹사이트**: 여러 페이지를 묶은 것 (예: naver.com 전체)

오늘은 **한 장짜리 웹페이지** 하나만 만듭니다. Week 3에서 여러 페이지짜리 웹사이트로 발전시킬 거예요.

### 웹페이지를 만드는 방법

전통적으로는 **HTML, CSS, JavaScript**라는 세 언어를 배워서 코드를 직접 씁니다. 하지만 우리는 **v0.dev**라는 도구를 씁니다. 한국어로 "이런 페이지 만들어줘" 하면 v0가 저 세 언어로 대신 코드를 짜줍니다.

## Step 1. v0.dev 접속과 가입

브라우저(Chrome, Edge 등) 주소창에 이 주소를 입력하세요:

```
v0.dev
```

또는 이 링크 클릭: <a href="https://v0.dev" target="_blank">**v0.dev**</a>

### 1-1. Sign in 클릭

화면 오른쪽 위에 **"Sign in"** 또는 **"Log in"** 버튼이 있어요. 클릭.

### 1-2. Continue with Google

여러 로그인 옵션 중 **"Continue with Google"**을 선택합니다. GitHub 계정이 있다면 GitHub도 OK, 하지만 대부분 학생은 구글로.

### 1-3. 여러분 구글 계정 선택 후 승인

- 여러분의 구글 계정 클릭.
- v0.dev가 요청하는 권한을 확인 후 **"Continue"**.

### 1-4. 팀 이름 정하기

첫 로그인이라면 "Choose a team name" 같은 화면이 뜹니다.

- 여러분 이름이나 별명을 입력 (예: `jieun-studio`, `min-projects`).
- 나중에도 변경 가능하니 대충 정해도 OK.

### 1-5. 요금제 선택

**"Free"**를 선택하세요. 이번 강의는 Free 플랜으로 충분히 진행 가능합니다.

> ⚠️ Free 플랜은 하루 크레딧 제한이 있어요 (보통 하루 5~10회 새 생성). 실습이 막히면 다음 날 재시도. 급하면 Pro로 업그레이드도 가능하지만 강의 중엔 필요 없어요.

## Step 2. v0.dev 화면 둘러보기

로그인 후 v0 화면이 뜹니다. 다음이 보일 거예요:

- **가운데**: 커다란 입력창. 여기에 만들고 싶은 걸 입력합니다.
- **아래**: 예시 프롬프트 몇 개 (참고용).
- **왼쪽/오른쪽 상단**: 프로젝트 목록, 프로필 등.

## Step 3. 첫 웹페이지 만들기 🎉

가운데 입력창에 이 문장을 정확히 붙여넣기 하세요:

```
"안녕! 나는 김지은이야" 라고 크게 표시되는 간단한 웹페이지 만들어줘.

디자인:
- 화면 정중앙에 큰 글씨로 인사말
- 그 아래 작은 글씨로 오늘 날짜
- 배경은 은은한 하늘색 그라데이션
- 폰트는 부드럽고 둥근 느낌
- 폰에서 봐도 예쁘게

인사말의 "김지은" 부분은 나중에 내 이름으로 바꿀 수 있게 잘 표시해줘.
```

> 💡 이름은 여러분 이름으로 바꿔서 입력하세요. 지금은 예시입니다.

입력창 아래쪽 **화살표 버튼(▲)** 또는 `Enter` 키를 누르세요.

### 잠시 기다리기

v0가 페이지를 생성 중이라는 표시가 뜹니다. 30초~2분 정도 기다립니다.

### 미리보기 확인

오른쪽에 **실제 웹페이지 미리보기**가 나타나요. 여러분이 요청한 대로:

- 커다란 인사말이 화면 정중앙
- 아래에 날짜
- 하늘색 그라데이션 배경

**이미 웹페이지가 만들어졌습니다.** 🎉

## Step 4. 마음에 안 들면 대화로 수정

한 번에 완벽하게 안 나올 수도 있어요. 같은 대화창에서 계속 요청하세요.

예시 요청들:

```
글씨를 좀 더 크게 해줘.
```

```
배경을 하늘색이 아니라 연한 핑크로 바꿔줘.
```

```
인사말 옆에 손 흔드는 이모지 👋를 추가해줘.
```

```
화면 하단에 "환영합니다"라는 작은 문구도 추가해줘.
```

**한국어로 자연스럽게 부탁하면 v0가 알아서 이해합니다.** 마치 디자이너에게 카톡하는 것 같아요.

### 대화 흐름 예시

만족스러운 페이지가 나올 때까지 5~10번 정도 대화 → 미리보기가 계속 업데이트됨.

## Step 5. Publish - 인터넷에 공개하기 🌍

미리보기가 만족스러우면, 이제 세상에 공개할 시간입니다.

### 5-1. Publish 버튼 찾기

미리보기 창 오른쪽 위 근처에 **"Publish"** 버튼이 있어요. (또는 **"Deploy"**, v0 버전에 따라 다를 수 있음)

클릭!

### 5-2. 프로젝트 이름 정하기

Publish 팝업이 뜨면 프로젝트 이름을 물어봐요. 예: `my-first-page`, `hello-jieun`.

- 영문 소문자, 숫자, 하이픈(-)만 사용.
- 짧고 기억하기 쉽게.

**"Publish"** 또는 **"Deploy"** 클릭.

### 5-3. 30초~1분 기다림

배포 진행 상태 바가 표시됩니다. 잠시 후:

```
✅ Deployed successfully
```

와 함께 URL이 뿌려집니다. 이런 형태:

```
https://my-first-page.vercel.app
```

또는:

```
https://my-first-page-abc123.vercel.app
```

**🎉 여러분의 첫 웹페이지가 인터넷에 공개됐습니다!**

## Step 6. URL을 다양한 곳에서 열어보기

방금 발급된 URL을 여러 곳에서 확인해보세요:

### 6-1. 다른 브라우저에서

Chrome을 썼다면 Edge나 Safari로. **로그인 없이도** 페이지가 뜨는지 확인.

### 6-2. 스마트폰에서

카톡으로 URL을 여러분 자신에게 보내고, 폰에서 열어보세요.

### 6-3. 시크릿 모드에서

Chrome이면 `Ctrl + Shift + N` (Mac: `Cmd + Shift + N`) → 새 시크릿 창 → URL 붙여넣기.

**셋 다 잘 뜨면** 진짜 인터넷 어디서든 접속 가능하다는 뜻이에요. 축하합니다!

### 6-4. 친구에게 공유 🤗

카톡·문자·인스타 DM으로 URL 보내세요. 친구가 열면 여러분의 페이지가 뜹니다.

## Step 7. 대시보드에서 프로젝트 관리

v0의 **왼쪽 상단 로고** 클릭 → 대시보드로 이동. 여러분이 만든 프로젝트 목록이 보입니다.

각 프로젝트 카드를 클릭하면 편집을 이어갈 수 있어요. 여러 개 앱을 만들면 여기서 관리합니다.

## 자주 발생하는 상황

### ❓ v0가 영어로 답변만 함

**해결**: 프롬프트 마지막에 `모든 화면 텍스트는 한국어로 작성해줘.`라고 명시.

### ❓ 미리보기가 하얗게만 나옴 / 아무것도 안 보임

**원인**: v0가 코드 생성 중 오류.

**해결**: 미리보기 화면에 **"Fix errors"** 버튼이 뜨면 클릭. 안 뜨면 v0에게: `아무것도 안 보여. 코드에 오류가 있으면 수정해줘.`

### ❓ Publish가 실패함

**원인**: v0 서버 일시적 오류이거나 코드 문제.

**해결**:
1. 잠시 기다린 후 재시도.
2. `Fix errors` 시도.
3. 그래도 안 되면 새 채팅에서 처음부터 다시 요청.

### ❓ Free 플랜 크레딧 소진

**해결**: 24시간마다 리셋되니 다음 날 재시도. 급하면 Pro 플랜 고려.

### ❓ Publish 후 URL이 404를 반환함

**원인**: 배포 진행 중일 수 있음.

**해결**: 1~2분 기다린 후 다시 접속. 그래도 404면 v0 대시보드에서 배포 상태 확인.

## 이번 주 정리

여러분은 오늘:

1. 웹페이지가 무엇인지 이해했고
2. v0.dev 계정을 만들었고
3. 한국어로 부탁만 해서 **진짜 웹페이지**를 만들었고
4. **공개 URL**로 세상에 공개했습니다

이 흐름 — **부탁 → 미리보기 → 수정 → Publish** — 이 앞으로 8주 내내 반복됩니다.

## 이번 주 과제

1. 여러분 이름으로 된 "Hello, World" 페이지를 완성해 URL 발급 (필수).
2. **최소 5번 이상 대화로 수정**해 자기 스타일로 만들기.
3. 그 URL을 친구 3명에게 카톡으로 보내고 반응 스크린샷.
4. **선택**: 페이지에 여러분 사진 URL을 추가하거나 (예: `프사 이미지를 화면 상단에 원형으로 넣어줘. 이미지 URL: https://...`), 좋아하는 이모지를 배치해보세요.
