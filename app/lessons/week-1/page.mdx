## 이번 주에 배울 것

이 강의는 **웹앱을 만드는 전체 과정**을 8주에 압축해서 경험하는 강의입니다. 실무에서 개발자·기획자·디자이너가 하는 일을 그대로 따라가면서, AI가 코드 짜는 부분을 대신해줍니다.

이번 첫 주는 오리엔테이션입니다.

1. 웹앱이 뭔지, URL 하나가 뜨기까지 무슨 일이 일어나는지 5분 개념 정리.
2. 개발자들이 프로덕트를 만드는 6단계 라이프사이클을 살펴보고, 이 강의가 각 단계를 어떤 순서로 진행할지 확인.
3. **Google AI Studio Build**를 열어 첫 웹페이지를 만들고 진짜로 배포.

## Part 1. 5분 개념 - 웹앱

여러분이 카톡에서 링크 하나를 눌렀을 때 무슨 일이 벌어질까요?

```
① 브라우저(크롬)가 그 URL의 서버에 "이 페이지 주세요" 요청
② 서버가 HTML/CSS/JS 파일을 응답으로 돌려줌
③ 브라우저가 그 파일을 해석해 화면을 그림
④ 사용자가 클릭·입력하면 다시 서버와 통신하며 갱신
```

**웹페이지 = HTML(뼈대) + CSS(스타일) + JavaScript(움직임)**로 만들어집니다. 웹앱은 이 세 언어의 조합에 서버·데이터베이스가 붙은 것.

전통적으로 개발자가 이 코드를 직접 씁니다. 우리는 **Google AI Studio Build**가 대신 짜게 시키고, 우리는 **무엇을 만들지·어떻게 보일지·잘 되는지 확인하는 데** 집중합니다.

## Part 2. 웹앱 개발 6단계 라이프사이클

실무에서 웹앱은 이렇게 만들어집니다. 이 강의도 정확히 이 순서를 따라갑니다.

```
1. 기획   (Discovery)  →  뭘 만들지, 왜 만들지 정한다
2. 설계   (Design)     →  화면과 사용자 흐름을 스케치한다
3. 개발   (Build)      →  실제로 만든다 (여러 번 반복)
4. 테스트 (QA)         →  잘 되는지 검증한다
5. 배포   (Launch)     →  세상에 공개한다
6. 운영   (Operate)    →  분석·개선을 계속한다
```

각 단계에서 **결과물(deliverable)**이 나옵니다. 이 결과물이 다음 단계의 재료가 돼요.

| 단계 | 이 강의 주차 | 결과물 |
|---|---|---|
| 1. 기획 | Week 2 | PRD (1페이지) |
| 2. 설계 | Week 3 | 와이어프레임 + 디자인 토큰 |
| 3. 개발 | Week 4~6 | 실제로 동작하는 앱 |
| 4. 테스트 | Week 7 | QA 리포트 |
| 5. 배포 | Week 8 | 공개 URL + 도메인 |
| 6. 운영 | 강의 이후 | 여러분 인생의 몫 :) |

Week 1인 오늘은 **이 순서를 안 지키고** 바로 손을 움직여봅니다. 감을 잡는 게 목적이니까요.

## Part 3. Google AI Studio Build 실습

### Step 1. AI Studio 접속

브라우저에서 <a href="https://aistudio.google.com" target="_blank">**aistudio.google.com**</a> 접속 → 구글 계정 로그인.

> 이번 강의는 **Gemini 유료 요금제**를 사용합니다. 아직 등록 안 되어 있다면 <a href="https://aistudio.google.com/app/apikey" target="_blank">API keys 페이지</a>에서 **"Set up billing"**으로 결제 등록. 강의 전체 사용해도 몇천 원 수준입니다.

### Step 2. Build 모드 열기

왼쪽 사이드바에서 **"Build"** (또는 **"Apps"**) 메뉴 클릭.

> UI가 자주 업데이트되므로 정확한 위치는 다를 수 있습니다. **"Chat"이 아닌 "앱을 만드는" 섹션**을 찾으세요. 없다면 대체 경로: Chat 프롬프트를 만들고 마지막에 **"Get code"**로 코드를 받아 배포하는 방식도 가능합니다 (Week 4에서 다시 다룸).

### Step 3. 첫 앱 프롬프트

Build 화면의 프롬프트 입력창에 아래를 그대로 붙여넣으세요 (오른쪽 위 복사 버튼 활용).

```
문과대학 국문학과 3학년 김지은의 자기소개 랜딩 페이지를 만들어줘.

구조:
- 화면 정중앙에 큰 인사말: "안녕하세요, 김지은입니다"
- 그 아래 한 줄 부제: "문학과 커피를 사랑하는 대학생"
- 아래쪽에 짧은 자기 소개 3~4문장
- 하단에 이메일 링크

디자인:
- 파스텔 톤 (연한 크림 배경, 브라운 포인트)
- 폰트는 부드러운 세리프
- 폰과 데스크톱 모두에서 예쁘게

모든 텍스트는 한국어로.
```

> "김지은", "국문학과" 부분은 여러분에 맞게 수정하세요.

**Run** (또는 화살표 버튼) 클릭 → 30초~2분 대기.

### Step 4. 미리보기 확인

오른쪽 창에 실제 웹페이지 미리보기가 뜹니다. 예쁘게 나왔으면 다음 단계.

마음에 안 들면 **같은 대화창**에 이런 후속 요청을 하나씩 던져보세요.

```
배경 색깔을 더 진한 크림색으로 바꿔줘.
```

```
인사말 폰트를 좀 더 크고 굵게. 
그리고 인사말 옆에 👋 이모지 추가해줘.
```

```
자기소개 아래에 "관심사"라는 섹션을 만들고, 
📚 문학, ☕ 커피, ✍️ 글쓰기, 🎧 재즈 이렇게 4개 카드로 표시해줘.
```

### Step 5. 배포하기

미리보기 우측 상단 **"Publish"** 또는 **"Deploy"** 버튼 클릭.

- 프로젝트 이름 입력 (예: `intro-jieun`).
- 배포 완료까지 30초~2분 대기.
- 공개 URL 발급.

이런 형태의 URL이 나옵니다:

```
https://intro-jieun.[플랫폼도메인].app
```

또는 (Build에서 Cloud Run으로 배포하는 경우):

```
https://intro-jieun-xxxx.a.run.app
```

### Step 6. 배포 확인

발급된 URL을 다음 세 곳에서 열어보세요.

1. **시크릿 브라우저** (로그인 없이도 뜨는지)
2. **다른 브라우저** (Chrome이면 Edge)
3. **스마트폰** (모바일에서 예쁜지)

세 곳 다 잘 뜨면 진짜로 인터넷에 공개된 것.

### Step 7. 친구에게 공유

카톡·문자·인스타 DM으로 URL 보내기. 상대가 링크를 열면 여러분의 페이지가 뜹니다.

## Part 4. AI Studio Build가 뭘 해준 건가?

Code 탭을 눌러 뒤에서 무슨 일이 벌어졌는지 봅시다.

- **HTML**: 화면의 뼈대 (`<h1>`, `<section>`, `<button>` 등)
- **CSS**: 색깔·폰트·간격 스타일
- **JavaScript**: 클릭 반응 같은 움직임 (지금은 거의 없음)

여러분이 안 짜도 되지만 **눈에 익히면 나중에 수정할 때 편해요**. 각주만 훑어보세요.

## 자주 발생하는 상황

### ❓ AI Studio에 "Build" 메뉴가 안 보여요

**해결**: AI Studio 인터페이스는 자주 바뀝니다. 
- **"Apps"**, **"Try Gemini apps"**, **"Templates"** 등 이름이 다를 수 있어요.
- 그래도 못 찾으면 일반 Chat 프롬프트로 만들고, 마지막에 **"Get code"** → JavaScript 코드 → CodePen에 붙여넣기. Week 4에서 자세히 안내합니다.

### ❓ 미리보기가 비어있거나 오류

**해결**: 프롬프트에 **"코드 오류가 있으면 수정해줘"** 후속 요청. 그래도 안 되면 **+ New chat**으로 처음부터 다시.

### ❓ 배포 후 URL 접속 시 로그인 요구

**해결**: 배포 대시보드에서 **"Public"** 또는 **"Anyone can access"** 옵션 확인. Cloud Run이라면 IAM에서 `allUsers`에 Cloud Run Invoker 권한.

### ❓ 사용량 한도 초과 (Rate limit)

**해결**: 무료 계정 한도 초과. 유료 계정 등록 확인. 몇 분 대기 후 재시도.
