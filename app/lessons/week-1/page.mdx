## 이번 주에 할 일

**설치할 것도, 코드 쓸 것도, 터미널 열 것도 없어요.** 오늘은 그냥 브라우저만 켜면 됩니다.

Google이 만든 **AI Studio**라는 웹사이트에서 Gemini AI와 첫 대화를 나눠봅니다. 그리고 "나만의 학습 도우미" 프롬프트를 만들어 **친구에게 링크로 공유**합니다.

### 오늘의 최종 결과물 미리보기

- 여러분이 만든 챗봇에 접속할 수 있는 URL (예: `aistudio.google.com/apps/prompts/1a2b3c...`)
- 그 링크를 친구에게 보내면, 친구가 여러분이 세팅한 대로 대화할 수 있어요

## 준비물 체크

- ☑️ 노트북 (Windows 또는 Mac)
- ☑️ Chrome, Edge, Safari 같은 최신 브라우저
- ☑️ **구글 계정** (지메일 있으면 됨)
- ☑️ **결제 등록된 구글 계정** (Gemini 유료 요금제)

> ⚠️ 유료 결제는 첫 강의 전에 미리 준비해주세요. 학교에서 계정을 공유해준다면 그걸 쓰셔도 되고, 개인이라면 신용카드로 등록해두세요. **월 몇천 원 수준**의 소액만 나옵니다 (수업만 쓰면 하루 100원 미만).

## Step 1. Google AI Studio 접속

브라우저 주소창에 아래를 입력하고 `Enter`:

```
aistudio.google.com
```

또는 이 링크 클릭: <a href="https://aistudio.google.com" target="_blank">**aistudio.google.com**</a>

### 로그인

- 처음이라면 **"Sign in"** 버튼 → 여러분 구글 계정으로 로그인.
- 약관 동의 화면이 뜨면 체크박스 몇 개 켜고 **"Continue"**.
- 첫 접속 시 **"Get API key"** 팝업이 뜰 수 있는데, 오늘은 필요 없으므로 X로 닫아도 됩니다.

### AI Studio 화면 둘러보기

로그인이 끝나면 이런 화면이 나옵니다:

- **왼쪽 사이드바**: Chat, Stream, Build 등 메뉴 + My Prompts (내가 저장한 것)
- **가운데**: 대화창 (여기가 여러분의 놀이터)
- **오른쪽 사이드바**: 설정 패널 (모델, 온도, 시스템 지시 등)

## Step 2. 첫 대화 나눠보기 🎉

가운데 대화창 아래쪽에 **"Type something..."** 입력창이 보일 거예요. 아래 문장을 복사(오른쪽 위 복사 버튼)해서 입력창에 붙여넣기.

```
안녕! 나는 대학교 2학년 학생이야. 오늘 처음 AI Studio를 써봐. 나에게 재미있게 자기소개 해줄래?
```

`Enter` 또는 **Run(▶)** 버튼을 누르면 잠시 후 Gemini가 답합니다.

**축하합니다! 여러분은 방금 AI와 첫 대화를 나눴습니다.** 🎉

이어서 몇 번 더 대화해보세요. 아래 프롬프트들을 하나씩 복사해서 붙여넣어보세요.

```
너는 어떤 걸 잘해?
```

```
나 요즘 무기력해. 어떻게 하면 좋을까?
```

```
우리 학교 근처 맛집 추천해줘. 나는 홍대 근처 살아.
```

### 응답이 마음에 안 들면?

응답 아래에 몇 가지 버튼이 있어요:

- **↻ Regenerate**: 다시 답변 생성 (같은 질문, 다른 답)
- **📋 Copy**: 답변 텍스트 복사
- **👍 / 👎**: 좋은/나쁜 답변 표시

## Step 3. 오른쪽 설정 패널 살펴보기

오른쪽 사이드바에 여러 설정이 있어요. 이번 주에 알아둘 건 두 개.

### 3-1. Model (모델)

기본으로 **"gemini-2.5-flash"**가 선택되어 있을 거예요. 이건 "빠르고 저렴한 Gemini"라는 뜻이에요.

드롭다운을 클릭하면 다른 모델도 볼 수 있어요:

- **gemini-2.5-flash** — 빠르고 저렴 (일상 대화, 요약, 간단한 질문)
- **gemini-2.5-pro** — 느리지만 똑똑함 (복잡한 추론, 논문 분석)
- **gemini-2.5-flash-lite** — 초저가·초경량

이번 강의 내내 **flash**를 씁니다. 큰 차이가 없어요.

### 3-2. Temperature (온도)

**Temperature**는 AI의 창의성 조절 노브입니다.

- **0.0 (낮음)**: 매번 거의 같은 답변. 사실 중심, 딱딱함.
- **1.0 (기본)**: 자연스러운 다양성.
- **2.0 (최대)**: 매우 창의적, 때로는 이상함.

한번 실험해봅시다. 같은 질문을 세 가지 temperature로 보내보세요.

**질문**:

```
짧은 시 한 편 지어줘. 봄과 이별에 대해.
```

이 질문을 아래 세 가지 세팅으로 각각 실행:

1. Temperature 0.0으로 세팅 → 실행
2. Temperature 1.0으로 세팅 → 실행 (기본값)
3. Temperature 1.8로 세팅 → 실행

세 답변의 톤과 창의성이 확 다를 거예요. 재밌죠?

## Step 4. System Instructions - 오늘의 핵심 ⭐

오른쪽 사이드바 위쪽에 **"System instructions"**라는 접힌 영역이 있어요. 클릭해서 펼치세요.

**여기가 마법 상자입니다.** 이 상자에 여러분이 원하는 챗봇의 성격·규칙·역할을 적어두면, 이후 모든 대화가 그 설정에 따라 진행됩니다.

시스템 지시 상자에 아래 프롬프트를 그대로 복사해서 붙여넣기:

```
너는 대학생들을 위한 학습 도우미야. 다음 규칙을 지켜:

1. 항상 친근하고 격려하는 톤으로 대답한다.
2. 어려운 개념은 대학생 눈높이의 비유로 설명한다.
3. 대답 마지막에 "혹시 더 궁금한 게 있어?"라고 물어본다.
4. 답변은 3~4문단을 넘지 않는다.
5. 절대 학생을 무시하거나 판단하는 말투를 쓰지 않는다.
6. 모든 답변은 한국어로 한다.
```

그리고 대화창을 초기화(휴지통 아이콘)하고 다시 질문해보세요:

```
경제학에서 '기회비용'이 뭐야?
```

방금 전 답변과 완전히 다르게 나올 거예요. 훨씬 친근하고, 대학생 관점의 예시가 나오고, "혹시 더 궁금한 게 있어?"로 끝날 겁니다.

**이게 프롬프트 엔지니어링의 핵심입니다.** 앞으로 여러분이 만들 모든 AI 앱은 이 System Instructions에서 시작해요.

## Step 5. 프롬프트 저장하기

지금까지 만든 설정(모델, 온도, 시스템 지시)을 저장하고 싶죠?

1. 상단 왼쪽 근처에 **"Save"** 버튼 (디스크 아이콘)을 찾으세요.
2. 클릭하면 이름을 물어봅니다. 아래 이름을 복사해서 붙여넣기:

```
나의 학습 도우미
```

3. **Save** 클릭 → 왼쪽 사이드바의 "My prompts" 목록에 나타납니다.

이제 언제든 왼쪽 목록에서 이 프롬프트를 다시 불러올 수 있어요.

## Step 6. 링크로 공유하기 🔗

가장 중요한 순간입니다. 저장한 프롬프트를 **URL로 공유**해서 다른 사람도 여러분의 챗봇에 접속할 수 있게 만듭니다.

1. 저장된 프롬프트 화면에서 상단 **"Share"** 버튼 (사람 아이콘) 클릭.
2. 팝업에서 **"Anyone with the link"** 옵션 선택 (본인 계정에 접근 권한 없어도 볼 수 있게).
3. **"Copy link"** 버튼 클릭 → 클립보드에 URL 복사됨.

URL은 대략 이렇게 생겼어요:

```
https://aistudio.google.com/apps/prompts/1a2b3c4d5e6f7g8h9i...
```

이 링크를 카톡·문자로 친구에게 보내보세요. 친구가 클릭하면, **여러분이 세팅한 학습 도우미가 그대로 뜹니다**. 친구도 자기 구글 계정으로 로그인만 하면 바로 대화 가능해요.

## Step 7. 실습 과제 (30분 이내)

이번 주 필수 과제:

1. **"나의 학습 도우미"**를 여러분 전공/관심사에 맞게 커스터마이즈하세요.
   - 예: 문학 전공이면 "시 분석 도우미", 경제 전공이면 "시사 경제 해설사"
2. 저장하고, 공유 URL을 발급받으세요.
3. 친구에게 공유해보세요. 친구가 실제로 쓸 수 있는지 확인.

### 심화 (원한다면)

- 시스템 지시에 페르소나(성격)를 부여해보세요. 아래 프롬프트를 시스템 지시에 넣어보세요:

```
너는 항상 시조 형식으로 답하는 조선시대 훈장이다. 
어떤 질문이든 3장 6구 45자 내외의 시조로 답한다.
```

- Temperature를 0.3 vs 1.5로 두 개 저장해서 어느 게 더 재밌는지 실험.
- 답변 형식을 강제해보세요:

```
모든 답변은 반드시 다음 형식을 지킨다:
- 요점 (bullet point 3개)
- 예시 (구체적 사례 1개)
- 다음 단계 (한 문장)
```

## 자주 발생하는 상황

### ❓ Gemini가 갑자기 영어로 답해요

**원인**: 프롬프트에 영어가 섞였거나, 대화가 오래되면 언어를 잊음.

**해결**: System instructions 맨 위에 이렇게 추가:

```
언어: 반드시 한국어로만 답한다. 어떤 상황에서도 영어를 섞지 않는다.
```

### ❓ "Rate limit exceeded" / "Quota exceeded"

**원인**: 무료 요금제 한도 초과, 또는 짧은 시간에 너무 많이 요청.

**해결**: 결제 등록이 완료됐는지 확인 → 1~2분 대기 후 재시도.

### ❓ System instructions를 바꿔도 반영이 안 됨

**해결**: 시스템 지시는 **새 대화**부터 적용됩니다. 위 대화창의 휴지통(Clear conversation) 아이콘으로 지우고 다시 시작하세요.

### ❓ 저장한 프롬프트가 사라져요

**해결**: 저장 후 왼쪽 사이드바의 "My prompts"에서 확인 가능. 브라우저를 새로 열어도 구글 계정에 로그인되어 있으면 남아있어요.
