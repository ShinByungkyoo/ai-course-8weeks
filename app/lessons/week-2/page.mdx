## 이번 주에 할 일

지난주엔 "안녕!" 한 문장만 있는 페이지였죠. 이번 주엔 **진짜 회사 홈페이지처럼 생긴 랜딩 페이지**를 만듭니다.

만들 페이지: **여러분의 자기소개 랜딩 페이지**

### 이번 주 결과물

- 히어로 → 소개 → 관심사 → 프로젝트 → 연락처 5개 섹션이 있는 세로 스크롤 페이지
- 사진, 이모지, 버튼, 링크가 어우러진 진짜 웹사이트 느낌
- 스마트폰에서 봐도 예쁘게 (반응형)

## 랜딩 페이지의 구조 (5분 개념)

**랜딩 페이지 = 방문자가 첫 눈에 들어오는 세로로 긴 한 페이지 사이트**입니다. 애플, 토스, 카카오 등 대부분 회사 홈페이지가 이 구조예요.

전형적인 구조는 이렇습니다:

```
┌─────────────────────────────┐
│ 헤더 (로고, 메뉴)             │  ← 상단 고정 (선택)
├─────────────────────────────┤
│                             │
│       히어로 섹션              │  ← 가장 눈에 띄는 첫 화면
│  (큰 제목 + 부제 + CTA 버튼)  │
│                             │
├─────────────────────────────┤
│                             │
│      About 섹션              │  ← 나에 대해
│                             │
├─────────────────────────────┤
│                             │
│      관심사·프로젝트 섹션      │  ← 카드 그리드
│                             │
├─────────────────────────────┤
│                             │
│      연락처 섹션              │
│                             │
├─────────────────────────────┤
│ 푸터 (저작권, SNS 링크)       │  ← 하단
└─────────────────────────────┘
```

각 섹션의 역할:

| 섹션 | 목적 |
|---|---|
| **헤더 (Header)** | 로고와 메뉴. 다른 페이지로 이동할 때 씀 |
| **히어로 (Hero)** | 첫인상. 3초 안에 "이건 뭐고 왜 봐야 하지?"를 전달 |
| **About** | 배경, 성격, 스토리 |
| **Features/카드 그리드** | 관심사, 프로젝트, 스킬 등 반복되는 아이템 |
| **CTA (Call to Action)** | "지금 연락하기" 같은 행동 유도 버튼 |
| **푸터 (Footer)** | 저작권, SNS 아이콘, 부가 링크 |

**이제 이 구조로 만들어봅시다.**

## Step 1. v0.dev에서 새 프로젝트 시작

<a href="https://v0.dev" target="_blank">v0.dev</a> 접속 → 왼쪽 상단 로고 클릭 → **"+ New Project"** 또는 상단 검색바에 새 프롬프트 입력하면 자동으로 새 프로젝트가 시작됩니다.

## Step 2. 랜딩 페이지 요청하기

입력창에 아래 프롬프트를 그대로 복사·붙여넣기 하세요. **"김지은"·"국문학과" 같은 부분은 여러분에 맞게 수정**하고요.

```
문과대학 국문학과 3학년 김지은의 자기소개 랜딩 페이지를 만들어줘.

전체 구조 (세로 스크롤 방식):

1. 헤더 (상단 고정)
   - 왼쪽에 로고 자리 (내 이니셜 "JE"를 원 안에)
   - 오른쪽에 메뉴: 소개 / 관심사 / 프로젝트 / 연락처
   - 스크롤 내려도 상단에 살짝 반투명하게 고정

2. 히어로 섹션 (첫 화면)
   - 큰 제목: "안녕하세요, 김지은입니다"
   - 부제: "문학과 커피를 사랑하는 대학생, 그리고 시작하는 창작자"
   - 프로필 이미지 자리 (원형, 임시 placeholder OK)
   - "더 알아보기" 버튼 (아래 섹션으로 스크롤)
   - 배경: 은은한 파스텔 그라데이션 (연한 핑크에서 연한 크림으로)

3. About 섹션
   - 왼쪽에 나의 이야기 (3~4문단): 왜 문학을 좋아하는지, 커피를 시작한 계기,
     지금 가장 관심 있는 주제
   - 오른쪽에 카드 형태로 통계 3개: "지금까지 읽은 책 60권", "카페 탐방 42곳", "쓴 글 15편"

4. 관심사 섹션
   - 상단 큰 타이틀: "내가 사랑하는 것들"
   - 카드 3~4개 (그리드로 배치): 각 카드에 이모지 + 제목 + 짧은 설명
     - 📚 문학 - "한국 근현대 시를 좋아합니다. 요즘 정지용에 빠져있어요."
     - ☕ 커피 - "핸드드립을 배우고 있고, 서울 카페 도장깨기 중"
     - ✍️ 글쓰기 - "나의 감각을 활자로 남기는 일"
     - 🎧 음악 - "재즈와 시티팝을 좋아합니다"
   - 마우스 올리면 카드가 살짝 떠오르는 효과

5. 프로젝트 섹션
   - 타이틀: "최근 프로젝트"
   - 카드 3개 (이미지 + 제목 + 짧은 설명 + "자세히" 링크)
     - "봄 시집 프로젝트" - 계절별 시를 모으는 아카이브
     - "카페 지도" - 방문한 카페 리뷰 모음
     - "1일 1글" - 100일 글쓰기 챌린지

6. 연락처 섹션
   - "이야기 나누고 싶다면" 타이틀
   - 이메일, 인스타그램, 브런치 아이콘 버튼
   - 큰 CTA 버튼: "이메일 보내기" (클릭하면 mailto: 열림)

7. 푸터
   - 왼쪽: "© 2026 김지은. 만든 사람: 김지은"
   - 오른쪽: SNS 아이콘 (인스타, 이메일)
   - 하단 얇은 라인

디자인 규칙:
- 전체 톤: 파스텔, 부드러움, 여성적이고 클래식
- 색상: 연한 핑크(#F8D7DA), 연한 크림(#FFF9F0), 진한 브라운 포인트(#5C4033)
- 폰트: 세리프 계열의 우아한 것 (예: Playfair, Nanum Myeongjo)
- 본문 폰트는 산세리프로 가독성 좋게
- 각 섹션 사이 넉넉한 여백
- 모바일에서는 카드가 세로로 스택
- 모든 텍스트 한국어

인터랙션:
- 메뉴 클릭하면 해당 섹션으로 부드럽게 스크롤
- 스크롤 시 각 섹션이 살짝 페이드인
- 이메일 버튼에 hover 시 색이 진해짐
```

**보내기(▲)** 또는 `Enter`.

2~3분 기다립니다.

## Step 3. 결과 확인

미리보기가 완성되면 세로로 스크롤해보세요. 위 5개 섹션이 다 있는지 체크:

- ☑️ 헤더 (상단 고정)
- ☑️ 히어로 (첫 화면)
- ☑️ About
- ☑️ 관심사 (카드 그리드)
- ☑️ 프로젝트
- ☑️ 연락처
- ☑️ 푸터

## Step 4. 대화로 다듬기 - 이번 주 핵심

지금부터가 진짜 실력이 붙는 부분이에요. **v0에게 어떻게 요청해야 원하는 결과가 나오는지** 감을 잡습니다.

### 요령 1. 구체적으로 어떤 부분인지 짚어주기

- ❌ 나쁨: `색깔을 바꿔줘`
- ✅ 좋음: `히어로 섹션의 배경 그라데이션을 연한 하늘색과 연한 라벤더로 바꿔줘.`

### 요령 2. 참고 대상 언급

- `애플 홈페이지처럼 넓은 여백과 큰 폰트로 리디자인해줘.`
- `토스 앱처럼 깔끔하고 모던하게.`
- `유튜브 스튜디오처럼 카드 그림자를 살짝 넣어줘.`

### 요령 3. 작게 나눠서 요청

한 번에 다 못 고쳐도 됩니다. 하나씩:

```
1) 히어로 섹션의 프로필 이미지를 조금 더 크게 (지금은 너무 작아).
```

수정된 후 다시:

```
2) 관심사 카드에 마우스 올리면 살짝 살짝 위로 뜨는 애니메이션을 추가해줘.
```

### 요령 4. 색깔은 컬러 코드로 명시

`연한 핑크`가 애매하면 `#F8D7DA` 같은 HEX 코드로. 이 코드가 뭔지 몰라도 `구글 컬러 팔레트`에서 예쁜 조합을 찾아 복붙하면 됩니다.

<a href="https://coolors.co/palettes/trending" target="_blank">coolors.co/palettes</a>에서 예쁜 팔레트를 골라 5개 색 코드를 v0에게 그대로 전달하세요:

```
아래 색을 사용해서 전체 리디자인해줘:
- 메인 배경: #FAF3E7
- 강조색: #E76F51
- 텍스트: #2A2A2A
- 카드 배경: #FFFFFF
- 서브 텍스트: #6C6C6C
```

### 요령 5. "이 부분만" 강조

- `히어로 섹션만` (다른 곳은 유지)
- `연락처 섹션에만` 이 스타일 적용
- `모든 카드에` 그림자 추가

## Step 5. 이미지 넣기

프로필 사진, 프로젝트 썸네일 등 이미지가 필요하죠. 두 가지 방법이 있어요.

### 방법 A: 이미지 URL 사용

이미 인터넷에 있는 이미지의 URL을 v0에게 전달:

```
히어로 섹션의 프로필 이미지 자리를 이 URL 이미지로 바꿔줘:
https://picsum.photos/400/400
```

무료 임시 이미지 사이트들:
- **picsum.photos** — 랜덤 예쁜 사진
- **placehold.co/400x400** — 회색 자리 표시자

### 방법 B: 여러분 이미지 업로드

Vercel에서는 이미지를 직접 업로드하기 위해 별도 스토리지가 필요해요. 초보에게 복잡하니 이번 주엔 **인스타그램 이미지 URL을 그대로 넣거나** 위 무료 서비스를 씁니다.

인스타 이미지 URL 얻는 법: 인스타에서 원하는 사진 → 오른쪽 상단 `⋯` → **"링크 복사"** — 이건 페이지 링크지 이미지 링크는 아님. 
간편한 대안은 **Google Drive**에 이미지 업로드 → 공유 링크 → v0에 전달.

**가장 편한 방법**: 여러분 사진을 <a href="https://imgbb.com/" target="_blank">imgbb.com</a>에 업로드 → "Direct link" 복사 → v0에 붙여넣기.

## Step 6. 폰트 바꾸기

v0에게:

```
전체 페이지 폰트를 "Pretendard" 폰트로 바꿔줘. 한글에 최적화된 폰트야.
```

Pretendard는 무료 한글 폰트 중 가장 예뻐서 인기예요. 다른 옵션:

- **Noto Sans KR** — 구글이 만든 안전한 선택
- **Nanum Gothic** — 클래식
- **Nanum Myeongjo** — 세리프 (문학적 느낌)
- **Gowun Batang** — 우아한 세리프

v0에게 이름만 알려주면 알아서 적용합니다.

## Step 7. 반응형 확인

미리보기 창에서 **폰 아이콘** 또는 **모바일 미리보기** 옵션을 찾아 클릭. 폰 크기 화면으로 미리보기가 바뀝니다.

카드가 세로로 잘 쌓이는지, 폰트가 너무 크지 않은지, 여백이 적절한지 확인.

문제 있으면:

```
모바일에서 히어로 섹션의 프로필 이미지가 너무 커. 
폰 화면에서는 이미지를 150px로, 태블릿 이상에서는 300px로.
```

## Step 8. Publish

지난주와 동일. **Publish** 버튼 → 프로젝트 이름 → **Deploy**.

URL 발급되면 폰에서 열어 최종 확인.

## Step 9. 인터넷에 공유하기 🌍

카톡, 인스타 DM, 문자로 URL 보내세요. 자기소개용 URL로 활용:

- 새로 만난 사람에게 "제 소개 페이지예요" 하고 URL 공유
- 인스타 프로필 링크에 걸어두기
- 자소서에 "포트폴리오"로 첨부

## 이번 주 과제

1. **자기소개 랜딩 페이지** 완성 & 공개 URL 발급 (필수).
2. 5개 섹션(히어로/About/관심사/프로젝트/연락처)이 모두 있어야 함.
3. **v0와 최소 10회 이상 대화**로 커스터마이즈. 대화 스크린샷 남기기.
4. 여러분 실제 사진, 실제 관심사, 실제 프로젝트를 반영.
5. 폰에서 열어봐도 예쁘게 나오는지 확인.
6. **선택 도전**: 스크롤 시 각 섹션이 페이드인 되는 애니메이션 추가.

## 다음 주 예고

지금은 세로로 긴 한 페이지지만, 진짜 회사 사이트들처럼:
