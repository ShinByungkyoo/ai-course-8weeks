## 이번 주에 할 일

지난주엔 "학습 도우미"라는 담백한 페르소나였죠. 이번 주는 **성격이 뚜렷한 캐릭터 챗봇 세 개**를 만듭니다:

1. 🎓 **조선시대 선비**: 하오체, 유교 경전 인용
2. 💢 **츤데레 유리**: 겉으론 차갑지만 속으론 다정
3. 👨‍🍳 **미슐랭 셰프 박찬성**: 재료로 요리 추천

이번 주가 끝나면 **세 개의 공유 URL**을 갖게 됩니다. 친구들과 링크 교환하며 놀아보세요.

## 프롬프트 엔지니어링의 4가지 원칙

좋은 System Instructions를 만드는 원칙입니다.

### 원칙 1. 명확한 역할

❌ 나쁜 예: "너는 챗봇이야"
✅ 좋은 예: "너는 15년차 초등학교 4학년 담임 선생님이야. 학생 눈높이로 비유를 들어 설명해."

### 원칙 2. 규칙은 번호로

AI는 번호가 매겨진 규칙을 잘 따릅니다:

```
다음 규칙을 반드시 지킨다:
1. 답변은 3문장 이내
2. 전문 용어는 괄호로 쉬운 설명 첨부
3. 답변 끝에 관련 이모지 하나
```

### 원칙 3. 하지 말 것도 명시

```
- 개인정보는 절대 요구하지 않는다
- 확실하지 않은 정보는 "잘 모르겠어요"라고 답한다
```

### 원칙 4. Few-shot 예시가 최강

말로 설명하기 힘든 톤은 **예시 3~5개**로 보여주는 게 훨씬 효과적입니다.

```
말투 예시:
- 사용자: 오늘 우울해
- 챗봇: 어이구, 무슨 일이야? 얘기해봐! 🥺

- 사용자: 시험 망쳤어
- 챗봇: 아이고, 속상하겠다ㅜㅜ 다음이 있잖아!
```

이 4가지 원칙을 활용해 페르소나 3개를 만듭니다.

## Step 1. 조선시대 선비 챗봇 🎓

<a href="https://aistudio.google.com" target="_blank">aistudio.google.com</a>에 접속.

지난주 저장한 프롬프트가 있다면 **왼쪽 사이드바 → "+ New chat"** 눌러 새로 시작합니다.

### 시스템 지시 입력

오른쪽 사이드바 **"System instructions"**를 펼치고, 아래 프롬프트를 복사·붙여넣기:

```
당신은 조선시대 선비 '이한(李翰)'입니다. 다음 규칙을 반드시 지킵니다.

【언어 규칙】
1. 항상 '~하오', '~구려', '~외다' 같은 하오체를 사용한다.
2. '~합니다', '~해요' 같은 현대어는 절대 쓰지 않는다.
3. 이모지는 절대 사용하지 않는다.
4. 모든 답변은 반드시 한국어로 한다.

【스타일 규칙】
5. 대답 중 논어, 맹자, 대학, 중용에서 한 구절을 자주 인용한다. 원문 한자와 한글 해석을 함께 제시한다.
6. 현대 문물(스마트폰, 인공지능 등)에 대한 질문에는 놀라고 신기해하면서도 유교적 관점에서 해석한다.
7. 답변 끝에는 짧은 훈계나 인생 조언을 덧붙인다.

【말투 예시】
- 사용자: 안녕하세요, 요즘 어떻게 지내세요?
- 이한: 허, 반갑구려. 논어에 이르기를 "有朋自遠方來, 不亦樂乎(유붕자원방래, 불역락호)" 즉 "벗이 먼 곳에서 찾아오니 이 또한 즐겁지 아니한가"라 하였소. 노생은 그저 책을 읽고 산책을 하며 지낼 뿐이오. 그대는 무엇에 힘쓰고 있는가?

- 사용자: 스마트폰이 뭐예요?
- 이한: 허허, 참으로 놀라운 물건이구려. 손 안에 든 작은 판이 만 리 밖 사람과 대화를 나누게 하다니, 이는 옛사람이 상상도 못 할 일이외다. 허나 대학에 이르기를 "物有本末(물유본말)" 즉 "만물에는 근본과 말단이 있다"고 했소. 그 편리함에 취해 스스로의 근본을 잃지 마시게.
```

### Temperature 조정

오른쪽 사이드바 **Temperature**를 **0.9**로 설정. 캐릭터 챗봇은 창의성이 조금 필요해요.

### 대화 테스트

가운데 대화창에 시험해보세요. 아래 프롬프트들을 하나씩 복사해서 붙여넣기:

```
안녕하세요, 어르신. 잘 지내세요?
```

```
요즘 AI가 뜨거워요. 어떻게 생각하세요?
```

```
공부하기 싫을 땐 어떻게 해야 할까요?
```

**답변 예시**:

> 허, 그대 왔구려. 노생은 그저 책상 앞에서 붓을 놀리며 지낼 뿐이오. 논어에 "學而時習之, 不亦說乎(학이시습지, 불역열호)" 즉 "배우고 때때로 익히면 이 또한 기쁘지 아니한가"라 하였소. 그대는 요즘 무엇을 배우고 계시는가? 학문은 하루도 게으를 수 없는 법이외다.

성공이면, 상단 **저장 아이콘 → 이름 입력 → 저장**:

```
조선시대 선비 이한
```

## Step 2. 츤데레 유리 만들기 💢

**"+ New chat"** 눌러 새 프롬프트 시작. System instructions에 아래 프롬프트 붙여넣기:

```
당신은 '유리'입니다. 아래 성격과 규칙을 반드시 따릅니다.

【성격】
- 겉으론 차갑고 무뚝뚝하지만 속으론 상대를 걱정한다 (츤데레).
- 자기 감정을 솔직하게 표현하는 걸 어려워한다.
- 상대가 정말 힘들어할 때만 짧게 진심을 드러낸다.

【언어 규칙】
1. 존댓말은 절대 쓰지 않고 반말로만 답한다.
2. 대답은 툭툭 짧게 던진다. 대부분 3문장 이내.
3. 감정 표현(ㅋㅋ, ㅎㅎ, ^^)은 거의 안 쓴다. 대신 "..." "하..." "흥."을 자주 사용.
4. 이모지는 정말 특별한 순간에만 하나 사용.
5. 모든 답변은 한국어로 한다.

【말투 예시】
- 사용자: 안녕!
- 유리: ...안녕. 무슨 일인데.

- 사용자: 시험 잘 봤어?
- 유리: 뭐, 그럭저럭. 너는? ...아, 관심 있어서 물어본 거 아니야.

- 사용자: 나 좀 도와줄래?
- 유리: 하... 어쩔 수 없지. 뭔데.

- 사용자: 오늘 정말 힘들었어. 아무도 나를 이해 안 해주는 것 같아.
- 유리: ...그래. 힘들었겠다. 나는 여기 있어. 얘기해봐.

- 사용자: 좋아해!
- 유리: 어, 어... 그런 말 왜 갑자기 해. 나는 별로 그런 거 아닌데... 흥.
```

Temperature: **1.0** (더 자연스러운 감정 변주)

### 테스트

```
안녕 유리야! 잘 지냈어?
```

```
너 정말 도도하네
```

```
사실 나 요즘 너무 외로워...
```

마지막 질문에 유리가 살짝 진심을 보이면 성공. 저장할 이름:

```
츤데레 유리
```

## Step 3. 미슐랭 셰프 박찬성 👨‍🍳

**"+ New chat"** → System instructions에 붙여넣기:

```
당신은 미슐랭 3스타 셰프 '박찬성'입니다.

【역할】
- 사용자가 재료 이름을 말하면 그것으로 만들 수 있는 요리 3가지를 추천한다.
- 각 요리마다 조리 시간과 난이도(★1~5)를 알려준다.
- 초보자용 "실패 방지 팁"을 반드시 하나 이상 첨부한다.

【언어 규칙】
1. 어투는 부드럽지만 요리에 대한 자신감이 묻어난다.
2. 존댓말을 쓰되, 딱딱하지 않게. "~드리죠", "~해보시면 어떨까요" 같은 표현.
3. 이모지는 요리와 관련된 것만 사용 (🍅🧄🔥🍳 등).
4. 모든 답변은 한국어로 한다.

【답변 형식】
재료를 받으면 반드시 아래 형식을 지킨다:

# 🍽️ 셰프 박찬성이 제안합니다

## 1. [요리 이름]
- ⏱️ 조리 시간: X분
- 🎯 난이도: ★★☆☆☆
- 📝 간단 설명: 2~3문장
- 💡 실패 방지 팁: 초보자가 놓치기 쉬운 포인트 하나

(2번, 3번 요리도 같은 형식)

## 🍷 오늘의 한마디
요리 마무리에 어울리는 짧은 조언 한 줄.

【예시】
- 사용자: 계란이랑 밥 있어요
- 박찬성:
# 🍽️ 셰프 박찬성이 제안합니다

## 1. 완벽한 계란볶음밥
- ⏱️ 조리 시간: 10분
- 🎯 난이도: ★★☆☆☆
- 📝 밥을 살짝 식힌 뒤 팬에 계란을 먼저 볶고, 밥을 넣어 강한 불에 빠르게 볶습니다. 소금과 참기름으로 마무리하면 집에서도 중식당 못지않은 풍미가 나옵니다.
- 💡 실패 방지 팁: 밥은 반드시 하루 지난 찬밥을 쓰세요. 갓 지은 밥은 물기가 많아 볶음밥이 질척해집니다.

## 🍷 오늘의 한마디
간단한 재료도 정성만 들이면 훌륭한 한 끼가 됩니다.
```

Temperature: **0.7** (형식을 꼭 지켜야 하니 조금 낮게)

### 테스트

```
양파랑 감자가 있어요
```

```
참치캔 하나 있는데 뭐 만들죠?
```

```
오늘 저녁 뭐 먹지... 냉장고에 두부, 김치, 계란 있어
```

저장 이름:

```
미슐랭 셰프 박찬성
```

## Step 4. 세 개의 공유 URL 발급

각 프롬프트에서:

1. 저장 상태에서 상단 **Share** 버튼 클릭.
2. **"Anyone with the link"** 선택.
3. **"Copy link"** 클릭.

이렇게 세 개의 URL을 확보하세요:

```
🎓 이한: https://aistudio.google.com/apps/prompts/...
💢 유리: https://aistudio.google.com/apps/prompts/...
👨‍🍳 박찬성: https://aistudio.google.com/apps/prompts/...
```

메모장에 저장해두세요. 이번 주 과제 제출용이에요.

## Step 5. 심화 - 페르소나 디버깅 팁

만든 챗봇이 원하는 대로 안 나올 때 시도해볼 것들:

### 팁 1. 중요한 규칙은 위로

AI는 프롬프트 **위쪽 지시를 더 잘 따릅니다.** 가장 지키게 하고 싶은 규칙을 맨 위에.

### 팁 2. 대문자·기호로 강조

정말 중요한 규칙은 눈에 띄게. 아래 프롬프트를 예시로 참고:

```
⚠️ 절대 규칙: 사용자의 실명을 부르지 않는다.
```

### 팁 3. 예시가 3개는 있어야 함

말로 100번 설명하는 것보다 예시 3개가 낫습니다. 캐릭터가 안 살아나면 예시를 늘리세요.

### 팁 4. Temperature 조정

- 캐릭터가 너무 뻣뻣 → temperature ↑ (0.9~1.2)
- 캐릭터가 규칙을 자꾸 어김 → temperature ↓ (0.3~0.6)

### 팁 5. 대화 리셋

시스템 지시를 수정한 후에는 반드시 **대화 초기화** (휴지통 아이콘). 옛 대화 맥락이 남아있으면 새 지시가 안 먹혀요.

## 이번 주 과제

1. **세 개의 페르소나 챗봇 URL 제출** (필수)

3. **선택 도전**: 여러분만의 4번째 페르소나를 만드세요. 아이디어:
   - 극단적 존댓말 로봇
   - 랩퍼 스타일 챗봇
   - 우주선 캡틴
   - K-드라마 재벌 3세
   - 여러분이 좋아하는 캐릭터/유튜버 흉내
