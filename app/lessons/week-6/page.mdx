## 이번 주에 할 일

Week 5에선 예쁜 페이지를 만들었지만 아직 AI 기능은 없었죠. 이번 주에 **진짜 Gemini AI가 들어간 챗봇 웹사이트**를 완성합니다.

이번 주 결과물:
- 여러분의 **URL** (예: `https://my-scholar-chat.vercel.app`)
- 누구나 접속해 대화할 수 있는 챗봇
- Week 2에서 만든 페르소나(선비/츤데레/셰프) 중 하나를 웹사이트로

**여전히 파이썬 없음. v0에게 부탁만 하면 끝.**

## Step 1. Gemini API 키 발급하기 🔑

Google AI Studio에서는 로그인만 하면 됐지만, 웹앱에서 Gemini를 부르려면 **API 키**가 필요해요. API 키는 "이 앱이 유료 요금제로 Gemini를 쓸 수 있게 해주는 열쇠"라고 생각하세요.

### 1-1. API 키 생성

<a href="https://aistudio.google.com/app/apikey" target="_blank">**aistudio.google.com/app/apikey**</a> 접속.

- **"Create API key"** 버튼 클릭.
- 프로젝트 선택 → 기본 프로젝트 그대로 OK.
- 잠시 후 `AIzaSy...`로 시작하는 긴 문자열이 나타남 → 이게 여러분의 **API 키**.

### 1-2. API 키 안전하게 보관

**⚠️ 매우 중요**: API 키는 비밀번호와 같습니다.

- 절대로 SNS·블로그·GitHub에 그대로 올리지 마세요.
- 다른 사람에게 공유하지 마세요.
- 유출되면 누가 여러분 이름으로 API를 마구 써서 요금이 나올 수 있어요.

**메모장에만 임시로 붙여넣어 두세요.** Step 6에서 v0에 입력할 거예요.

### 1-3. 유료 요금제 확인

Week 1에서 이미 등록하셨겠지만, 다시 확인:

<a href="https://aistudio.google.com/app/apikey" target="_blank">API keys 페이지</a>에서 프로젝트 이름 옆에 **"Paid tier"** 표시가 있는지. 없으면 클릭해서 **Billing 활성화** 진행.

## Step 2. v0에게 챗봇 앱 만들어달라고 부탁

<a href="https://v0.dev" target="_blank">v0.dev</a>에서 **New Chat** 시작.

프롬프트 입력창에 이렇게 써보세요:

```
Gemini API를 사용하는 챗봇 웹앱을 만들어줘.

기능 요구사항:
- 사용자가 화면 하단 입력창에 메시지를 입력하면, 
  Gemini가 답변해서 대화창에 표시된다.
- 대화 기록이 화면에 남아 이전 대화를 볼 수 있다.
- AI가 답변하는 동안 "생각 중..." 로딩 표시.
- 답변은 스트리밍(한 글자씩 흘러나오게).
- 화면 상단에 앱 제목: "선비 이한과의 대화".
- 우측 상단에 "대화 초기화" 버튼.

디자인 요구사항:
- 한지 느낌의 크림색 배경, 갈색 포인트 컬러.
- 서예 느낌의 세리프 폰트 (Nanum Myeongjo 같은).
- 사용자 메시지는 오른쪽, AI 메시지는 왼쪽 (카톡 스타일).
- 모바일 반응형.

기술 요구사항:
- Next.js App Router 사용.
- API 키는 환경변수 GEMINI_API_KEY에서 읽어옴.
- 서버 컴포넌트/서버 액션으로 API 키 노출 방지.
- Gemini 모델: gemini-2.5-flash.
- 시스템 프롬프트는 코드에 상수로 포함 (아래 내용).

시스템 프롬프트:
"""
당신은 조선시대 선비 '이한(李翰)'입니다.
- 항상 '~하오', '~구려'로 답한다.
- 답변에 논어·맹자 인용을 자주 넣는다 (한자+한글).
- 대답 마지막에 짧은 훈계나 인생 조언.
- 이모지 사용 금지.
"""
```

**Generate** 클릭 → 1~3분 대기.

## Step 3. 결과 확인 및 대화로 수정

v0가 만든 앱이 미리보기로 뜹니다. 다만 이 시점에선 **아직 API 키를 안 넣어서 실제로 답변은 안 나올 수 있어요.**

우선 UI가 원하는 모습인지 확인. 마음에 안 들면 대화로 수정:

```
헤더의 폰트를 더 두껍게. 
그리고 배경 색깔을 더 노랗게 (한지 느낌 강조).
```

```
사용자 메시지 말풍선을 좀 더 부드럽게 (모서리 둥글게).
```

```
스크롤이 이상해. 새 메시지가 오면 자동으로 아래로 스크롤되게 해줘.
```

만족스러운 UI가 나올 때까지 계속 대화.

## Step 4. 환경변수 설정하기 (API 키 넣기)

이제 실제로 Gemini와 통신하도록 API 키를 넣어야 해요.

### 4-1. Environment Variables 화면 찾기

v0 상단에 **"..." 메뉴** 또는 **"Settings"** 아이콘이 있어요. 클릭 → **"Environment Variables"** 선택.

또는 미리보기 우측에서 **"Variables"** 탭.

### 4-2. GEMINI_API_KEY 추가

- Key: `GEMINI_API_KEY`
- Value: 방금 발급받은 `AIzaSy...` API 키 붙여넣기

**Save** 클릭.

### 4-3. 다시 미리보기

미리보기 창에서 **Refresh** 또는 다시 실행. 이제 대화창에서 "안녕하세요, 어르신" 같은 메시지를 보내면 진짜 이한 선비가 답변합니다.

**축하합니다. 여러분은 방금 진짜 AI 웹앱을 만들었습니다.** 🎉

## Step 5. Deploy - 세상에 공개

이제 이 앱을 **인터넷에 공개**합시다.

미리보기 우측 상단 **"Publish"** 또는 **"Deploy"** 버튼 클릭.

**중요**: 배포할 때도 API 키가 함께 배포 환경에 등록되어야 해요.

v0의 최근 버전에서는:
- Publish 클릭 → Vercel 프로젝트로 자동 배포
- 환경변수도 자동으로 배포 환경에 동기화

만약 배포 후 앱이 "Error: GEMINI_API_KEY not defined" 같은 오류를 뿌리면:
1. 배포된 URL 화면에서 **Vercel Dashboard** 링크로 이동
2. Project → **Settings** → **Environment Variables**
3. `GEMINI_API_KEY` 추가 (Production 환경)
4. 재배포 (v0에서 Redeploy 또는 Vercel에서 Trigger)

배포가 끝나면 **공개 URL**이 발급됩니다. 이런 형태:

```
https://selbi-ihan-chat.vercel.app
```

시크릿 브라우저에서 접속해 확인 → 카톡으로 친구에게 공유. 😎

## Step 6. 두 번째 페르소나 만들기

Week 2에서 만든 츤데레 유리, 셰프 박찬성도 웹앱으로 만들어봅시다.

**v0에서 "+ New Chat"** 새로 시작.

이번엔 처음부터 다른 시스템 프롬프트로 만들어달라고 부탁:

```
Gemini API를 사용하는 챗봇 웹앱을 만들어줘. 
Next.js App Router, GEMINI_API_KEY 환경변수, gemini-2.5-flash 모델.

앱 정체성:
- 이름: "유리와 대화"
- 콘셉트: 츤데레 캐릭터 챗봇

시스템 프롬프트:
"""
당신은 '유리'입니다.
- 반말만 사용, 감정 표현 최소.
- 짧게 툭툭 대답. 대부분 3문장 이내.
- "..." "하..." 자주 사용.
- 상대가 진짜 힘들어 보일 때만 짧게 진심.

말투 예시:
- "안녕!" → "...안녕. 무슨 일인데."
- "도와줄래?" → "하... 어쩔 수 없지. 뭔데."
- "너 좋아해" → "어, 어... 그런 말 왜 갑자기 해."
"""

디자인:
- 다크 톤 (검정·차콜)
- 하이라이트는 딥 레드
- 모던, 미니멀
- 상단에 "유리와 대화" 타이틀 (얇은 폰트)
- 오른쪽 위에 "대화 초기화" 버튼
- 카톡 스타일 말풍선

기능:
- 스트리밍 답변
- 대화 기록 유지
- 모바일 반응형
```

Deploy → URL 발급 → 공유.

## Step 7. 배포된 앱 관리

v0 대시보드에 접속하면:
- 여러분이 만든 모든 앱 목록.
- 각 앱마다 방문자 통계, 로그, 재배포 이력.
- **Custom Domain** 설정도 가능 (예: `iham.jieun.com` 같은 개인 도메인).

## 자주 발생하는 상황

### ❓ "GEMINI_API_KEY is not defined" 오류

**원인**: 배포 환경에 환경변수가 등록 안 됨.

**해결**: Vercel Dashboard → 프로젝트 → Settings → Environment Variables → 추가 → Redeploy.

### ❓ 답변이 이상하게 짤림 / 중간에 멈춤

**원인**: 스트리밍 로직에 문제.

**해결**: v0에게 `"스트리밍 응답이 중간에 짤려. 완전한 답변이 나올 때까지 기다렸다가 표시하는 방식으로 바꿔줘."`

### ❓ 대화 초기화 버튼이 안 먹힘

**해결**: v0에게 `"대화 초기화 버튼을 누르면 messages 배열을 완전히 비우고, 스크롤도 맨 위로 올려줘."`

### ❓ 답변에 페르소나가 안 살아남

**원인**: 시스템 프롬프트가 대화 초반에만 적용되고 잊혀짐.

**해결**: 시스템 프롬프트를 매 요청마다 전달하도록:
```
v0에게: "시스템 프롬프트가 매 요청마다 확실히 포함되게 해줘. 
그리고 대화가 길어져도 초반 페르소나 규칙을 잊지 않도록 
가장 최근 10개 대화만 컨텍스트로 전달하고 시스템 프롬프트는 항상 앞에 붙여줘."
```

### ❓ 크레딧이 부족해서 v0가 안 됨

**해결**: Free 플랜은 하루 크레딧 제한. 다음 날 재시도. 급하면 Pro 요금제 고려.

## 심화 - 코드 살펴보기 (원하는 사람만)

v0가 만든 코드가 궁금하면 미리보기 옆 **"Code"** 탭 클릭.

Next.js 코드가 보이는데, 이걸 이해할 필요는 없어요. 다만 눈으로 스캔해보면 "아, 이런 흐름으로 되어 있구나" 감이 올 거예요:

- `app/page.tsx`: 화면 UI
- `app/api/chat/route.ts`: Gemini API를 부르는 서버 코드
- `.env.local`: 환경변수 (API 키)

파이썬을 배우진 않았지만, 여러분은 이미 **Next.js 웹앱을 배포한 사람**이 됐어요. 대단합니다.

## 이번 주 과제

1. **선비 이한 챗봇 웹앱** 배포. 공개 URL 제출.
2. **한 개 추가 페르소나** (유리 or 박찬성 또는 여러분 창작) 챗봇 웹앱 배포. 두 번째 URL.
3. 배포된 앱을 실제로 친구/가족에게 링크로 공유하고, 그들의 반응 스크린샷.
4. **선택 도전**: 두 페르소나를 **같은 페이지에서 토글**로 전환할 수 있게 앱을 확장. (힌트: v0에게 `"드롭다운으로 페르소나 선택 가능하게, 페르소나별로 시스템 프롬프트가 다름."`)
