## 이번 주에 할 일

지금까지 만든 챗봇의 한계:

1. **최신 정보를 모른다** — Gemini는 학습 시점(예: 2025년) 이후 뉴스를 모름
2. **정확한 계산이 약하다** — LLM은 "125 × 8 = 1000"을 틀리게 답할 수 있음
3. **문맥 기반 도구를 못 씀** — 오늘 날짜, 현재 시각 등

이번 주 두 가지로 이걸 해결:

- **Google Search Grounding**: AI가 실시간으로 구글 검색해서 최신 정보 답변
- **Function Calling**: AI가 여러분이 정의한 도구를 스스로 골라 사용

이번 주가 지나면 **진짜 어시스턴트**가 완성됩니다.

## Part 1: Google Search Grounding 🌐

Google Search Grounding = **AI가 답변할 때 자동으로 구글 검색해서 근거를 찾아오는 기능**.

### Step 1. Grounding 활성화

<a href="https://aistudio.google.com" target="_blank">aistudio.google.com</a>에서 **+ New chat**.

오른쪽 사이드바 아래쪽에서 **"Tools"** 섹션을 찾아 펼치세요. (인터페이스에 따라 **"Grounding with Google Search"** 스위치가 별도로 있을 수도 있어요.)

**"Google Search"** 스위치를 켜세요.

### Step 2. 최신 정보 질문 던지기

아래 질문들을 하나씩 붙여넣어보세요:

```
오늘 서울 날씨 어때?
```

```
최근 3개월 이내에 나온 애플의 신제품 소식 알려줘.
```

```
이번 주 개봉한 한국 영화 리스트 알려줘.
```

```
현재 원달러 환율은?
```

답변 아래에 **참고한 웹페이지 링크들이 표시**될 거예요. AI가 진짜로 검색해서 정보를 가져왔다는 증거입니다.

### Step 3. 리서치 어시스턴트 프롬프트

Grounding + System Instructions 조합으로 **리서치 어시스턴트**를 만들어봅시다.

**System Instructions**:

```
당신은 대학생을 돕는 리서치 어시스턴트입니다. 사용자가 질문하면 
Google Search로 최신 정보를 찾아 다음 형식으로 답변합니다.

【답변 형식】
## 📌 핵심 답변
사용자 질문에 대한 직접적 답변 (3~5문장).

## 🔍 상세 정보
- 관련 사실 3~5개 (bullet point)
- 최신 뉴스나 데이터가 있으면 함께 언급

## 📚 참고 자료
검색에서 실제로 인용한 출처 (링크 형태로)

## 💡 추가로 알면 좋은 것
사용자가 더 조사하면 좋을 관련 주제 3개.

【규칙】
- 확실하지 않은 정보는 "확인이 필요합니다"라고 명시.
- 정치·의료·법률처럼 민감한 주제는 전문가 상담을 권장.
- 모든 답변은 한국어로.
```

**Google Search grounding** 켜기 + **Temperature**: `0.5` (사실 중심).

**저장 이름**:

```
리서치 어시스턴트 (Web Search)
```

**테스트**:

```
2026년 청년 정책 중 대학생이 활용할 수 있는 것 3가지만 알려줘.
```

```
최근 한 달간 발표된 AI 관련 큰 뉴스 5개 정리해줘.
```

```
서울 시내 신진 문학 잡지 최근 소식이 있어?
```

## Part 2: Function Calling 🛠️

**Function Calling** = AI가 여러분이 정의한 도구(함수)를 스스로 골라 사용하는 기능.

Google Search 외에도 **여러분이 만든 커스텀 도구**를 붙일 수 있어요. 예:

- 계산기
- 현재 시각
- 환율 계산기
- 날씨 조회 (별도 API)
- 여러분만의 로직

### Step 4. Function Calling 옵션 열기

오른쪽 사이드바 **"Tools"** 섹션에서 **"Function calling"**을 켜세요.

**Add function** 버튼이 나타나면 클릭. 함수 하나씩 정의합니다.

### Step 5. 계산기 함수 정의

**Add function** → 다음 값을 채워넣기.

**Name**:

```
calculator
```

**Description**:

```
정확한 수학 계산을 수행합니다. 큰 수의 곱셈, 나눗셈, 제곱근, 삼각함수 등 
AI가 직접 계산하면 부정확할 수 있는 모든 수식에 사용합니다.
```

**Parameters** (JSON Schema):

- Name: `expression`
- Type: `string`
- Description:

```
계산할 수식 문자열. 예: "128 * 47", "sqrt(2) * 100", "sin(pi/2)"
```

- Required: ✅ (체크)

### Step 6. 현재 시각 함수 정의

**Add function** 하나 더.

**Name**:

```
get_current_time
```

**Description**:

```
현재 한국 시간(KST)을 YYYY-MM-DD HH:MM:SS 요일 형식으로 리턴합니다. 
"지금 몇 시야?", "오늘 며칠?" 같은 시간·날짜 질문에 사용하세요.
```

**Parameters**: 없음 (인자 필요 없는 함수)

### Step 7. 환율 계산 함수 정의

**Name**:

```
convert_currency
```

**Description**:

```
한 통화를 다른 통화로 환산합니다. 기본 환율표를 사용하며, 
실제 시장 환율과 차이가 있을 수 있음을 사용자에게 알리세요.
```

**Parameters**:

- `amount`: number, Description: `환산할 금액`
- `from_currency`: string, Enum: `KRW, USD, EUR, JPY, CNY, GBP`
- `to_currency`: string, Enum: `KRW, USD, EUR, JPY, CNY, GBP`

### Step 8. 테스트

**System Instructions**에 다음 붙여넣기:

```
당신은 실용적인 어시스턴트입니다. 사용자의 요청을 분석해서 
필요한 도구를 스스로 골라 사용하세요.

규칙:
- 수학 계산이 필요하면 calculator 도구 사용 (직접 암산하지 않기)
- 시간·날짜 관련 질문에는 get_current_time 도구 사용
- 환율 관련 요청에는 convert_currency 도구 사용
- 도구를 쓴 뒤에는 그 결과를 자연스러운 문장으로 정리해서 답변
- 모든 답변은 한국어로
```

**테스트 질문들**:

```
128 곱하기 47이 얼마야?
```

→ AI가 자동으로 `calculator` 도구 호출.

```
지금 몇 시야?
```

→ AI가 자동으로 `get_current_time` 도구 호출.

```
100달러가 원화로 얼마야?
```

→ AI가 자동으로 `convert_currency({amount: 100, from: "USD", to: "KRW"})` 호출.

```
안녕! 오늘 기분 어때?
```

→ AI가 도구 없이 그냥 대화.

AI가 **상황에 맞게 도구를 골라 쓰는** 모습을 관찰하세요. 이게 에이전트적 행동입니다.

## Part 3: Grounding + Function Calling 조합

두 기능을 동시에 켜면 진짜 강력한 어시스턴트가 됩니다.

### Step 9. 모든 도구 켠 상태로 실험

**Tools 섹션**에서 다음을 모두 켜세요:

- ✅ Google Search grounding
- ✅ Function calling (calculator, get_current_time, convert_currency)

이 상태에서 복잡한 질문 던져보기:

```
지금 서울 날씨 알아보고, 우산이 필요한지 알려줘. 
그리고 만약 우산이 필요하면 편의점 우산 가격이 얼마 정도인지도.
```

이 한 질문에 AI가:
1. Google Search로 서울 날씨 조회
2. 날씨 기반 우산 필요 여부 판단
3. Google Search로 편의점 우산 가격 조사
4. 종합해서 답변

**이걸 3~4단계 자동 실행하는 게 에이전트의 진짜 힘**입니다.

또 다른 실험:

```
오늘 원달러 환율 검색해서 알아본 뒤, 
100달러가 지금 원화로 정확히 얼마인지 계산해줘.
```

## 자주 발생하는 상황

### ❓ Function calling 스위치가 안 보여요

**해결**: AI Studio 인터페이스는 자주 바뀝니다. 모델을 **gemini-2.5-flash** 또는 **gemini-2.5-pro**로 선택했는지 확인. 일부 구버전 모델은 function calling 미지원.

### ❓ AI가 도구를 안 쓰고 자기가 답함

**원인**: 도구 Description이 모호하거나, System Instructions에 지시 부족.

**해결**: 
1. 각 함수의 Description을 더 명확히 (특히 언제 써야 하는지).
2. System Instructions에 "반드시 이 도구를 사용" 규칙 추가.

### ❓ Grounding이 켜져 있는데 오래된 정보를 줌

**원인**: 검색 결과가 여전히 오래된 페이지일 수 있음. Google Search는 웹 페이지의 최신성을 완벽히 보장하지 않아요.

**해결**: 프롬프트에 "2026년 10월 이후 발표된 것만" 같은 시간 범위 명시.

### ❓ 참고 자료(링크)가 표시되지 않아요

**해결**: 특정 UI에서는 답변 아래 **"Sources"** 또는 **"참고"** 섹션을 클릭해서 펼쳐야 표시됩니다. 안 보이면 새로고침 후 다시 시도.

### ❓ Function calling이 계속 실패해요

**해결**: 
1. 파라미터의 이름·타입이 정확한지 확인.
2. Required 필드가 다 채워져 있는지.
3. 모델을 **gemini-2.5-pro**로 바꾸면 함수 선택이 더 정확.

## Step 11. 실전 응용 - 나만의 어시스턴트

여러분 전공·관심사에 맞춘 커스텀 어시스턴트를 만들어보세요.

### 예시 A: 문학 리서치 어시스턴트

```
당신은 문학 전공 대학원생을 돕는 리서치 어시스턴트입니다.
- Google Search로 작가·작품·평론 최신 정보 조사
- 인용 형식은 반드시 각주 형태로
- 정확하지 않은 정보는 "확인 필요" 표시
```

### 예시 B: 취업 준비 코치

```
당신은 취업 준비생을 돕는 코치입니다.
- 지원하려는 회사·업계 최신 뉴스를 Google Search로 조사
- 자소서 문항에 맞춰 회사 분석 정리
- 예상 면접 질문 5개 함께 제안
```

### 예시 C: 실시간 시사 브리핑

```
당신은 매일 아침 시사 브리핑을 제공하는 뉴스 큐레이터입니다.
- 오늘 날짜 확인 후 Google Search로 주요 뉴스 조사
- 카테고리별(정치/경제/사회/문화/국제)로 3가지씩 정리
- 각 뉴스에 30자 요약 첨부
```

## 이번 주 과제

1. **리서치 어시스턴트** (Grounding 켠 것) 프롬프트 저장 & 공유 URL.
2. **함수 3개** (calculator, get_current_time, convert_currency) 세팅한 프롬프트 저장.
3. **Grounding + Function calling 동시 켠 어시스턴트** 저장. 복합 질문 3개 이상 테스트.
4. **선택 도전**: 여러분 전공에 맞춘 커스텀 어시스턴트 하나 완성.
