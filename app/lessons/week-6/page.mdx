## 이번 주에 할 일

지금까지 만든 앱들의 공통점: **데이터가 고정**되어 있었어요. 여러분(개발자)이 미리 준비한 데이터를 보여주기만 했죠.

이번 주는 다릅니다. **사용자가 직접 데이터를 만들고, 저장하고, 다시 방문해도 그대로**인 앱을 만듭니다.

만들 것: **To-Do 앱** (할 일 관리 앱)

교과서 같은 예제지만, 이 안에 웹앱의 핵심 기술이 다 들어있어요:
- 사용자가 새 항목 추가
- 항목 편집
- 완료 체크
- 삭제
- **데이터 저장(localStorage)**

이걸 다 배우면 다른 종류의 앱도 만들 수 있어요 — 메모장, 가계부, 습관 트래커, 학습 로그 등.

## 5분 개념

### CRUD

앱이 데이터를 다루는 4가지 기본 동작:

| 이름 | 뜻 | To-Do 예시 |
|---|---|---|
| **C**reate | 만들기 | 새 할 일 추가 |
| **R**ead | 읽기 | 할 일 목록 보기 |
| **U**pdate | 수정 | 할 일 내용 편집, 완료 체크 |
| **D**elete | 삭제 | 할 일 지우기 |

거의 모든 앱은 이 4가지의 조합입니다. 인스타(사진 CRUD), 카톡(메시지 CRUD), 배달앱(주문 CRUD) 등등.

### 상태(State)

"상태" = 지금 이 순간 화면이 보여주는 데이터.

To-Do 앱에서 상태:
```
할일들 = [
  { id: 1, 내용: "우유 사기", 완료: false },
  { id: 2, 내용: "숙제 하기", 완료: true },
]
```

사용자가 "새 할 일 추가" 하면 → 이 배열에 항목 추가 → 화면이 즉시 갱신됩니다.

React·Next.js에서는 이걸 **`useState`**라는 도구로 관리해요. v0가 알아서 코드에 넣어줍니다.

### localStorage

브라우저는 각 웹사이트마다 **작은 저장 공간**을 하나씩 줍니다. 이걸 localStorage라고 해요.

- 크롬 껐다 다시 켜도 남아있음
- 각 사이트마다 별도 (naver.com이 저장한 걸 daum.net이 못 봄)
- 5MB 정도 저장 가능 (충분히 큼)

**이번 주 마법**: 앱의 상태 배열을 localStorage에 저장 → 다시 방문 시 자동으로 불러오기 → 마치 서버에 저장된 것처럼 데이터가 살아남음.

## Step 2. To-Do 앱 뼈대 요청

```
할 일 관리 웹앱을 만들어줘. Next.js App Router.

앱 기능:

1. 새 할 일 추가
   - 상단에 큰 입력창 + "+ 추가" 버튼
   - Enter 키로도 추가 가능
   - 빈 문자열은 추가 안 됨
   - 추가되면 입력창 자동으로 비우고 focus 유지

2. 할 일 목록
   - 최근 추가된 것이 맨 위
   - 각 항목: 체크박스 + 할 일 텍스트 + 편집 아이콘 + 삭제 아이콘
   - 완료된 항목은 취소선 + 회색으로

3. 완료 토글
   - 체크박스 클릭 시 완료 상태 토글

4. 편집
   - 편집 아이콘(펜) 클릭 → 해당 항목의 텍스트가 입력창으로 바뀜
   - Enter 시 저장, Esc 시 취소

5. 삭제
   - 휴지통 아이콘 클릭 → 확인 팝업 → 확인 시 삭제
   - 확인 팝업은 자체 UI (window.confirm 말고 예쁜 모달)

6. 필터 탭 (상단)
   - "전체 (N)" / "진행중 (N)" / "완료 (N)"
   - 각 탭 옆에 해당하는 개수 표시
   - 현재 선택된 탭은 강조

7. 전체 지우기
   - 우측 상단에 "완료된 할 일 모두 삭제" 버튼
   - 완료된 항목이 하나라도 있을 때만 활성화
   - 클릭 시 확인 팝업

8. 통계 카드 (상단)
   - "오늘 할 일 X개 중 Y개 완료 (Z%)"
   - 프로그레스 바로도 시각화

데이터 구조:
type Todo = {
  id: string;              // uuid 사용
  text: string;
  completed: boolean;
  createdAt: string;       // ISO 날짜
}

localStorage 저장:
- key: "todos-v1"
- 상태가 바뀔 때마다 자동으로 저장 (useEffect)
- 앱이 처음 켜질 때 localStorage에서 불러옴
- SSR 대응: 서버 렌더링 시엔 빈 배열, 클라이언트 마운트 후 로드

디자인:
- 미니멀 (Todoist 느낌)
- 흰 배경, 부드러운 그레이 라인
- 강조색: 파란색(#3B82F6)
- 완료 항목: 회색 + 취소선
- 각 항목에 살짝 그림자
- 반응형 (모바일에선 아이콘만, 데스크톱은 아이콘+텍스트)

UX 디테일:
- 새 항목 추가 시 애니메이션으로 위에서 내려오듯
- 삭제 시 사라지는 애니메이션
- 완료 토글 시 체크박스에 부드러운 애니메이션
- 전체가 비어있으면 "🎉 오늘 할 일 없음! 잘 하고 있어요"
```

`Enter` → 3~5분 대기.

## Step 3. 기본 기능 테스트

미리보기에서:

1. 할 일 3개 추가.
2. 하나 완료 체크.
3. 하나 편집해서 텍스트 바꾸기.
4. 하나 삭제 → 팝업 확인.
5. 필터 탭 전환.
6. **미리보기 창 새로고침** (F5) → 데이터가 유지되어야 함! (이게 핵심)
7. 다른 탭에서 미리보기 URL 열기 → 같은 데이터.

**"미리보기 새로고침 후에도 할 일이 살아있는가"**가 이번 주 성패입니다.

### 안 되면

```
새로고침하면 할 일이 다 사라져. 
localStorage 저장·복원 로직이 잘 안 되는 것 같아. 
디버깅해서 수정해줘.

체크할 것:
1. 상태 변경 시 localStorage.setItem이 호출되는지
2. 초기 로드 시 localStorage.getItem을 하는지
3. JSON.parse / JSON.stringify가 잘 되는지
4. SSR (서버 렌더링) 시 window is undefined 오류가 없는지
```

## Step 4. 우선순위 기능

일 관리 앱에서 자주 쓰는 기능:

```
각 할 일에 우선순위를 지정할 수 있게 해줘.
- 낮음 (기본, 회색) / 중간 (주황) / 높음 (빨강)
- 새 할 일 추가 시 우측에 드롭다운으로 우선순위 선택
- 편집 시에도 우선순위 변경 가능
- 목록에서 각 항목의 왼쪽에 우선순위 도트 표시 (색깔로)
- 정렬 옵션에 "우선순위 순" 추가

Todo type에 priority: "low" | "medium" | "high" 필드 추가.
```

## Step 5. 마감일 기능

```
각 할 일에 선택적 마감일을 지정할 수 있게 해줘.
- 새 항목 추가 시 우측에 날짜 선택기 (선택사항)
- 마감일이 있으면 각 항목 오른쪽에 "D-3", "오늘 마감!" 같은 배지
- 오늘 마감인 것은 노란 배지, 
- 지난 것은 빨간 배지 + 취소선 없어도 강조
- 필터에 "오늘" / "이번 주" / "지연" 추가

Todo type에 dueDate: string | null 필드 추가.
```

## Step 6. 카테고리 (선택)

일이 많아지면 카테고리로 분류하고 싶어요:

```
할 일에 카테고리(태그)를 붙일 수 있게 해줘.
- 사이드바에 카테고리 목록: "학교", "일상", "취미", "건강", "기타"
- 사이드바에서 카테고리 클릭 시 해당 카테고리만 필터
- 새 할 일 추가 시 카테고리 선택 (드롭다운 또는 칩)
- 각 항목에 카테고리 태그 표시
- 카테고리별 완료율 통계

Todo type에 category: string 필드 추가.

카테고리 목록도 사용자가 직접 관리할 수 있게 
(추가/삭제 가능). 카테고리 배열도 localStorage에 저장.

localStorage keys:
- "todos-v1"
- "categories-v1"
```

## Step 7. 다크 모드

```
우측 상단에 다크모드 토글 버튼 추가.
- 클릭 시 전체 배경이 어두운 회색으로, 텍스트는 밝은 흰색으로
- localStorage에 "theme" 저장 ("light" | "dark")
- 재방문 시 이전 선택이 유지
- 시스템 다크모드 감지도 (prefers-color-scheme 미디어 쿼리) 
  → 사용자가 명시 선택 없으면 시스템 따라감
```

## Step 8. 키보드 단축키

파워 유저를 위한 디테일:

```
키보드 단축키 지원:
- Ctrl/Cmd + N: 새 할 일 입력창에 포커스
- Ctrl/Cmd + A: 모든 진행중 할 일 완료 토글
- Ctrl/Cmd + K: 검색창 표시 (검색 기능도 함께 추가)
- Esc: 편집 취소 or 팝업 닫기

우측 하단에 "?" 버튼 클릭 시 단축키 도움말 표시.
```

## Step 9. 데이터 내보내기/불러오기

데이터를 잃지 않도록:

```
설정 메뉴에서 두 가지 기능:

1. "내보내기 (Export)"
   - 현재 모든 할 일을 JSON 파일로 다운로드
   - 파일명: todos-YYYY-MM-DD.json

2. "불러오기 (Import)"
   - JSON 파일 선택 → 현재 데이터에 병합 또는 대체
   - 확인 팝업으로 사용자에게 선택 물음
```

이거면 브라우저를 바꿔도, 캐시가 지워져도 데이터를 복구할 수 있어요.

## Step 10. 통계 대시보드 (선택)

동기부여를 위한 시각화:

```
상단에 통계 카드 3개 추가:
- 카드 1: "오늘 완료" - 오늘 완료된 할 일 개수
- 카드 2: "이번 주 완료율" - 최근 7일 완료된 것 %
- 카드 3: "연속 완료일" - 오늘 포함 연속으로 뭔가 완료한 일수

각 카드에 작은 스파크라인 그래프 (지난 7일 추이).

completedAt: string | null 필드를 추가해서 언제 완료됐는지 기록.
```

## Step 11. Publish

**Publish** → 배포 → 실제 URL에서 확인.

**배포 URL에서 localStorage 테스트** 반드시:
- 브라우저 두 개(Chrome + Edge)에서 접속 → 각각 별개의 데이터가 저장되는가.
- 폰과 노트북에서 접속 → 각 기기별로 별개 (localStorage는 기기·브라우저별로 저장).

만약 여러 기기 동기화가 필요하다면 실제 서버 DB가 필요해요. 그건 이 강의 범위를 벗어나지만, Vercel의 KV(Redis) 같은 서비스로 확장 가능.

## Step 12. 여러분 방식으로 변형

To-Do 대신 다른 주제로 응용해보세요.

- **가계부**: text 대신 "금액 + 카테고리 + 메모"
- **독서 로그**: "책 제목 + 저자 + 시작일 + 완독일 + 별점"
- **운동 트래커**: "운동 종류 + 시간 + 세트/횟수"
- **일기**: "날짜 + 감정 + 오늘 있었던 일"
- **한 줄 아이디어 노트**: "아이디어 + 태그 + 발전 상태"

핵심 패턴은 똑같아요: **입력 → 배열에 추가 → localStorage 저장 → 목록 표시**.

## 자주 발생하는 상황

### ❓ 새로고침하면 데이터가 사라짐

**해결**: Step 3의 디버깅 요청 활용. 특히 SSR 대응 (Next.js는 서버에서 먼저 렌더링하므로 `window`, `localStorage`에 직접 접근하면 오류).

```
useEffect로 mount 후에만 localStorage에 접근하도록 해줘.
초기값은 빈 배열로 시작, useEffect에서 
localStorage.getItem으로 불러오기.
```

### ❓ 여러 탭에서 열면 데이터가 안 맞음

**해결**:
```
localStorage 변경을 여러 탭 간에 동기화하도록 
storage 이벤트를 리스닝해서 다른 탭의 변경을 감지, 
현재 탭의 상태도 갱신하게 해줘.
```

### ❓ 삭제 애니메이션이 뚝뚝 끊김

**해결**:
```
할 일 삭제 시 부드럽게 사라지는 애니메이션 적용.
Framer Motion을 사용해서 AnimatePresence로 감싸고 
opacity + height 트랜지션.
```

### ❓ 사용자가 실수로 삭제하면?

**해결**:
```
삭제한 항목을 5초간 하단에 "실행 취소" 스낵바로 표시. 
5초 안에 클릭하면 복구, 지나면 완전 삭제.
```

## 이번 주 과제

1. **To-Do 앱 완성 & 배포**. URL 제출.
2. **필수 기능**: 추가·완료·편집·삭제 + 필터 + **localStorage 저장**.
3. **선택 기능 3개 이상 구현**: 우선순위 / 마감일 / 카테고리 / 다크모드 / 통계 등.
4. 새로고침 후에도 데이터 유지되는지 확인. **스크린샷 3장** (초기 → 데이터 입력 후 → 새로고침 후).
5. **선택 도전**: 여러분 취향에 맞게 To-Do가 아닌 다른 주제로 변형 (독서 로그, 운동 트래커 등).
