## 이번 주에 할 일

지난 4주는 텍스트 위주였어요. 이번 주는 **이미지**를 다룹니다.

Gemini 2.5는 **멀티모달** 모델이에요. 텍스트뿐 아니라 이미지·오디오·비디오까지 이해합니다. 우리는 이번 주에 **이미지 이해(Vision)**를 집중적으로 다룹니다.

## 결과물

- **여행 사진 → 감성 캡션 3가지 스타일** (Vision + Structured Output)
- **옷장 사진 → 오늘의 코디 추천**
- **문제 사진 → 풀이 설명**
- 각 프롬프트마다 저장 & 공유 URL

## Part 1: 이미지 이해 기초

### Step 1. 첫 이미지 업로드

<a href="https://aistudio.google.com" target="_blank">aistudio.google.com</a>에서 **+ New chat**.

가운데 대화창 하단, 입력창 왼쪽에 **➕ 또는 클립 아이콘**이 있어요. 클릭하면 파일 업로드 옵션이 뜹니다.

- **Upload File**: 컴퓨터에서 이미지 선택
- **Take a photo**: 웹캠으로 찍기 (Mac은 잘 됨)

여러분 폰에서 아무 사진 하나를 컴퓨터로 옮겨서 업로드해보세요.

### Step 2. 이미지에 대해 물어보기

이미지가 대화창 위에 미리보기로 뜬 상태에서, 입력창에 이걸 붙여넣기:

```
이 사진에 뭐가 보여? 한국어로 상세하게 설명해줘.
```

`Run` → 잠시 후 AI가 사진을 보고 답변합니다.

**놀랍지 않나요?** AI가 정말로 사진을 이해합니다. 색깔, 사물, 표정, 분위기까지.

### Step 3. 같은 사진에 다양한 질문

같은 사진에 대해 다양한 질문을 던져보세요.

```
이 사진의 분위기를 한 문장으로 표현해줘.
```

```
이 사진에 어울리는 인스타 캡션 만들어줘. 감성적으로.
```

```
이 사진을 초등학생이 이해할 수 있게 설명해줘.
```

```
이 사진 속 상황이 왜 웃긴지 (또는 슬픈지) 분석해줘.
```

같은 사진이 각 질문마다 완전히 다른 답변으로 이어져요. 이게 프롬프트의 힘입니다.

## Part 2: 여행 사진 감성 캡션 앱 ⭐

이번 주 하이라이트. Vision + Structured Output + 페르소나 조합.

### Step 4. 새 프롬프트 세팅

**+ New chat**.

**System Instructions**에 아래 붙여넣기:

```
당신은 인스타그램 감성 캡션 전문가입니다.
사용자가 여행 사진을 올리면, 사진 속 실제 요소(색감·시간대·사물·분위기·계절)를 
근거로 3가지 스타일의 캡션을 제안합니다.

【스타일 정의】
1. 감성적: 3~4문장, 시적이고 잔잔한 톤. 해시태그 3개 포함.
2. 위트있게: 2~3문장, 짧고 재치있게. 이모지 2~3개 자연스럽게 배치.
3. 긴 여행기: 5~7문장, 그 순간의 감정과 배경을 담아 진솔하게. 마지막에 여행 인사이트 한 줄.

【규칙】
- 사진 속 실제 요소를 반드시 반영.
- 국가·지역이 명확히 보이면 언급하고, 애매하면 상상으로 채우지 않는다.
- 각 캡션 사이 --- 구분선.
- 모든 텍스트 한국어.
```

**Temperature**: `0.9` (창의성 필요)

**저장 이름**:

```
여행 사진 감성 캡션 (3-Style)
```

### Step 5. Structured Output으로 강화

캡션 3가지가 JSON 배열로 나오면 더 다루기 쉬워요.

**Structured Output** 켜기 → 스키마:

- `emotional`: object
  - `caption`: string, Description: `감성적 스타일 캡션 3~4문장`
  - `hashtags`: array of string, Description: `해시태그 3개`
- `witty`: object
  - `caption`: string, Description: `위트있는 캡션 2~3문장`
  - `emojis`: array of string, Description: `사용된 이모지들`
- `journey`: object
  - `caption`: string, Description: `긴 여행기 5~7문장`
  - `insight`: string, Description: `여행 인사이트 한 줄`

### Step 6. 테스트

여행 사진 하나 업로드 + 메시지:

```
이 사진에 어울리는 3가지 스타일 캡션을 만들어줘.
```

결과 예시:

```json
{
  "emotional": {
    "caption": "골목의 낡은 벽돌은 오래 살아온 시간의 색이었다. 오후 네 시의 빛이 그 위에 살포시 얹혀 있었고, 나는 그 순간이 오래 남길 바랐다. #교토여행 #교토골목 #여행의감성",
    "hashtags": ["#교토여행", "#교토골목", "#여행의감성"]
  },
  "witty": {
    "caption": "골목에서 시간을 팔았어요. 안녕 2026 오후 4시! 📷☕✨",
    "emojis": ["📷", "☕", "✨"]
  },
  "journey": {
    "caption": "교토의 골목은 사람이 적을수록 매력적이다. 큰길에서 한 걸음만 벗어나면 갑자기 이런 오래된 벽돌담이 나타난다. 오후 네 시의 볕이 벽에 걸쳐 있는 광경을 나는 한참 서서 봤다. 관광객 카페 대신 이 골목에서 15분을 보낸 게 이 여행의 가장 좋은 순간이었다. 어쩌면 좋은 여행은 유명한 곳을 얼마나 봤나가 아니라, 이렇게 그냥 멈춰선 순간이 몇 번이었나로 재는 것 같다. 다음엔 관광지에 덜 가고 골목에 더 오래 있어야겠다.",
    "insight": "좋은 여행은 유명한 곳이 아니라 멈춰선 순간의 개수로 잰다."
  }
}
```

**이거 인스타 업로드 전 참고 자료로 쓰면 진짜 유용해요.**

## Part 3: 실용 앱 응용 예시

### 예시 A: 오늘의 코디 추천

**System Instructions**:

```
당신은 20대 여성/남성 스타일 코디네이터입니다.
사용자가 옷장 사진을 올리면, 사진 속 옷들을 분석해서 
3가지 코디 조합을 제안합니다.

【답변 형식】
각 코디마다:
- 조합: 상의 / 하의 / 아우터 / 신발 / 액세서리 (사진에 없어도 상상 OK)
- 어울리는 상황: 학교/데이트/모임 등
- 포인트: 이 코디의 하이라이트 한 문장

【규칙】
- 사진에 실제로 있는 옷을 우선 활용.
- 계절감 고려.
- 스타일 톤 다양하게 (캐주얼·세미포멀·스트릿 각 하나씩).
```

**Structured Output** 스키마:

- `outfits`: array of object (3개)
  - `top`: string
  - `bottom`: string
  - `outerwear`: string
  - `shoes`: string
  - `accessories`: array of string
  - `occasion`: string
  - `highlight`: string

**저장 이름**:

```
오늘의 코디 추천
```

### 예시 B: 문제 풀이 도우미

**System Instructions**:

```
당신은 대학생 학습 튜터입니다. 사용자가 문제집·시험지 사진을 올리면
그 안의 문제를 이해하고 풀이 과정을 설명합니다.

【답변 형식】
1. 문제 정리 (원문 그대로 텍스트로)
2. 핵심 개념 (이 문제가 다루는 개념 2~3줄)
3. 풀이 단계 (번호 매긴 3~5단계)
4. 정답
5. 유사 문제에서 주의할 점

【규칙】
- 답만 주지 말고 반드시 개념부터 설명.
- 애매한 문제는 정답을 강요하지 말고 여러 해석 제시.
- 사진이 흐리거나 문제가 안 보이면 "다시 찍어주세요" 요청.
```

**저장 이름**:

```
문제 풀이 도우미
```

### 예시 C: 냉장고 셰프

**System Instructions**:

```
당신은 미슐랭 3스타 셰프 '박찬성'입니다 (Week 2에서 만든 것과 동일).
사용자가 냉장고 사진을 올리면, 그 안 재료로 만들 수 있는 요리 3가지를 추천합니다.

【답변 형식】
각 요리:
- 요리명 + 이모지
- 사진에서 확인된 재료 (실제로 보이는 것만)
- 추가로 필요한 재료 (없는 것)
- 조리 시간
- 난이도 ★1~5
- 실패 방지 팁

【규칙】
- 사진에 없는 재료를 마음대로 추가하지 않는다. "추가 필요"로 명시.
- 유통기한 임박해 보이는 재료 우선 활용 추천.
```

**저장 이름**:

```
냉장고 셰프
```

## Part 4: 여러 이미지 한 번에

이미지를 여러 장 업로드할 수도 있어요. 클립 아이콘을 여러 번 눌러 사진 2~3장 추가.

응용 예시:

- 다른 그림 찾기:

```
두 사진의 차이점을 5가지 찾아줘.
```

- 최고의 사진 고르기:

```
세 장 중 인스타에 올리기 제일 좋은 사진을 골라줘. 이유도.
```

- 시간 순서 정렬:

```
이 4장을 촬영 시점 순으로 나열해줘. 계절이나 시간대 단서를 근거로.
```

## 자주 발생하는 상황

### ❓ 이미지 파일이 안 올라가요

**해결**: 지원 형식은 JPG, PNG, WebP, HEIC. 파일 크기는 20MB 이하 권장. GIF·비디오는 다른 방식으로.

### ❓ 답변이 사진과 다른 걸 얘기해요

**원인**: AI가 사진의 애매한 부분을 상상으로 채움.

**해결**: System Instructions에 강한 지시 추가:

```
사진에 명확히 보이는 것만 근거로 답한다. 
확실하지 않으면 "사진에서 확인 불가"라고 답한다.
```

### ❓ 영수증·손글씨 같은 작은 텍스트가 잘 안 읽혀요

**해결**:
1. 사진을 밝은 곳에서 다시 촬영.
2. 각도를 정확히 위에서 (수직).
3. 모델을 **gemini-2.5-pro**로 바꾸기 (더 똑똑, 하지만 느리고 비쌈).

### ❓ 여러 사진을 함께 못 이해해요

**해결**: 프롬프트에 "몇 번째 사진"임을 명시적으로 언급하게 하기:

```
답변할 때 반드시 "첫 번째 사진", "두 번째 사진" 하는 식으로 
어느 사진을 얘기하는지 명확히 표시해줘.
```

## 이번 주 과제

1. **여행 사진 감성 캡션 (3-Style)** 프롬프트 저장 & 공유 URL 발급.
2. 여러분의 실제 여행 사진 3장으로 캡션 뽑아보기. 결과 스크린샷.
3. Part 3의 세 예시(코디·문제풀이·냉장고 셰프) 중 하나를 골라 실제로 만들어보고 저장.
4. **선택 도전**: 여러분만의 Vision 활용 앱 하나 만들기. 아이디어:
   - 화분 사진 → 식물 이름 판별 + 관리법
   - 명함 사진 → 이름·회사·연락처 JSON
   - 미술관 작품 사진 → 작품 해설
   - 강의 노트 사진 → 텍스트로 변환 + 요약
