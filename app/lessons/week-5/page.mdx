## 이번 주에 할 일

지금까지는 Google AI Studio에서 프롬프트를 짜고 공유 URL을 발급받았죠. 이건 훌륭하지만 한계가 있어요:

- 접속하는 사람이 **Google 계정으로 로그인**해야 함
- UI는 Google이 정해준 대로만 사용
- 진짜 "웹사이트" 느낌은 아님

이번 주부터 **진짜 웹앱**을 만듭니다. 도구는 **v0.dev**.

### v0.dev가 뭐예요?

Vercel(웹사이트 배포 회사)이 만든 **"말로 웹앱 만드는 도구"**입니다.

- 여러분이 한국어로 `"내 자기소개 페이지 만들어줘. 아기자기하게."` 라고 부탁 → 진짜 웹페이지 미리보기
- 마음에 안 들면 대화로 계속 수정 → `"버튼을 좀 더 크게 해줘"`, `"배경을 그라데이션으로"`
- 완성되면 **원클릭 배포** → `https://내앱.vercel.app` URL 발급

이번 주 최종 결과: **인터넷에 공개된 여러분의 자기소개 웹페이지**.

## Step 1. v0.dev 가입

<a href="https://v0.dev" target="_blank">v0.dev</a> 접속.

**Sign in** → **Continue with Google** (또는 GitHub) → 여러분 구글 계정으로 로그인.

가입할 때:
- **팀 이름**을 물어봐요. 여러분 이름이나 별명으로 (예: `jieun-studio`).
- 요금제는 **Free** 선택. 하루 사용량 제한이 있지만 강의용으론 충분.

## Step 2. v0 화면 둘러보기

로그인 후 화면:

- **가운데**: 커다란 프롬프트 입력창. 여기에 "만들고 싶은 앱"을 설명.
- **하단**: 예시 프롬프트들 (참고용).
- **오른쪽 위**: 프로필, 프로젝트 목록.

## Step 3. 첫 프롬프트 - 자기소개 페이지

입력창에 이렇게 써보세요:

```
문과대학 국문학과 3학년 김지은의 자기소개 웹페이지를 만들어줘.

포함 내용:
- 상단에 큰 이름과 한 줄 자기소개 ("문학과 커피를 사랑하는 대학생")
- 프로필 이미지 자리 (원형, 임시 placeholder OK)
- "About Me" 섹션 - 성장 배경, 관심사 3~4문단
- "관심사" 섹션 - 카드 3개로 (문학 / 커피 / 여행) 각 카드에 이모지+제목+간단설명
- "연락처" 섹션 - 이메일, 인스타그램 링크

디자인 요구사항:
- 파스텔 톤 (연한 핑크·연한 베이지 계열)
- 부드러운 서체
- 모바일에서도 예쁘게 보이도록
- 상단에 은은한 그라데이션 배경
```

**Generate** 클릭 → 30초~2분 정도 기다림.

### 미리보기 확인

v0가 생성한 웹페이지가 오른쪽에 미리보기로 뜹니다. **실제 브라우저에서 보이는 그대로**예요.

이 시점에서:
- ✅ 마음에 들면 → Step 4로
- 🔄 수정하고 싶으면 → 계속 대화로 수정 (Step 5 미리보기)

## Step 4. Publish (인터넷에 공개)

미리보기 오른쪽 위 **"Publish"** 또는 **"Deploy"** 버튼 클릭.

몇 초 후, **공개 URL**이 발급됩니다. 이런 형식:

```
https://v0-something-abc123.vercel.app
```

이 URL은 **누구나 접속 가능한 실제 웹사이트**입니다. 브라우저 시크릿 모드로 접속해서 확인해보세요. 세계 어디서든 열립니다.

카톡·문자로 친구에게 공유해보세요. 😎

## Step 5. 대화하면서 앱 발전시키기

한 번에 완벽하게 안 나올 수도 있어요. 계속 수정합시다.

**같은 대화창에** 이런 후속 요청을 던져보세요:

```
프로필 이미지 자리를 정사각형에서 원형으로 바꿔줘.
```

```
"관심사" 카드에 호버 효과 추가해줘. 마우스 올리면 살짝 커지게.
```

```
전체적으로 더 세련되게 리디자인해줘. 
현재는 너무 학생 홈페이지 같아. 
어른스러운 미니멀 디자인으로.
```

```
다크모드 토글 버튼을 우측 상단에 추가해줘.
```

각 요청마다 v0가 새 버전을 만들고 미리보기가 업데이트됩니다. 마음에 들면 **다시 Publish**하면 URL이 자동 반영돼요.

## Step 6. 잘 안 나올 때 - 프롬프트 개선 팁

v0에게 부탁할 때 잘 되는 요령:

### 팁 1. 구체적일수록 좋음

- ❌ `"멋진 웹사이트 만들어줘"`
- ✅ `"1980년대 카페 감성의 웹사이트, 갈색·크림색 톤, 세리프 폰트, 옛 편지 같은 배경"`

### 팁 2. 참고 대상을 언급

- `"애플 홈페이지처럼 미니멀하게"`
- `"인스타그램 프로필 페이지 스타일로"`
- `"토스 앱처럼 깔끔하고 여백 많은 디자인"`

### 팁 3. 섹션 단위로 나눠서 요청

한 번에 다 안 되면:
- 첫 요청: `"자기소개 페이지 뼈대만"`
- 두 번째: `"이제 About Me 섹션에 커피 관련 콘텐츠 추가"`
- 세 번째: `"연락처 섹션 아래에 갤러리 추가"`

### 팁 4. 색깔·서체는 명시

- `"파스텔 톤"`
- `"세리프 폰트"`
- `"버튼은 진한 남색, 배경은 크림색"`

### 팁 5. 인터랙션도 요청 가능

- `"버튼 클릭하면 스크롤 부드럽게 이동"`
- `"이미지 마우스 올리면 살짝 확대"`
- `"모바일에서는 카드가 세로로 쌓이게"`

## Step 7. 다른 스타일 시도

같은 자기소개 페이지를 완전히 다른 스타일로 만들어봅시다. **"+ New chat"** 새 프롬프트:

```
90년대 인터넷 감성의 자기소개 페이지 만들어줘.
- 반짝이는 텍스트 애니메이션
- 방문자 카운터 (임의 숫자)
- 알록달록 무지개 그라데이션
- 코믹 산스 같은 유쾌한 폰트
- 뒷배경엔 별 반짝이는 GIF 느낌
- 아래쪽에 "친구들에게 링크 걸어주세요" 배너
```

Publish → URL 확인 → 완전 다른 느낌의 페이지가 나옵니다.

## Step 8. v0 프로젝트 관리

여러분이 만든 앱들은 **v0의 프로젝트 목록**에 자동 저장됩니다.

- 왼쪽 상단 로고 클릭 → 대시보드로 이동.
- 각 프로젝트 카드를 클릭하면 편집을 이어갈 수 있음.
- **Delete**로 필요 없는 건 삭제.

배포된 URL은 v0가 관리해주므로 여러분은 관리 부담이 없어요.

## Step 9. 실전 예시 - 다양한 미니 앱 만들기

Week 6부터 진짜 Gemini AI를 붙이지만, 이번 주 실습으로 다양한 앱을 미리 만들어보세요.

### 예시 1: 오늘의 명언 페이지

```
매일 다른 명언을 보여주는 웹페이지. 새로고침하면 랜덤으로 바뀜.
- 30개 이상의 명언 데이터를 코드에 미리 포함 (한국·서양·동양 골고루)
- 화면 정중앙에 큰 글씨로 명언, 아래 저자
- 배경은 매번 다른 잔잔한 색깔로
- "새 명언 보기" 버튼
```

### 예시 2: 포트폴리오 페이지

```
디지털 마케팅 지망생을 위한 포트폴리오 페이지.
- 상단: 이름, 지원 분야, 이력서 다운로드 버튼
- 중간: 프로젝트 카드 4개 (제목, 이미지 자리, 짧은 설명, "자세히" 버튼)
- 하단: 스킬 프로그레스 바 (Excel, Photoshop, 카피라이팅 등)
- 색상: 프로페셔널한 네이비·화이트
```

### 예시 3: 이벤트 초대장

```
동아리 정기 공연 초대장 페이지.
- 상단에 큰 공연 제목과 날짜/장소
- 카운트다운 타이머 (D-day까지 몇 일 남았는지)
- "RSVP" 버튼 (누르면 팝업으로 이름·이메일 입력)
- 하단에 지도 자리 (임시 placeholder)
- 재즈 감성의 어두운 톤, 골드 포인트
```

각 예시 페이지를 만들어 URL로 저장하세요.

## 이번 주 과제

1. 여러분 자신의 **자기소개 페이지**를 v0로 만들어 Publish. URL 제출.
2. Step 9의 예시 중 **하나를 골라** 자기 스타일로 커스터마이즈해서 만들기. 두 번째 URL 제출.
3. 각 페이지를 최소 3번 이상 대화로 수정해보기 (색깔 변경, 요소 추가 등).
4. **선택 도전**: 여러분 학과·동아리·개인 프로젝트에 정말 필요한 페이지 하나를 상상해서 만들어보세요.

## 자주 발생하는 상황

### ❓ v0가 영어로 답변만 함

**해결**: 프롬프트에 `"모든 텍스트는 한국어로 작성해줘"` 명시.

### ❓ Publish가 실패함

**원인**: v0의 일시적 오류나 코드에 문제.

**해결**: 미리보기 화면에서 **"Fix errors"** 버튼이 있으면 클릭. 계속 실패하면 새 채팅에서 다시 시도.

### ❓ Free 요금제 크레딧 소진

**해결**: 다음 날까지 대기 (24시간마다 리셋). 또는 Pro 요금제 (수업용은 굳이 필요 없음).

### ❓ 폰에서 보면 이상함

**해결**: v0에게 `"모바일 반응형으로 재작업. 카드는 세로 스택으로, 폰트 좀 작게, 여백 조정."`
